2.1 Definition of Computer Architecture

  • Computer architecture = the design and structure of a computer system – what its parts are and how they work together
  • Covers: instruction set, CPU design, memory and I/O
  • It decides what the computer can do and what the programmer can use

Architecture vs Organization

Computer ArchitectureComputer Organization
MeaningAttributes visible to the programmer. Affects how a program runs logicallyHow the architecture is built – the hardware units and their connections
Question“What does the computer do?”“How does it do it?”
ExamplesInstruction set, number of bits for data types, I/O mechanism, addressing techniquesControl signals, interfaces to peripherals, memory technology used
Example: Does the computer have a multiply instruction? → Architecture decision.
Is it done by a special multiply unit or by repeated addition? → Organization decision.
  • ★ Same architecture can have different organizations → programs still run on all of them (software compatibility)
  • A new organization can give better speed or lower cost, while the architecture stays the same

Early (mechanical) era

  • Abacus – ancient counting tool, the earliest calculating device
  • Pascaline (1642) – mechanical adding machine by Blaise Pascal
  • Charles Babbage – “Father of the Computer”
      ★ Difference Engine (designed 1822) – calculates tables of numbers
      ★ Analytical Engine (proposed 1837) – first design of a general-purpose computer. Had a Store (memory), a Mill (processing unit) and used punched cards
  • Ada Lovelace – wrote programs for the Analytical Engine (1843). Called the first programmer

Electronic era

  • ENIAC (built 1943–45, unveiled 1946) – first general-purpose electronic digital computer. Used over 17,000 vacuum tubes
  • ENIAC was programmed by rewiring switches and cables – not a stored-program computer
  • ★ Stored-program concept (John von Neumann, 1945) → program and data are kept together in memory. Basis of modern computers (Von Neumann architecture – Chapter 3)

Generation features

1st – Vacuum tubes

  • Very large and costly
  • Produced much heat
  • Unreliable, slow
  • Input: punched cards

2nd – Transistors

  • Smaller, faster, cheaper
  • Less heat, more reliable
  • Magnetic core memory
  • Transistor invented 1947 (Bell Labs)

3rd – ICs

  • Many transistors on one chip
  • IC by Jack Kilby (1958)
  • Smaller, low power
  • Keyboard and monitor used

4th – Microprocessor

  • Whole CPU on one chip
  • Personal computers
  • Networks, Internet
  • First: Intel 4004 (1971)

2.4 Evolution of Computer Architecture

Vacuum tube→Transistor→IC→Microprocessor⇒ smaller, faster, cheaper
  • Each new technology made computers smaller, faster, cheaper, more reliable and power-saving
  • Computers moved from room-sized machines to desktops, laptops, phones and embedded devices
  • Processors moved from single core to multi-core for more performance

★ Moore’s Law

  • Number of transistors on a chip doubles about every two years
  • Given by Gordon Moore (1965). It is an observation, not a law of nature

★ Key Observations

  • Architecture = what the programmer sees. Organization = hidden hardware details
  • Same architecture + different organization → same software works
  • Each generation is defined by its hardware technology
  • Stored-program idea: program and data in the same memory
  • ENIAC was electronic but not stored-program
  • Technology change: tubes → transistors → ICs → microprocessor

Real-Life Applications

  • Software compatibility – old programs run on new computers of the same architecture
  • Choosing a computer – knowing processor, memory and speed helps in buying the right laptop or phone
  • Chip design – companies design faster processors using the same architecture
  • Programmers – write better programs when they know how the hardware works
