Chapter 5 : Number Systems

  • Number system = a consistent method to represent numbers using digits or symbols
  • Defined by a base (radix). Each digit’s value depends on its position and the base
  • Gives unique representation and allows maths operations. Essential for data encoding, processing and storage
  • Radix = base = number of distinct digits (including 0) used in positional notation
SystemBaseDigitsKey points
Binary20, 1“bi” = two. Basis of how computers store and process everything. Each digit = bit (binary digit). Bits grouped to encode letters, numbers, colours
Octal80–7E.g. 22₈, 13₈, 17₈. Each digit is a power of 8. 1 octal digit = 3 bits (octal 7 = 111). Compact form of binary
Decimal100–9Used in daily life. 134₁₀ = 1×10² + 3×10¹ + 4×10⁰. 24.5 = 2×10¹ + 4×10⁰ + 5×10⁻¹
Hexadecimal160–9, A–FA–F = 10–15. E.g. 7B3₁₆, 6F₁₆, 4B2A₁₆. 1 hex digit = 4 bits (F = 1111). Used in memory addressing, colour coding (web), low-level programming

Basic calculations (powers)

  • Any number to the power 0 = 1 (2⁰ = 1, 8⁰ = 1, X⁰ = 1). Power 1 = the number itself (2¹ = 2, 8¹ = 8, X¹ = X)
  • Negative powers of 8: 8⁻¹ = 0.125, 8⁻² = 0.015625, 8⁻³ = 0.001953125, 8⁻⁴ = 0.000244140625, 8⁻⁵ = 0.000030517578125

Chapter 6 : Conversions between Number Systems

ConversionMethod
Decimal → other (binary 2, octal 8, hex 16)Whole part: divide repeatedly by the base; write remainders bottom to top. Fraction part: multiply repeatedly by the base; write the whole-number parts top to bottom
Any → decimalMultiply each digit by base^position and add. Positions: …3, 2, 1, 0 . −1, −2, −3…
Binary → octalGroup bits in 3s from the radix point (both sides), write each group as an octal digit
Binary → hexGroup bits in 4s, write each group as a hex digit
Octal → binaryReplace each octal digit by 3 bits
Hex → binaryReplace each hex digit by 4 bits
Octal ↔ hexGo through binary: octal → binary → hex, or hex → binary → octal

Chapter 7 : Representation of Data in Computers

  • = how information is stored and processed inside the computer using 0s and 1s
  • Computers cannot understand human language, numbers or pictures directly – only the binary system
  • Each 0 or 1 = bit. Group of 8 bits = 1 byte. Numbers, letters, symbols, images, sounds are all patterns of bits
  • Why important: computer works only with binary; correct representation stores / reads data properly; different devices and programs read the same data the same way

7.1 Integers

  • Whole numbers, no fraction: 0, 5, −10, 200. Also called fixed-point numbers (radix point fixed)
  • Stored in a fixed number of bits – 8, 16, 32, 64. Bit length decides the range
Unsigned (zero and positive only)Range
8-bit0 to 2⁸ − 1 = 0 to 255
16-bit0 to 2¹⁶ − 1 = 0 to 65,535
32-bit0 to 2³² − 1 = 0 to 4,294,967,295
64-bit0 to 2⁶⁴ − 1 = 0 to 18,446,744,073,709,551,615
  • Examples: 8-bit 0100 0001 = 2⁶ + 2⁰ = 65. 16-bit 0001 0000 0000 1000 = 2¹² + 2³ = 4104. All zeros = 0
  • Signed integers – zero, positive and negative. MSB (most significant bit) = sign bit: 0 = positive, 1 = negative. Remaining bits = magnitude

7.2 Floating-point numbers

  • Encode very large and very small values. Based on scientific notation: fraction × exponent. Trade-off between range and precision
Sign bit0 = positive, 1 = negative
ExponentDecides the scale of the number
MantissaStores the significant digits
  • Importance: range (huge and tiny numbers), precision (balances accuracy and range), flexibility (different scales)
  • Applications: scientific computing, graphics, engineering calculations
  • Standard format: IEEE 754 (textbook: 32-bit = 1 sign + 8 exponent + 23 mantissa; 64-bit = 1 + 11 + 52)

7.3 Characters

  • Letters, digits, symbols stored as binary codes
  • ASCII (American Standard Code for Information Interchange) – each character 1 byte; 128 characters (A–Z, a–z, 0–9, symbols); same meaning on all computers
  • Extended ASCII – 8 bits, 256 characters, extra symbols and graphics
  • Unicode – characters of all languages; 2 bytes or more per character; backward compatible with ASCII; needed for multilingual computing

7.4 Strings

  • String = sequence of characters. Each character is stored as its ASCII / Unicode code in consecutive memory locations

★ Key Observations

  • 1 octal digit = 3 bits. 1 hex digit = 4 bits – that is why grouping works
  • Decimal → other: divide for whole part (read remainders upward), multiply for fraction (read downward)
  • Octal ↔ hex: always go through binary
  • n-bit unsigned range: 0 to 2ⁿ − 1
  • Sign bit: 0 positive, 1 negative
  • Sign-magnitude and 1’s complement have two zeros; 2’s complement has one
  • ASCII = 128 characters (1 byte); Unicode = all languages, 2 bytes or more

Real-Life Applications

  • Hex – colour codes in web design, memory addresses
  • Binary – all data inside computers
  • Floating-point – scientific computing, graphics, engineering calculations
  • Unicode – messages and websites in many languages
  • 2’s complement – how processors do signed integer maths
