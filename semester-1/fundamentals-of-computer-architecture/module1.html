1.2 Computer and Computer System

  • Computer = electronic device that processes data as per instructions given by software programs. It takes input, processes it in the CPU, stores information and gives output
  • Analytical Engine – first mechanical computer. Charles Babbage (Father of the Computer), 1830s
  • ENIAC (Electronic Numerical Integrator and Computer) – first fully functional programmable electronic digital computer, 1945
  • Computer system = hardware (processing unit, memory, I/O devices, storage) + software (operating system, applications) working together for a specific purpose
  • Parts of a computer system: monitor, CPU, CD drive, floppy drive, printer, mouse, keyboard, speaker

IPOS cycle

INPUT→PROCESSING→OUTPUT|STORAGE
(↔ processing)

How the CPU works – example 5 + 3

User presses keys 5, +, 3→Input goes to memory (RAM)→Control unit fetches and interprets instruction→ALU performs 5 + 3→Result stored in memory→Output shown on screen

1.5 Data Representation

  • Data representation = how data is represented, stored and processed in binary (0s and 1s)
  • Computers understand only binary. Numbers, text, images, audio, video are all converted to binary codes
DataHow it is represented
BinaryOnly 0 and 1 (bits). Groups of bits form bytes and larger units. Uses the on / off state of hardware
NumericIntegers → directly in binary. Floating-point (real numbers) → special formats like IEEE 754 (magnitude + precision)
TextASCII – 7 or 8 bits per character (English letters, symbols). Unicode – almost all human languages, up to 32 bits per character
ImageGrid of pixels. Each pixel has a binary value. Black & white: 1 bit per pixel. Colour: several bytes for R, G, B
AudioSound wave sampled at regular intervals. Each sample’s amplitude → binary number. Higher sampling rate and bit depth = better quality
VideoSequence of image frames + synchronised audio samples

Chapter 2 : Overview of Computer Architecture – Definition, History, Evolution

2.1 Computer Architecture

Definition

  • Computer architecture = a specification describing how computer software and hardware connect and interact to form a system
  • Defines the structure and function of components – CPU, memory, I/O devices, storage
  • Decides which technologies are compatible with the computer system
ArchitectureOrganization (textbook point)
Attributes visible to the programmer – instruction set, data type bits, I/O mechanism, addressingHow it is built – control signals, interfaces, memory technology

Importance

  • Essential for computer scientists and technology enthusiasts
  • Foundation for designing innovative and efficient computing solutions
  • Lets programmers write optimised software that uses the full power of the computer

Impact of design decisions

  • Strongly affects processing speed and overall performance
  • Affects energy efficiency – critical for modern devices and large systems
  • Key role in advanced applications – from web software to large language models (LLMs)

Three main pillars of computer architecture

PillarMeaning
1. System DesignOverall structure of the hardware – CPU, data processors, multiprocessors, memory controllers, DMA. How hardware parts connect and coordinate to execute instructions efficiently
2. Instruction Set Architecture (ISA)Interface between software and hardware. Specifies CPU functions, capabilities and the instructions it can execute. Defines data formats, processor register types, instruction types. Crucial for software compatibility and performance
3. MicroarchitectureImplementation of the ISA inside the CPU. Data paths, execution units, pipeline design, cache structure, storage. How ALU, registers and caches work together

Four main types of computer architecture

  • Fundamentals stay the same despite rapid advances. Types: 1 Von Neumann, 2 Harvard, 3 Modified Harvard, 4 RISC & CISC
TypeKey points
Von NeumannSingle shared memory for data and instructions. Fetched sequentially. Easy program modification. Von Neumann bottleneck – CPU cannot fetch instruction and data at the same time. Modern CPUs use caching and pipelining to reduce it. Introduced stored-program computers
HarvardSeparate memory and pathways for instructions and data. Simultaneous access → better performance for data-intensive tasks. Instruction memory can be read-only; data memory is optimised for read/write speed. More complex and costlier
Modified HarvardHybrid of the two. Separate instruction and data caches but one shared (unified) main memory. Simultaneous access with simpler design. Common in most modern processors
RISC (Reduced Instruction Set Computing)Simple, fixed-length instructions, usually one clock cycle. Hardware efficiency, faster clock, low power. E.g. ARM (smartphones, tablets), MIPS (embedded)
CISC (Complex Instruction Set Computing)Large variety of instructions, including complex multi-operation ones. May take multiple cycles. Fewer instructions for the programmer to write. E.g. Intel x86 (most PCs), Motorola 68000 (older Apple computers)

1st generation – Vacuum tubes (1940–1956)

  • Huge, heavy, hot, high power use; handled only small amounts of data. Many failures and reliability problems
  • Established electronic digital computing and binary maths; set the base for stored-program architecture and the shift to transistors
  • ENIAC – by J.P. Eckert and J.W. Mauchly; first successful electronic computer
Advantages
  • Calculates in milliseconds
  • Vacuum tubes were the only electronic parts available
Disadvantages
  • Size and weight – 30 tons
  • Magnetic drums store little data
  • Low work efficiency
  • Large energy use

2nd generation – Transistors (1956–1963)

  • Transistors replaced vacuum tubes – smaller, faster, more dependable, power-efficient. Computing spread to many industries
Advantages
  • Less heat than 1st generation
  • Lower cost
  • Faster – microseconds
  • Smaller size
Disadvantages
  • Needs cooling system and constant maintenance
  • Used for specific purposes only

3rd generation – Integrated Circuits (1964–1971)

  • Many transistors on one chip – higher capacity, much smaller size, cost and power. Smaller, quicker, more dependable computers; new uses in industry, government, education
  • IC invented by Robert Noyce and Jack Kilby (1958–59)
Advantages
  • Fast and reliable, cheaper, smaller
  • Big storage capacity
  • Time down from microseconds to nanoseconds
Disadvantages
  • IC chips hard to maintain
  • Air conditioning needed
  • Very advanced technology needed to make ICs

4th generation – Microprocessor (1971–present)

  • Major CPU functions on a single chip. Made strong, portable, affordable computers – embedded systems, smartphones, laptops, PCs
  • A microprocessor executes any logical and mathematical function of software
Advantages
  • Negligible heat
  • Less maintenance
  • Small size
  • High-level languages can be used
Disadvantages
  • Advanced technology needed to make microprocessors
  • Air conditioning often needed
  • Complicated design and production

5th generation – Artificial Intelligence (2010 onwards)

  • Progress in machine learning, neural networks, natural language processing – language translation, image identification, independent decision-making
  • Goal: a device that responds to natural language, learns and self-organises
  • Uses ULSI (Ultra Large Scale Integration) – about 10 million electronic components in microprocessor chips
Advantages
  • Works faster
  • Unique features, different sizes
  • Multimedia features
  • User-friendly interfaces
Disadvantages (teacher’s notes)
  • Low-level languages needed
  • Over-use may dull human thinking

Chapter 3 : Von Neumann Architecture and its Components

3.1 Von Neumann Architecture

  • Von Neumann architecture = basic computer design proposed by mathematician John von Neumann in 1945
  • Based on the stored-program computer model – instructions and data share the same memory space
  • Underpins most modern computers
Input device→CPU
(Control Unit + Arithmetic/Logic Unit) ↕ Memory Unit→Output device

Benefits

  • Simplicity – one memory for instructions and data, simple design
  • Flexibility – programs stored like data, easy to modify
  • Ease of programming – versatile software without hardware change
  • Foundation of modern computing – scalable, general-purpose

Limitations

  • Von Neumann bottleneck – data and instructions share memory and bus, so CPU fetches them one after the other; limits throughput
  • Sequential processing – one instruction at a time
  • Memory latency – shared memory becomes a bottleneck under high demand
  • Energy efficiency – higher energy use than Harvard (separate paths)

3.2 Components of Von Neumann Architecture

ComponentDetails
Memory unitStores data and instructions in the same addressable space. Fast random access. Typically RAM
CPUCore unit that executes instructions. Has ALU (operations), Control Unit (CU) (manages execution) and registers: PC Program Counter, MAR Memory Address Register, MDR Memory Data Register, CIR Current Instruction Register, AC Accumulator
I/O devicesData entry and output with outside devices – keyboard, mouse, monitor, printer
BusesPathways for data and control signals: Data bus (carries data), Address bus (carries memory addresses), Control bus (carries control signals)

3.3 Central Processing Unit (CPU)

  • CPU = the brain of the computer – thinking, calculating, decision-making
  • Handles instructions for games, typing, videos. Installed in a socket on the motherboard
  • Tasks: maths calculations; running applications and games; coordinating input (keyboard, mouse) with output (screen); storing and retrieving data while processing

Main components of the CPU

Input unit→CONTROL UNIT
(clock circuit, latch circuit, reset circuit)↓ALU↕MEMORY UNIT
(registers, cache)↕Main memory→Output unit
ComponentWork
Control unitManages the CPU by sending signals – clock, hold, reset – to its parts. Makes all parts work together. E.g. synchronises data movement from cache to ALU
ALU (Arithmetic and Logic Unit)Arithmetic: add, subtract, multiply, divide. Logic: AND, OR, comparisons. Uses addition for all calculations – e.g. 2×3 = 2+2+2 = 6
Memory unitStores data and instructions. Old CPUs used registers; modern ones also have fast cache. CPU fetches from RAM, ROM or hard disk and keeps it in registers or cache
RegistersSmall, high-speed memory inside the CPU. Hold data, instructions and addresses being used. Types: general-purpose, instruction register, program counter
CacheFast temporary storage for most frequently used data and instructions. Cuts the time to fetch from slower main memory

Functions of the CPU (instruction cycle)

1 FETCH
data & instructions→2 DECODE
instructions→3 EXECUTE
commands→4 STORE
output↺
  • Fetch – CPU gets the instruction (binary numbers) from RAM
  • Decode – CPU interprets the instruction. The slide says “with the help of ALU”; in textbooks decoding is done by the control unit
  • Execute – the decoded instruction is carried out
  • Store – the result is stored in memory

Types of CPUs (by cores)

  • A core = a mini-CPU inside the main CPU. More cores → more tasks at once
Single-coreOldest, used in the 1970s. One task at a time – slow for modern apps
Dual-coreTwo cores, two tasks at once. Better multitasking (music while doing homework)
Quad-coreFour cores. Heavy tasks – video editing, modern games. Common today

Why is the CPU called the brain?

  • Thinks through and executes every task; processes instructions like the brain processes information
  • Controls and coordinates all hardware and software operations
  • Without the CPU the computer cannot function – “a lifeless box of parts”

How the CPU gets faster

Multiple coresMini-CPUs work on different tasks at the same time
Faster clockClock speed in GHz (e.g. 3.5 GHz) – how many instructions per second
Bigger cacheMore data stored close by – less waiting
PipeliningStarts the next instruction before the current one finishes – like a factory line

Advantages of CPU

  • Versatile – simple maths to complex games
  • Fast – billions of instructions per second
  • Multi-tasking with multi-core
  • Compatible with wide software
  • Precision and control
  • Widely available, cost-effective

Disadvantages of CPU

  • Heat – needs fans / cooling
  • High power consumption
  • Cost – e.g. Intel Core i9
  • Less efficient than GPU for massive parallel tasks (graphics, video editing)
  • Sequential processing limits speed

3.4 Memory in Von Neumann Architecture

  • Memory unit stores both instructions and data in the same physical memory – the defining feature
  • Organised as a memory hierarchy balancing speed, capacity and cost
LevelLocationSpeedSizeRole
RegistersInside CPUFastestSmall (e.g. 16–64 bits)Hold immediate operands and instructions
CacheClose to CPUVery fastSmallFrequently used data / instructions; reduces access time
Main memory (RAM)System memoryModerateLargerActive data and programs. SRAM – faster, used for cache. DRAM – slower, higher density, used for main memory
Secondary storageExternal drivesSlowestVery largePermanent storage. Non-volatile – hard drives, SSDs

How memory works in the cycle

  • CPU fetches instructions and data from the same memory through a shared bus
  • MAR holds the address to be accessed. MDR temporarily holds the data moving to / from memory
  • Shared memory and bus → instructions and data processed sequentially

3.5 Input / Output (I/O) Systems

  • I/O systems = components that let the computer communicate with the outside by accepting input and giving output – the interface between internal processing and the user / other devices
RoleDetails
Input devicesKeyboard, mouse, scanner, sensors – convert outside data into a form the computer can process
Output devicesMonitor, printer, speakers, actuators – present processed data to user or environment
Controlled by CPUThe control unit manages I/O by sending control signals and coordinating data movement between I/O devices and memory
Data transfer by busesData bus – actual data. Address bus – device or memory location. Control bus – signals like read / write to synchronise

Types of I/O interfaces

Memory-mapped I/ODevices get addresses inside the memory space. CPU reads / writes those addresses to talk to the device
Isolated I/ODevices have a separate address space. Needs special I/O instructions, different from memory instructions
  • Input operation: CPU sends a command to the input device (keyboard) → device sends data over the data bus to memory or CPU registers
  • Output operation: CPU sends data from memory to the output device (monitor)
  • Importance: extends the computer beyond internal calculation; user interaction, data storage / retrieval, communication with other systems
  • Link to bottleneck: I/O also shares the data and control buses, so heavy I/O adds to the Von Neumann bottleneck

Chapter 4 : Types of Computers

4.1 Types of Computers

  • Classified by size and data handling capability. Ten types:
TypeKey points
1 Super computerMost powerful and fastest. Very complex tasks – scientific research, weather forecasting, nuclear simulations, space exploration, cryptography. Very large, costly, needs air-conditioned rooms. Fugaku, IBM Blue Gene, Cray XT5
2 MainframeLarge, powerful. Used by big organisations (banks, government, insurance) to process huge data. Supports hundreds to thousands of users at once. Reliable, large memory, multitasking. IBM Z Series, Unisys ClearPath
3 Mini computerMid-sized: smaller / less powerful than mainframe, larger than PC. Used by small and medium businesses for dedicated tasks. Now largely replaced by small or mid-sized servers
4 WorkstationHigh-performance, for technical / scientific work – graphic design, 3D rendering, engineering simulation, software development. More powerful than a PC, less than servers and mainframes
5 Personal computer (PC)General-purpose, for individual use. Desktops, laptops, tablets, smartphones. Browsing, office work, gaming, multimedia
6 ServerProvides resources, data, services or programs to other computers over a network. Many users at once – hosting websites, managing email, data storage
7 AnalogProcesses continuous data (voltage, temperature), not discrete values. Rare today; used in specialised science and engineering to measure physical quantities
8 DigitalMost common. Processes discrete binary data (0s and 1s) using digital circuits and binary logic. PCs, servers, laptops
9 HybridCombines analog and digital. Processes both continuous and discrete data. Medical equipment (patient monitoring), space research
10 Tablets and smartphonesPortable microcomputers / personal computers. Touchscreen, wireless communication, apps – communication, entertainment, productivity

★ Key Observations

  • Hardware = touchable. Software = instructions, not physical
  • Computer works in the cycle: Input → Processing → Output → Storage
  • CD-ROM / DVD-ROM read only; -R write once; -RW rewritable
  • RAM is volatile; hard disk is non-volatile
  • System software is low-level, fast, less interactive. Application software is high-level, more interactive
  • All data inside a computer is only 0s and 1s
  • Generations are defined by technology: tube → transistor → IC → microprocessor → AI
  • Each generation: smaller, faster, cheaper, more reliable
  • ISA = software–hardware interface. Microarchitecture = how ISA is built
  • Von Neumann = shared memory; Harvard = separate memory; Modified Harvard = separate caches + shared main memory
  • RISC = simple, 1 cycle, low power; CISC = complex, multi-cycle, fewer instructions
  • Classification: by size (super, mainframe, mini, micro) and by data (analog, digital, hybrid)
  • Von Neumann = one memory for program and data; bottleneck = one bus
  • Caching and pipelining reduce the bottleneck
  • CPU parts: CU + ALU + memory unit (registers, cache)
  • Instruction cycle: Fetch → Decode → Execute → Store
  • MAR = address, MDR = data, PC = next instruction address
  • Memory: speed falls and size rises from registers → cache → RAM → secondary
