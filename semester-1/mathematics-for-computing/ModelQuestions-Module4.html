Q1

State the sum rule and the product rule of counting with examples. 3 marks ★★★★☆ Very important

Answer

  • Sum rule : if a task can be done in m ways or in n ways (and the two cannot happen together), then the total number of ways is m + n.
    Example : to go to college by bus (3 routes) or by train (2 routes) : 3 + 2 = 5 ways.
  • Product rule : if a task has two stages, done in m ways and then n ways, the total is m × n.
    Example : 4 shirts and 3 trousers give 4 × 3 = 12 outfits.

Key words : “or” → add, “and (then)” → multiply.

How to write it: Write both rules with a formula and one everyday example each.
Exam tip: Say clearly “or means add, and means multiply”.
Q2

Define factorial and permutation. Derive the formula for ⁿPᵣ. Find ⁸P₃. 3 marks ★★★★☆ Very important

Answer

Factorial : n! = n(n − 1)(n − 2) … 3 · 2 · 1, and 0! = 1.

A permutation is an arrangement of objects in which order matters. The number of arrangements of r objects chosen from n different objects is ⁿPᵣ.

Derivation : the 1st place can be filled in n ways, the 2nd in (n − 1), …, the r-th in (n − r + 1) ways. By the product rule : ⁿPᵣ = n(n − 1)…(n − r + 1) = n! / (n − r)!.

⁸P₃ = 8 × 7 × 6 = 336. Also ⁿPₙ = n!.

How to write it: Definitions → place-by-place argument → formula → numerical example.
Exam tip: Permutation means order matters : “arrange”, “words”, “seats”.
Q3

How many 5-letter words (without repetition of letters) can be formed from the letters of the word COMPUTE? 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

COMPUTE has 7 different letters. We choose 5 and arrange them, so order matters :

⁷P₅ = 7 × 6 × 5 × 4 × 3 = 2520

Place 1 : 7 ways, place 2 : 6, place 3 : 5, place 4 : 4, place 5 : 3. Answer : 2520 words.

How to write it: Count the letters → say “order matters” → ⁷P₅ → answer with a line of units.
Exam tip: This was asked in November 2025 (VIII (c)).
Q4

Find the number of arrangements of the letters of the word MISSISSIPPI. In how many arrangements are the 4 S’s together? 5 marks ★★★★☆ Very important

Answer

MISSISSIPPI has 11 letters : M × 1, I × 4, S × 4, P × 2. When some objects are alike, the number of arrangements is n! / (n₁! n₂! …).

11! / (4! · 4! · 2!) = 39916800 / (24 × 24 × 2) = 34650

S’s together : treat SSSS as one block. We now arrange 8 objects : M, I × 4, P × 2 and the block : 8! / (4! · 2!) = 40320 / 48 = 840.

How to write it: Count the letters and the repeats → formula n!/(n₁!n₂!…) → compute. For “together”, glue them as one block.
Exam tip: Write the repeats first : I = 4, S = 4, P = 2.
Q5

In how many ways can 6 people sit (i) in a row, (ii) around a circular table, (iii) in a row if two particular persons must sit together? 5 marks ★★★☆☆ Important

Answer

  • (i) Row : 6! = 720.
  • (ii) Circle : fix one person to remove rotations; arrange the other 5 : (6 − 1)! = 5! = 120.
  • (iii) Together : treat the two as one block. There are 5 objects, so 5! = 120 ways; the two can swap inside the block in 2! = 2 ways. Total = 120 × 2 = 240.
How to write it: One line for each part, showing the factorial and the value.
Exam tip: For circular arrangements, divide by n, i.e. (n − 1)!.
Q6

Define combination. Write the formula for ⁿCᵣ and its properties. Find ⁹C₃. 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

A combination is a selection in which order does not matter. ⁿCᵣ is the number of ways to choose r objects out of n. Since each selection of r objects can be arranged in r! ways, ⁿPᵣ = ⁿCᵣ · r!, so

ⁿCᵣ = n! / ( r! (n − r)! )

  • ⁿCᵣ = ⁿCₙ₋ᵣ
  • ⁿC₀ = ⁿCₙ = 1
  • ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ

⁹C₃ = (9 × 8 × 7) / (3 × 2 × 1) = 84.

How to write it: Definition → derive using ⁿPᵣ/r! → formula → properties → example.
Exam tip: Selection, committee, team, choose → combination.

Q8

A committee of 4 is to be formed from 5 men and 4 women. In how many ways can this be done (i) without restriction, (ii) with exactly 2 women, (iii) with at least 2 women? 5 marks ★★★★☆ Very important

Answer

  • (i) Choose 4 from 9 : ⁹C₄ = 126.
  • (ii) 2 women from 4 and 2 men from 5 : ⁴C₂ × ⁵C₂ = 6 × 10 = 60.
  • (iii) At least 2 women = 2 women + 3 women + 4 women : ⁴C₂·⁵C₂ + ⁴C₃·⁵C₁ + ⁴C₄·⁵C₀ = 60 + 4 × 5 + 1 = 60 + 20 + 1 = 81.

Check : 126 − (0 women : ⁵C₄ = 5) − (1 woman : ⁴C₁·⁵C₃ = 40) = 81 ✔.

How to write it: Name the groups (men, women) → ⁿCᵣ for each case → add the cases (or subtract the complement).
Exam tip: “At least” → add cases, or use the complement.
Q9

How many diagonals does a polygon with n sides have? Find it for a hexagon. How many handshakes occur among 10 people? 3 marks ★★★☆☆ Important

Answer

A polygon with n vertices has ⁿC₂ line segments joining the vertices. n of them are sides, so the diagonals = ⁿC₂ − n = n(n − 3)/2. For a hexagon : ⁶C₂ − 6 = 15 − 6 = 9.

Handshakes : each pair shakes hands once, so ¹⁰C₂ = (10 × 9)/2 = 45.

How to write it: Think “pairs” → ⁿC₂ → subtract the sides for diagonals.
Exam tip: “Pairs, handshakes, matches” are all ⁿC₂.
Q10

State the pigeonhole principle. Give two applications. 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

Pigeonhole principle : if n + 1 (or more) objects are placed in n boxes, then at least one box contains at least 2 objects.

Generalised form : if N objects are placed in k boxes, some box has at least ⌈N/k⌉ objects.

  • Among any 13 people, at least two were born in the same month (13 people, 12 months).
  • Among any 5 integers, two have the same remainder when divided by 4 (5 numbers, 4 possible remainders 0, 1, 2, 3).

Class of 100 students : at least ⌈100/12⌉ = 9 have a birthday in the same month.

How to write it: Statement → generalised form → two applications with the boxes and objects named.
Exam tip: Always say what the pigeons (objects) and the holes (boxes) are.
Q11

Solve using the pigeonhole principle : (i) How many cards must be drawn from a pack of 52 to be sure that at least 3 are of the same suit? (ii) Show that among any 11 integers, two have the same units digit. 5 marks ★★★★☆ Very important

Answer

(i) Boxes : 4 suits. To be sure of 3 cards of one suit, use the worst case : 2 cards of each suit (2 × 4 = 8 cards) with no suit having 3. The next (9th) card gives 3 of a suit. Answer : 9 cards. (Formula : ⌈N/4⌉ ≥ 3 ⇒ N ≥ 9.)

(ii) There are only 10 possible last digits 0, 1, …, 9 (boxes). With 11 integers (objects), two of them must have the same last digit.

How to write it: Name the boxes → apply the worst-case or the ⌈N/k⌉ formula → answer.
Exam tip: The worst-case method is easy : fill every box one short, then add one more.
Q12

State the principle of inclusion–exclusion for two and three sets. 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

|A ∪ B| = |A| + |B| − |A ∩ B|

|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |B ∩ C| − |A ∩ C| + |A ∩ B ∩ C|

Add the single sets, subtract the pairwise overlaps, add back the triple overlap. Example : 60 like tea, 50 like coffee, 30 like both. At least one : 60 + 50 − 30 = 80.

How to write it: Both formulas on separate lines → reason in one sentence → example.
Exam tip: Asked in November 2025 (I (f)). Write the signs carefully : + − − − + for three sets.
Q13

How many integers from 1 to 100 are divisible by 2, 3 or 5? How many are divisible by none of them? 5 marks ★★★★★ Must study

Answer

Let A, B, C be the numbers divisible by 2, 3, 5 respectively. |A| = ⌊100/2⌋ = 50, |B| = 33, |C| = 20.

  • |A ∩ B| = divisible by 6 = 16
  • |B ∩ C| = divisible by 15 = 6
  • |A ∩ C| = divisible by 10 = 10
  • |A ∩ B ∩ C| = divisible by 30 = 3

|A ∪ B ∪ C| = 50 + 33 + 20 − 16 − 6 − 10 + 3 = 74.

Divisible by none = 100 − 74 = 26.

How to write it: Define A, B, C → find each size using ⌊N/k⌋ → substitute in the formula → subtract from 100.
Exam tip: Divisible by both 2 and 3 means divisible by 6 (the LCM).
Q14

What is a recurrence relation? Give examples (Fibonacci, factorial) and explain order and initial conditions. 3 marks ★★★★☆ Very important

Answer

A recurrence relation gives each term of a sequence in terms of the earlier terms. It needs initial conditions to start. The order is the gap between the largest and smallest index used.

SequenceRecurrenceInitial value(s)
Factorialaₙ = n · aₙ₋₁a₀ = 1
Fibonacciaₙ = aₙ₋₁ + aₙ₋₂a₀ = 0, a₁ = 1 → 0, 1, 1, 2, 3, 5, 8, …
Arithmeticaₙ = aₙ₋₁ + da₀ given
Tower of Hanoiaₙ = 2aₙ₋₁ + 1a₁ = 1 → 1, 3, 7, 15, …

Solving a recurrence means finding a closed formula for aₙ.

How to write it: Definition → order and initial condition → table of 3–4 examples.
Exam tip: A first-order recurrence needs one initial value, second-order needs two.
Q15

Solve the recurrence relation aₙ = 3aₙ₋₁ + 2 with a₀ = 1. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

  1. Homogeneous part : aₙ = 3aₙ₋₁ gives aₙ = A · 3ⁿ.
  2. Particular solution : try aₙ = c. Then c = 3c + 2, so c = −1.
  3. General solution : aₙ = A · 3ⁿ − 1.
  4. Initial condition : a₀ = 1 gives A − 1 = 1, so A = 2.

aₙ = 2 · 3ⁿ − 1

Check : a₁ = 3(1) + 2 = 5 = 2·3 − 1 ✔; a₂ = 3(5) + 2 = 17 = 2·9 − 1 ✔; a₃ = 53 = 2·27 − 1 ✔.

How to write it: Homogeneous solution → particular solution → general solution → use a₀ → write the formula → check two terms.
Exam tip: Asked in November 2025 (VIII (b)). Always check a₁ and a₂.
Q16

Solve aₙ = 5aₙ₋₁ − 6aₙ₋₂ with a₀ = 1, a₁ = 0. 5 marks ★★★☆☆ Important

Answer

This is a second-order linear homogeneous recurrence. Try aₙ = rⁿ : r² = 5r − 6, so r² − 5r + 6 = 0 (characteristic equation), (r − 2)(r − 3) = 0, r = 2, 3.

General solution : aₙ = A · 2ⁿ + B · 3ⁿ.

  • n = 0 : A + B = 1
  • n = 1 : 2A + 3B = 0

From the first, A = 1 − B. Then 2 − 2B + 3B = 0, so B = −2 and A = 3.

aₙ = 3 · 2ⁿ − 2 · 3ⁿ

Check : a₂ = 5(0) − 6(1) = −6, and 3·4 − 2·9 = −6 ✔.

How to write it: Characteristic equation → roots → general form → two equations from a₀ and a₁ → solve → check a₂.
Exam tip: If the roots are equal (r), the form is (A + Bn)rⁿ.
Q17

The Tower of Hanoi : form the recurrence for the minimum number of moves for n discs and solve it. 3 marks ★★★☆☆ Important

Answer

To move n discs : move the top n − 1 discs to the spare peg (aₙ₋₁ moves), move the largest disc (1 move), then move the n − 1 discs back on top (aₙ₋₁ moves).

aₙ = 2aₙ₋₁ + 1, a₁ = 1

Solution : aₙ = A·2ⁿ + c with c = 2c + 1 ⇒ c = −1, and a₁ = 1 ⇒ 2A − 1 = 1 ⇒ A = 1. So aₙ = 2ⁿ − 1. For 3 discs : 7 moves; for 10 discs : 1023 moves.

How to write it: Explain the three moves → recurrence → solve → give an example value.
Exam tip: Always state the recurrence and the initial condition separately.
Q18

Define a graph, degree of a vertex and state the handshaking lemma. Verify it for a graph with edges ab, ac, ad, be, bf, ce, df. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A graph G = (V, E) has a set of vertices V and a set of edges E, each joining two vertices. The degree of a vertex is the number of edges meeting at it.

Handshaking lemma : Σ deg(v) = 2 |E|

Reason : every edge adds 1 to the degree of each of its two ends. So the number of odd-degree vertices is always even.

Vertexabcdef
Degree332222

Sum of degrees = 3 + 3 + 2 + 2 + 2 + 2 = 14 = 2 × 7 ✔. There are 7 edges.

How to write it: Definitions → lemma → list degrees → add → compare with 2|E|.
Exam tip: The sum of degrees is always even.

Q21

Define Euler path and Euler circuit. State the conditions for their existence with examples. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

An Euler path is a path that uses every edge exactly once. An Euler circuit is an Euler path that starts and ends at the same vertex.

Condition (connected graph)Result
All vertices have even degreeEuler circuit exists
Exactly two vertices have odd degreeEuler path exists (starts and ends at the odd vertices), no circuit
More than two odd verticesNo Euler path
How to write it: Two definitions → table of conditions (degrees) → two figures.
Exam tip: Euler is about edges. Count the odd-degree vertices first.
Q22

Do the Königsberg bridges have an Euler path? Test K₅ and K₄ for an Euler circuit. 3 marks ★★★☆☆ Important

Answer

Königsberg : 4 land areas with degrees 3, 3, 3 and 5 (the 7 bridges). All four degrees are odd, i.e. more than two odd vertices, so there is no Euler path : the walk crossing every bridge once is impossible.

K₅ (complete graph on 5 vertices) : every vertex has degree 4 (even), so K₅ has an Euler circuit. K₄ : every vertex has degree 3 (odd), 4 odd vertices, so no Euler path or circuit. In general Kₙ has an Euler circuit when n is odd.

How to write it: Find the degrees → count odd vertices → apply the rule.
Exam tip: Write the degrees of every vertex. The rule needs them.
Q23

Define Hamilton path and Hamilton circuit. How do they differ from Euler paths? Give examples. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A Hamilton path visits every vertex exactly once. A Hamilton circuit is a Hamilton path that returns to its starting vertex. It need not use all edges.

Sufficient condition (Dirac) : a simple graph with n ≥ 3 vertices in which every vertex has degree ≥ n/2 has a Hamilton circuit.

How to write it: Definitions → figure with the highlighted circuit → comparison table → Dirac’s condition.
Exam tip: Hamilton → vertices, Euler → edges. Write this in the first line.
Q24

Does K₄ have a Hamilton circuit? Find a Hamilton circuit in a graph with vertices 1–5 and edges 12, 23, 34, 45, 51, 13. Explain why a graph with a vertex of degree 1 has no Hamilton circuit. 3 marks ★★★☆☆ Important

Answer

K₄ (every pair joined) : 1 → 2 → 3 → 4 → 1 is a Hamilton circuit. ✔

Graph with edges 12, 23, 34, 45, 51, 13 : the circuit 1 → 2 → 3 → 4 → 5 → 1 uses all 5 vertices once and returns to 1. ✔ (The edge 13 is not used.)

A vertex of degree 1 has only one edge, so a circuit cannot enter and also leave it without repeating that edge. Hence such a graph has no Hamilton circuit.

How to write it: Write the vertex sequence → check that each vertex appears once and the end returns to the start.
Exam tip: Write the circuit as a vertex sequence ending at the start vertex.
Q25

Short answers : (a) Find ⁶P₂ and ⁶C₂. (b) State the pigeonhole principle in one line. (c) Define a simple graph. (d) What is the degree sum of a graph with 9 edges? 2 marks ★★☆☆☆ Good to know

Answer

(a) ⁶P₂ = 6 × 5 = 30, ⁶C₂ = 30/2 = 15. (b) If n + 1 objects are put in n boxes, some box has at least 2 objects. (c) A graph with no loops and no multiple edges. (d) 2 × 9 = 18.

How to write it: One line per part.
