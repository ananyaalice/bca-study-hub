Model Questions

Mathematics for Computing

119 model questions with exam-ready answers, module by module and chapter by chapter.

Every answer has simple sentences to write in the exam, a worked example (all calculations were checked by computer), a diagram or table where it helps, a “How to write it” box and an “Exam tip”.

Syllabus coverage: every topic of the 5 module notes is covered (73 topics). Each module page ends with a coverage check that links every topic to its questions. Module 2 also covers Relations and Functions with standard content, because the notes for that part are not added yet.

Importance stars: every question has a rating from ★☆☆☆☆ to ★★★★★. Questions marked “Asked in Nov 2025” have a topic that came in the November 2025 paper. Each module page starts with a priority list, so a student with little time can read the 5-star questions first. (46 must-study, 34 very important, 32 important, 7 good to know)

The mark label (2, 3 or 5) shows how long the answer should be. These are practice questions made from the syllabus. They are not official previous-year papers.
