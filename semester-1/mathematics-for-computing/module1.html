Chapter 1 : Propositions

1.1 What is a Proposition?

A proposition is a declarative sentence (a sentence that declares a fact) that is either true or false, but not both.

Example 1 : Propositions

No.StatementTruth value
1Trivandrum is the capital of Kerala.True
2Noida is the capital of India.False
31 + 1 = 2True
42 + 2 = 3False

Here 1 & 3 are true and 2 & 4 are false. All four are propositions, because each one is a statement that is either true or false.

Example 2 : NOT Propositions

No.SentenceWhy it is not a proposition
1What time is it?A question, not a declarative sentence
2Read this carefully.A command, not a declarative sentence
3x + 1 = 2Neither true nor false (depends on x)
4x + y = zNeither true nor false (depends on x, y, z)
  • Questions and commands are not propositions (not declarative).
  • Sentences with unknown variables are not propositions (neither true nor false).

1.2 Propositional Variables

  • Variables that represent propositions are called propositional variables (or sentential variables). Example: P, Q, R, S.
  • Truth value of a true proposition is denoted by T. Truth value of a false proposition is denoted by F.

1.3 Simple and Compound Propositions

(a) Simple (Atomic) Proposition

A statement that does not contain any logical connective (NOT, AND, OR, IF…THEN). It cannot be broken into simpler propositions.

  • 5 is a prime number. (True)
  • The Earth revolves around the Sun. (True)
  • 7 is an even number. (False)

(b) Compound Proposition

A proposition formed by combining two or more simple propositions using logical connectives.

Common logical connectives

Biconditional↔if and only if

(Exclusive OR ⊕ is also used – see Chapter 2.)

Example : using connectives

Let p : It is raining. q : I will carry an umbrella.

★ Key Point for Exams ★

Simple proposition : a single declarative statement with no logical connectives.
Compound proposition : formed by combining simple propositions using connectives such as NOT (¬), AND (∧), OR (∨), IF…THEN (→) or IF AND ONLY IF (↔).

Chapter 2 : Logical Operators

Logical operators (connectives) turn everyday words “not”, “and”, “or”, “if” into precise, testable rules. For n propositional variables a truth table has 2n rows (2 variables → 4 rows, 3 variables → 8 rows).

Example 9

Express “I will use all my savings to travel to Europe or to buy an electric car” in propositional logic.

  • p : “I will use all my savings to travel to Europe.”

2.5 Conditional Statement ( p → q ) – “if p then q”

Definition 5. Let p and q be propositions. The conditional statement p → q is the proposition “If p, then q”. It is false only when p is true and q is false, and true otherwise.

  • p is called the hypothesis (or antecedent or premise) – the condition being tested.
  • q is called the conclusion (or consequence) – what follows if the hypothesis holds.
pqp → q
TTT
TFF
FTT
FFT

Why is p → q TRUE when p is false?

Take: “If it rains, then the road is wet.” p : It rains. q : The road is wet.

  • p is false (it did not rain). The statement made no promise about what happens then.
  • Whether the road is wet (q true) or dry (q false), the promise has not been broken.
  • Since there is no violation, the statement is considered true. (Only “it rained but the road is NOT wet” breaks the promise.)

Ways of reading p → q : “if p then q”, “p implies q”, “p only if q”, “q if p”.

2.6 Biconditional ( p ↔ q ) – “if and only if”

Definition 6 (as numbered in the school slides). The biconditional p ↔ q is the proposition “p if and only if q”. It is true when p and q have the same truth value, and false when they differ.

pqp ↔ q
TTT
TFF
FTF
FFT

Example 10

p : “You can take the flight.” q : “You have a valid ticket.”
p ↔ q : “You can take the flight if and only if you have a valid ticket.”

  • Agreement, not causation : true when both are true or both are false.
  • Difference from →: the conditional allows one “false pairing” (T,F); the biconditional rules out two (T,F and F,T) – it needs agreement in both directions at once.
  • p ↔ q has the same meaning as (p → q) ∧ (q → p).

★ Key Observations ★

  • ∧ has exactly one T row (T,T). ∨ has exactly one F row (F,F).
  • → has exactly one F row (T,F). ↔ is true on rows T,T and F,F.
  • ⊕ is the opposite of ↔ (p ⊕ q ≡ ¬(p ↔ q)).
  • Adding more terms with ∧ can only keep a statement true or make it false, never the reverse.

Chapter 3 : Contrapositive of a Statement

Definition 6 (as numbered in the school notes). The contrapositive of a conditional statement is formed by negating both the hypothesis and the conclusion, and then interchanging them.

Rule

  • Original : If p, then q (symbolically p → q)
  • Contrapositive : If not q, then not p (symbolically ¬q → ¬p)

Steps to find the contrapositive

1. Identify p and q→2. Negate both : ¬p, ¬q→3. Swap : ¬q → ¬p

Truth table proof

PQP → Q¬P¬Q¬Q → ¬P
TTTFFT
TFFFTF
FTTTFT
FFTTTT

Columns P → Q and ¬Q → ¬P are identical in every row ⇒ P → Q ≡ ¬Q → ¬P.

Examples

Example 1

Statement : If it rains, then the ground is wet.
P : It rains. Q : The ground is wet.
Contrapositive : If the ground is not wet, then it did not rain.

Example 2

Statement : If a number is divisible by 5, then its last digit is 0 or 5.
P : A number is divisible by 5. Q : Its last digit is 0 or 5.
Contrapositive : If a number’s last digit is not 0 or 5, then it is not divisible by 5.

★ Important Property ★

The original statement and its contrapositive are logically equivalent – they always have the same truth value.

Chapter 4 : Logical Equivalence

Two propositions are logically equivalent if they have the same truth value for every possible assignment of truth values to their component propositions. If P and Q are logically equivalent we write P ≡ Q.

Examples

  • Contrapositive : P → Q ≡ ¬Q → ¬P (identical truth tables).
  • De Morgan’s Law : ¬(P ∧ Q) ≡ ¬P ∨ ¬Q.

Key Points

  • Logically equivalent propositions have identical truth tables.
  • They may be written differently but carry the same logical meaning.
  • Logical equivalence is represented by the symbol ≡.

Method : checking equivalence with a truth table

List all rows (2ⁿ)→Work out each part column by column→Compare the two final columns→Same in every row ⇒ ≡

Chapter 5 : Tautologies and Contradictions

5.1 Tautology

A tautology is a compound proposition that is true for every possible combination of truth values of its component propositions. The final column of its truth table contains only T. Symbolically : P ≡ T.

Example : P ∨ ¬P

A contradiction is a compound proposition that is false for every possible combination of truth values of its component propositions. The final column of its truth table contains only F. Symbolically : P ≡ F.

Chapter 6 : Predicates and Quantifiers

6.1 Predicates

A predicate is a statement that contains one or more variables and becomes a proposition (true or false) when specific values are assigned to the variables or when the variables are quantified. A predicate is also called a propositional function.

General form

P(x) where P denotes the predicate and x is the variable.

Examples

PredicateAssigned valueResult
P(x) : x > 5P(8)True
P(x) : x > 5P(3)False
Q(x) : x is an even numberQ(6)True
Q(x) : x is an even numberQ(9)False
R(x, y) : x + y = 10R(4, 6)True
R(x, y) : x + y = 10R(3, 5)False

6.2 Open Sentence

A predicate is also called an open sentence, because its truth value cannot be determined until values are assigned to its variables or the variables are quantified.

Example : P(x) : x + 2 = 7 is not a proposition, because its truth value depends on the value of x. (True only for x = 5.)

6.3 Quantifiers

A quantifier is a symbol used in predicate logic to indicate how many elements of the domain satisfy a predicate. Quantifiers convert predicates into propositions by saying whether the predicate is true for all elements or for at least one element of the domain.

There are two basic quantifiers : Universal (∀) and Existential (∃).

1. Universal quantifier ( ∀ )

  • Means “for all” or “for every”. States that a predicate is true for every element in the domain.
  • General form : ∀x P(x) – read “For every x, P(x) is true.”
  • Example : Domain = natural numbers, P(x) : x + 0 = x. Then ∀x P(x). Meaning : every natural number remains unchanged when 0 is added.

2. Existential quantifier ( ∃ )

  • Means “there exists” or “there is at least one”. States that a predicate is true for at least one element in the domain.
  • General form : ∃x P(x) – read “There exists an x such that P(x) is true.”
  • Example : Domain = integers, P(x) : x² = 25. Then ∃x P(x). Meaning : there exists an integer whose square is 25 (namely x = 5 or x = −5).

6.4 Quantified Statements : English → Symbols

English statementSymbolic form
Every student passed the exam.∀x P(x)
Some students passed the exam.∃x P(x)
Every square has four sides.∀x S(x)
There exists a prime number that is even.∃x E(x)

Pattern : “every / all” → ∀; “some / there exists / at least one” → ∃.

6.5 Negation of Quantifiers

StatementNegationMeaning
∀x P(x)∃x ¬P(x)There exists at least one element for which P(x) is false.
∃x P(x)∀x ¬P(x)P(x) is false for every element.

Rule : to negate a quantified statement, flip the quantifier (∀ ↔ ∃) and negate the predicate.

Examples

Example 1

Original : ∀x (x > 0)
Negation : ∃x (x ≤ 0)

Example 2

Original : ∃x (x² = 16)
Negation : ∀x (x² ≠ 16)

Summary

  • A predicate is an open statement containing variables whose truth value depends on the values assigned to those variables.
  • A quantifier specifies whether a predicate is true for all elements or for at least one element in a given domain.
  • The universal quantifier (∀) means “for all”.
  • The existential quantifier (∃) means “there exists”.
  • Quantifiers transform predicates into propositions with definite truth values.

Chapter 7 : Rules of Inference

A rule of inference is a logically valid pattern that allows a new true statement (the conclusion) to be derived from one or more accepted true statements (the premises). Each rule guarantees that if the premises are true, the conclusion must also be true. Rules of inference are the individual valid “steps” used to build a formal logical proof.

Premises (known true)→Rule of inference→Conclusion (must be true)

Notation : the statements above the line are the premises, the statement below the line is the conclusion, and ∴ means “therefore”.

1. Modus Ponens (Law of Detachment)

p → q
p
∴ q

If p implies q, and p is true, then q is true.

Examples

  • If it rains, the ground is wet. It is raining. Therefore, the ground is wet.
  • Premise 1 : If a polygon is a square, then it has four sides. Premise 2 : Shape A is a square. Conclusion : Shape A has four sides.

2. Modus Tollens (Law of Contrapositive)

p → q
¬q
∴ ¬p

If p implies q, and q is false, then p must be false.

Examples

  • If it rains, the ground is wet. The ground is not wet. Therefore, it is not raining.
  • Premise 1 : If it is snowing outside, then the temperature is at or below 0 °C. Premise 2 : The temperature is not at or below 0 °C. Conclusion : Therefore, it is not snowing outside.

3. Hypothetical Syllogism

p → q
q → r
∴ p → r

Two implications can be chained together.

Examples

  • If I study, I pass. If I pass, I graduate. Therefore, if I study, I graduate.
  • Premise 1 : If a shape is a square, then it is a rectangle. Premise 2 : If a shape is a rectangle, then it is a parallelogram. Conclusion : If a shape is a square, then it is a parallelogram.

4. Disjunctive Syllogism

p ∨ q
¬p
∴ q

If either p or q is true, and p is false, then q must be true.

Examples

  • I will study Mathematics or Statistics. I will not study Mathematics. Therefore, I will study Statistics.
  • It is Monday or Tuesday. It is not Monday. So, it is Tuesday.

5. Addition

p
∴ p ∨ q

If p is true, then “p or q” is true.

Examples

  • I study Mathematics. Therefore, I study Mathematics or Physics.
  • It is raining. So, it is raining or snowing.

6. Simplification

p ∧ q
∴ p

If both p and q are true, then p is true.

Examples

  • I study Mathematics and Statistics. Therefore, I study Mathematics.
  • It is raining and cold. So, it is raining.

7. Conjunction

p
q
∴ p ∧ q

If both p and q are true, they can be combined.

Examples

  • I study Mathematics. I study Statistics. Therefore, I study Mathematics and Statistics.
  • It is raining. It is cold. So, it is raining and cold.

8. Resolution

p ∨ q
¬p ∨ r
∴ q ∨ r

Combining two disjunctions with complementary terms eliminates p.

Examples

  • Premise 1 : It is raining (p) or I will stay home (q). Premise 2 : It is not raining (¬p) or I will bring an umbrella (r). Conclusion : I will stay home (q) or I will bring an umbrella (r). (The complementary pair “raining / not raining” cancels out.)
  • I run or walk. I don’t run or I get tired. So, I walk or get tired.

A rule is valid when ((p → q) ∧ p) → q is a tautology:

★ Easy way to remember ★

  • Ponens “affirms” p → gives q. Tollens “denies” q → gives ¬p.
  • Hypothetical Syllogism = chain (p→q, q→r gives p→r).
  • Disjunctive Syllogism = knock one side of OR out, the other remains.
  • Addition adds a new term with ∨. Simplification drops a term from ∧. Conjunction joins two with ∧.
  • Resolution : p and ¬p cancel out.

Chapter 8 : Direct and Indirect Proofs

8.1 What is a Proof?

A proof is a logical argument that establishes the truth of a mathematical statement beyond doubt.

  • It starts from accepted truths : definitions, axioms, previously proven results (theorems).
  • It uses only valid logical steps (rules of inference); each line follows necessarily from the last.
  • It ends in certainty – the conclusion is shown to be unavoidable. (∎ marks the end of a proof.)

8.2 Two Paths to the Same Truth

To prove a statement of the form “if p, then q” (p → q) we can take a direct route (start from p and reason forward to q) or an indirect route (prove the same statement by working with its negation). Both are equally valid; the choice depends on which path is easier.

8.3 Direct Proof

To prove P → Q directly, assume P is true and use definitions, axioms, known facts and logical steps to show that Q must also be true.

Assume P→Apply reasoning (definitions, algebra, theorems)→Arrive at Q

Best when the forward path from hypothesis to conclusion is short and clear.

Worked Example : If n is an even integer, then n² is even.

  • Assume the hypothesis : let n be an even integer.
  • Definition of even : n = 2k for some integer k.
  • Substitute : n² = (2k)² = 4k² = 2(2k²).
  • Recognise the form : 2k² is an integer, so n² = 2 × (an integer).
  • Conclusion : n² is even. ∎

8.4 Indirect Proof

An indirect proof establishes P → Q without a direct chain from P to Q. Two common forms : proof by contrapositive and proof by contradiction. Use them when reasoning forward is awkward.

8.4.1 Proof by Contrapositive

The contrapositive of “p → q” is “¬q → ¬p”; the two are logically equivalent, so proving one proves the other. Useful when assuming q is false gives more to work with than assuming p is true.

State ¬Q → ¬P→Assume ¬Q→Reason forward→Reach ¬P

Worked Example : If n² is even, then n is even.

  • State the contrapositive : if n is odd, then n² is odd.
  • Assume the new hypothesis : let n be odd, so n = 2k + 1 for some integer k.
  • Reason forward : n² = (2k+1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd.
  • Conclude : the contrapositive holds, so the original statement holds. ∎

8.4.2 Proof by Contradiction

Assume the statement to be proved is false (i.e. assume P is true and Q is false), then show this assumption leads to a logical impossibility. Since the assumption cannot hold, the original statement must be true. Good for “no such thing exists” claims.

Assume the opposite→Manipulate the assumption→Reach a contradiction→So the claim is true

Worked Example : √2 is irrational.

  • Assume the opposite : suppose √2 is rational, √2 = a/b with a, b integers and no common factor (lowest terms).
  • Manipulate : squaring gives 2 = a²/b², so a² = 2b². Hence a² is even, so a is even.
  • Push further : write a = 2c. Then 2b² = 4c², so b² = 2c², hence b² is even and b is even too.
  • Contradiction : both a and b are even, but we assumed they have no common factor. Impossible!
  • So √2 cannot be rational; √2 is irrational. ∎

★ Key Takeaways ★

  • Direct proof reasons forward : assume the hypothesis, follow logical steps to the conclusion.
  • Contrapositive flips the claim : P → Q and ¬Q → ¬P are always equally true – pick whichever is easier.
  • Contradiction assumes the opposite : show that denying the claim breaks logic, so the claim must hold.
  • Let the shape of the statement decide the strategy. Every proof is a choice of route – the destination (certainty) is the same.

Important Terms

  • Proposition – true-or-false declarative sentence
  • Propositional variable – P, Q, R…
  • Truth value – T or F
  • Simple / atomic – no connectives
  • Compound – built using connectives
  • Connective – ¬ ∧ ∨ ⊕ → ↔
  • Hypothesis / antecedent – p in p → q
  • Conclusion / consequence – q in p → q
  • Contrapositive – ¬q → ¬p
  • Logical equivalence – same truth table (≡)
  • Tautology – always true
  • Contradiction – always false
  • Predicate / propositional function / open sentence – P(x)
  • Quantifier – ∀ (for all), ∃ (there exists)
  • Domain – set of values x may take
  • Rule of inference – valid reasoning pattern
  • Direct proof, contrapositive proof, proof by contradiction

★ Exam Points ★

  • Proposition = declarative sentence, true or false, not both. Questions, commands and sentences with unknown x are not propositions.
  • ∧ true only for T,T. ∨ false only for F,F. ⊕ true when exactly one is true. → false only for T,F. ↔ true when both are the same.
  • Truth table with n variables has 2ⁿ rows.
  • p → q ≡ ¬q → ¬p (contrapositive) ≡ ¬p ∨ q. The converse q → p is not equivalent.
  • De Morgan : ¬(p ∧ q) ≡ ¬p ∨ ¬q ; ¬(p ∨ q) ≡ ¬p ∧ ¬q.
  • Tautology : final column all T (P ≡ T). Contradiction : final column all F (P ≡ F).
  • Predicate P(x) is not a proposition until x is assigned a value or quantified.
  • ¬∀x P(x) ≡ ∃x ¬P(x) and ¬∃x P(x) ≡ ∀x ¬P(x).

  • Proofs : direct (assume P ⇒ Q), contrapositive (assume ¬Q ⇒ ¬P), contradiction (assume the claim false ⇒ absurdity). Standard examples : n even ⇒ n² even; n² even ⇒ n even; √2 irrational.
