Q1

Define a matrix. Explain the types of matrices : row, column, square, diagonal, scalar, identity, zero, symmetric and skew-symmetric. 5 marks ★★★☆☆ Important

Answer

A matrix is a rectangular arrangement of numbers in m rows and n columns. Its order is m × n.

TypeMeaningExample
Row matrix1 row[1 2 3]
Column matrix1 column123
Square matrixm = n1234
Diagonal matrixsquare, non-diagonal entries are 02005

SymmetricAᵀ = A1223
Skew-symmetricAᵀ = −A (diagonal is 0)02-20

Exam tip: Give an example for every type. A small 2 × 2 example is enough.
Q2

Explain the matrix operations (addition, scalar multiplication, multiplication) with examples. Show that matrix multiplication is not commutative. 5 marks ★★★★☆ Very important

Answer

Let A = 1234 and B = 0152.

  • Addition (same order, add entries) : A + B = 1386
  • Scalar multiplication : 2A = 2468
  • Multiplication (row × column; the number of columns of the first = rows of the second) : AB = 1052011 (e.g. entry (1,1) = 1·0 + 2·5 = 10)

BA = 341118. Since AB ≠ BA, matrix multiplication is not commutative. It is associative : (AB)C = A(BC).

How to write it: Write A and B → show each operation with the result → compute both AB and BA to compare.
Exam tip: Show one entry of AB in full. It proves you know the row-by-column rule.
Q3

Define the transpose of a matrix. State its properties and verify (AB)ᵀ = BᵀAᵀ. 3 marks ★★★☆☆ Important

Answer

The transpose Aᵀ is obtained by interchanging rows and columns. Properties : (Aᵀ)ᵀ = A, (A + B)ᵀ = Aᵀ + Bᵀ, (kA)ᵀ = kAᵀ, (AB)ᵀ = BᵀAᵀ.

With the A, B above : (AB)ᵀ = 1020511 and BᵀAᵀ = 1020511. They are equal ✔.

How to write it: Definition → four properties → numerical verification.
Exam tip: Notice the order reverses in (AB)ᵀ.
Q4

Define the determinant of a 2 × 2 and a 3 × 3 matrix. Find the determinant of [[3, 2], [1, 4]]. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

For a 2 × 2 matrix, |a b ; c d| = ad − bc.

For a 3 × 3 matrix, expand along the first row : |A| = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁).

Example 1 : 3214 : det = (3)(4) − (2)(1) = 12 − 2 = 10.

Example 2 : 201132111 : det = 2(3·1 − 2·1) − 0(1·1 − 2·1) + 1(1·1 − 3·1) = 2(1) − 0 + 1(−2) = 0.

How to write it: Formula for 2 × 2 and for 3 × 3 (cofactor expansion) → one numerical example of each.
Exam tip: Asked in November 2025 (I (h)). Show the substitution before the answer.
Q5

State the properties of determinants. 3 marks ★★★☆☆ Important

Answer

  • |Aᵀ| = |A|.
  • Interchanging two rows changes the sign of the determinant.
  • If two rows (or columns) are identical or proportional, the determinant is 0.
  • If a row is multiplied by k, the determinant is multiplied by k. So |kA| = kⁿ|A| for an n × n matrix.
  • Adding a multiple of one row to another row does not change the determinant.
  • |AB| = |A| |B|.
  • The determinant of a triangular matrix is the product of its diagonal entries.
  • A square matrix is invertible exactly when |A| ≠ 0.
How to write it: List 5–6 properties, one line each.
Exam tip: The property “two proportional rows ⇒ det = 0” is used to find rank and singularity quickly.
Q6

Define singular and non-singular matrices. Find the inverse of A = [[2, 1], [5, 3]] using the adjoint. 5 marks ★★★★★ Must study

Answer

A square matrix is singular if |A| = 0 and non-singular if |A| ≠ 0. The inverse exists only for a non-singular matrix : A⁻¹ = adj(A) / |A|. For a 2 × 2 matrix [a b ; c d], adj = [d −b ; −c a].

A = 2153 : |A| = 2·3 − 1·5 = 1 ≠ 0.

adj A = 3-1-52, so A⁻¹ = 3-1-52.

Check : A A⁻¹ = 1001 = I ✔.

How to write it: Condition |A| ≠ 0 → adjoint → A⁻¹ = adj A / |A| → check AA⁻¹ = I.
Exam tip: Always verify the inverse by multiplication. It takes 30 seconds.
Q7

Find the inverse of [[1, 2, 3], [0, 1, 4], [5, 6, 0]] using row operations (Gauss–Jordan method). 5 marks ★★★★☆ Very important

Answer

Write [A | I] and use row operations to change A into I. The right part then becomes A⁻¹.

|A| = 1 ≠ 0, so the inverse exists.

  1. R₃ → R₃ − 5R₁ : 1231000140100-4-15-501
  2. R₁ → R₁ − 2R₂ and R₃ → R₃ + 4R₂ : 10-51-20014010001-541
  3. R₁ → R₁ + 5R₃ and R₂ → R₂ − 4R₃ : 100-2418501020-15-4001-541

A⁻¹ = -2418520-15-4-541.

How to write it: Write [A | I] → row operations step by step → read A⁻¹ from the right side → verify.
Exam tip: Do one operation per step and write it beside the matrix.
Q8

Define the rank of a matrix and echelon form. How is the rank found? 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

The rank of a matrix is the maximum number of linearly independent rows (equal to the number of independent columns).

A matrix is in row echelon form if : (i) zero rows are at the bottom, (ii) the first non-zero entry (leading entry) of each row is to the right of the leading entry of the row above it.

Method : reduce the matrix to echelon form using row operations; rank = number of non-zero rows. Row operations do not change the rank. For an m × n matrix, rank ≤ min(m, n).

How to write it: Definition → echelon-form rules → the method in one line.
Exam tip: Asked in November 2025 (I (i), X (a)). Always say “rank = number of non-zero rows in echelon form”.
Q9

Find the rank of (i) [[1, 2, 3], [2, 4, 6], [1, 1, 1]] (ii) [[1, 0], [0, 0]]. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

(i) A = 123246111.

  1. R₂ → R₂ − 2R₁ gives (0, 0, 0).
  2. R₃ → R₃ − R₁ gives (0, −1, −2).
  3. Swap R₂ and R₃.

Echelon form : 1230-1-2000. Two non-zero rows, so rank = 2. (det A = 0, so rank < 3 ✔.)

(ii) 1000 is already in echelon form with one non-zero row, so rank = 1.

How to write it: Row operations step by step → echelon form → count non-zero rows.
Exam tip: Check with the determinant : det = 0 means rank is less than the order.
Q10

Reduce the matrix [[1, 2, 1, 3], [2, 4, 3, 7], [3, 6, 4, 10]] to echelon form and find its rank. 5 marks ★★★★☆ Very important

Answer

A = 1213243736410

  1. R₂ → R₂ − 2R₁, R₃ → R₃ − 3R₁ : 121300110011
  2. R₃ → R₃ − R₂ : 121300110000

Two non-zero rows, so rank(A) = 2.

How to write it: Eliminate below the first leading entry → continue with the next column → count non-zero rows.
Exam tip: If a column of zeros appears, move to the next column and continue.
Q11

Solve by Gaussian elimination : x + y + z = 6, 2x + 3y + 7z = 20, 3x + 4y + 10z = 27. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Augmented matrix [A | B] = 111623720341027

  1. R₂ → R₂ − 2R₁, R₃ → R₃ − 3R₁ : 111601580179
  2. R₃ → R₃ − R₂ : 111601580021

Back substitution : 2z = 1 ⇒ z = 1/2; y + 5z = 8 ⇒ y = 11/2; x + y + z = 6 ⇒ x = 0.

x = 0, y = 11/2, z = 1/2

Check in equation 2 : 0 + 3(11/2) + 7(1/2) = 16.5 + 3.5 = 20 ✔. The ranks of A and [A | B] are both 3, so the solution is unique.

How to write it: Augmented matrix → forward elimination to echelon form → back substitution → check.
Exam tip: Asked in November 2025 (X (b)). Write each row operation.
Q12

State the condition for consistency of a system AX = B (rank method). Discuss the system x + y + z = 3, x + 2y + 3z = 6, x + 3y + 5z = k for different values of k. 5 marks ★★★★★ Must study

Answer

Rank condition : let ρ(A) be the rank of the coefficient matrix and ρ([A | B]) the rank of the augmented matrix; n = number of unknowns.

ConditionResult
ρ(A) ≠ ρ([A | B])No solution (inconsistent)
ρ(A) = ρ([A | B]) = nUnique solution
ρ(A) = ρ([A | B]) < nInfinitely many solutions

Example : [A | B] = 11131236135k. R₂ − R₁, R₃ − R₁ : 11130123024k − 3. R₃ − 2R₂ : 11130123000k − 9

  • k ≠ 9 : ρ(A) = 2, ρ([A | B]) = 3, so no solution.
  • k = 9 : ρ(A) = ρ([A | B]) = 2 < 3, so infinitely many solutions (one free variable : z = t, y = 3 − 2t, x = t).
How to write it: Table of the three cases → reduce [A | B] → discuss each value of k.
Exam tip: Look at the last row (0 0 0 | k − 9). It decides everything.
Q13

Solve 2x + y = 5, x + 3y = 5 by Cramer's rule and by the matrix inverse method. 3 marks ★★★☆☆ Important

Answer

A = 2113, |A| = 6 − 1 = 5 ≠ 0.

Cramer's rule : x = |Aₓ| / |A|, y = |A_y| / |A|, where the column of x (or y) is replaced by the right-hand side.

|Aₓ| = 5·3 − 1·5 = 10, |A_y| = 2·5 − 5·1 = 5. So x = 10/5 = 2, y = 5/5 = 1.

Inverse method : X = A⁻¹B, A⁻¹ = (1/5)3-1-12, X = (1/5)(3·5 − 5, −5 + 2·5)ᵀ = (2, 1)ᵀ ✔.

How to write it: Compute |A| → replace columns → divide → check with the inverse method.
Exam tip: Cramer’s rule works only when |A| ≠ 0.
Q14

Define a vector space. Write its axioms and give examples. 5 marks ★★★★☆ Very important

Answer

A vector space V over a field F (usually ℝ) is a set with vector addition and scalar multiplication satisfying :

  1. Addition : closed, commutative (u + v = v + u), associative, has a zero vector 0, and every v has a negative −v.
  2. Scalar multiplication : closed (cv ∈ V).
  3. Distributive laws : c(u + v) = cu + cv and (c + d)v = cv + dv.
  4. Associative and identity : (cd)v = c(dv) and 1·v = v.

Examples : ℝⁿ, the set of m × n matrices, the set of polynomials of degree ≤ n, the set of all real functions.

How to write it: Definition → axioms in two groups (addition, scalar multiplication) → three examples.
Exam tip: You need not write all ten axioms in detail. Group them as above.
Q15

Define a subspace. Determine whether (i) Z = {(x, y, z) : z = xy} and (ii) Q = {(x, y, z) : z = x + y} are subspaces of ℝ³. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A non-empty subset W of a vector space V is a subspace if (a) u + v ∈ W and (b) cu ∈ W for all u, v ∈ W and scalars c (so 0 ∈ W).

(i) Z : z = xy – not a subspace

u = (1, 1, 1) ∈ Z (1 = 1·1). But 2u = (2, 2, 2) ∉ Z since 2 ≠ 2·2 = 4. So Z is not closed under scalar multiplication.

(ii) Q : z = x + y – a subspace

  1. (0, 0, 0) ∈ Q. ✔
  2. u = (x₁, y₁, x₁ + y₁), v = (x₂, y₂, x₂ + y₂) ⇒ u + v = (x₁ + x₂, y₁ + y₂, (x₁ + x₂) + (y₁ + y₂)) ∈ Q. ✔
  3. cu = (cx₁, cy₁, c(x₁ + y₁)) = (cx₁, cy₁, cx₁ + cy₁) ∈ Q. ✔

Q is the plane z = x + y through the origin, with basis (1, 0, 1), (0, 1, 1).

How to write it: Subspace test → check each set separately → a counter-example for the one that fails, three steps for the one that holds.
Exam tip: Asked in November 2025 (XI (b)). Try the zero vector and scalar 2 first.
Q16

Define linear combination, span and linear independence. Test whether (1, 2, 3), (2, 4, 6), (1, 0, 1) are linearly independent. 5 marks ★★★★☆ Very important

Answer

A linear combination of v₁, …, vₖ is c₁v₁ + … + cₖvₖ. Their span is the set of all linear combinations. The vectors are linearly independent if c₁v₁ + … + cₖvₖ = 0 forces all cᵢ = 0; otherwise they are dependent.

Here (2, 4, 6) = 2(1, 2, 3), so 2·(1, 2, 3) − 1·(2, 4, 6) + 0·(1, 0, 1) = 0 with non-zero coefficients. The vectors are linearly dependent. (Check : the matrix with these rows has determinant 0 and rank 2.)

How to write it: Definitions → write the dependence relation (or the determinant) → conclude.
Exam tip: For n vectors in ℝⁿ, det ≠ 0 means independent.
Q17

Define basis and dimension. Find a basis and the dimension of the subspace Q = {(x, y, z) : z = x + y}. Write the standard basis of ℝ³. 5 marks ★★★★☆ Very important

Answer

A basis of V is a set of vectors that is linearly independent and spans V. The number of vectors in a basis is the dimension dim V.

Standard basis of ℝ³ : e₁ = (1, 0, 0), e₂ = (0, 1, 0), e₃ = (0, 0, 1). dim ℝ³ = 3.

Q : every vector is (x, y, x + y) = x(1, 0, 1) + y(0, 1, 1). So (1, 0, 1) and (0, 1, 1) span Q; they are independent (not multiples of each other). Basis = {(1, 0, 1), (0, 1, 1)}, dim Q = 2.

How to write it: Definitions → write the general vector → split it into free parameters → basis and dimension.
Exam tip: The number of free parameters = dimension.
Q18

Define a linear transformation. Show that T(x, y) = (2x + y, x − 3y) is linear and write its matrix. Is T(x) = x + 1 linear? 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A map T : V → W is a linear transformation if T(u + v) = T(u) + T(v) and T(cu) = cT(u).

  1. T(u + v) with u = (x₁, y₁), v = (x₂, y₂) : T(x₁ + x₂, y₁ + y₂) = (2(x₁ + x₂) + (y₁ + y₂), (x₁ + x₂) − 3(y₁ + y₂)) = T(u) + T(v). ✔
  2. T(cu) = (2cx + cy, cx − 3cy) = c(2x + y, x − 3y) = cT(u). ✔

So T is linear. Its matrix is A = 211-3, since A(x, y)ᵀ = (2x + y, x − 3y)ᵀ.

T(x) = x + 1 is not linear because T(0) = 1 ≠ 0 (a linear map always sends 0 to 0).

How to write it: Two conditions → verify both for the map → matrix → one non-linear example.
Exam tip: Asked in November 2025 (I (j)). A quick test : T(0) must be 0.
Q19

Define the kernel and image of a linear transformation. State the rank–nullity theorem and verify it for T(x, y, z) = (x + y, y + z). 3 marks ★★★☆☆ Important

Answer

Ker T = {v : T(v) = 0}, Im T = {T(v)}. Rank–nullity : dim V = dim Ker T + dim Im T (nullity + rank).

For T(x, y, z) = (x + y, y + z) : matrix = 110011, rank 2, so dim Im T = 2. Ker T : x + y = 0 and y + z = 0 give (x, y, z) = t(1, −1, 1), dim = 1. Check : 3 = 1 + 2 ✔.

How to write it: Definitions → theorem → compute rank and nullity → add.
Exam tip: Nullity = number of unknowns − rank.
Q20

Define eigenvalue and eigenvector. Write the characteristic equation. 3 marks ★★★★★ Must study

Answer

For a square matrix A, a non-zero vector v is an eigenvector if Av = λv for some scalar λ, called the eigenvalue. The matrix stretches v by the factor λ without changing its direction.

Av = λv ⇒ (A − λI)v = 0 has a non-zero solution only if det(A − λI) = 0. This is the characteristic equation; for an n × n matrix it is a polynomial of degree n in λ.

Procedure : (1) solve det(A − λI) = 0 for λ; (2) for each λ solve (A − λI)v = 0 to get v.

How to write it: Definition (Av = λv) → characteristic equation → the 2-step procedure.
Exam tip: Eigenvectors are never the zero vector.
Q21

Find the eigenvalues and eigenvectors of [[3, −1], [1, 1]]. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A = 3-111. Characteristic equation : det(A − λI) = (3 − λ)(1 − λ) + 1 = λ² − 4λ + 4 = (λ − 2)² = 0.

Eigenvalue : λ = 2 (repeated).

(A − 2I)v = 0 : 1-11-1 gives x − y = 0, so x = y. Eigenvector : v = (1, 1) (and its non-zero multiples).

Check : A(1, 1)ᵀ = (2, 2)ᵀ = 2(1, 1)ᵀ ✔. Sum of eigenvalues 4 = trace; product 4 = det ✔.

How to write it: Characteristic equation → eigenvalue(s) → solve (A − λI)v = 0 → eigenvector → check.
Exam tip: Asked in November 2025 (XI (a)). Note that this matrix has only one independent eigenvector.
Q22

Find the eigenvalues and eigenvectors of [[2, 1], [1, 2]]. 5 marks ★★★★☆ Very important

Answer

det(A − λI) = (2 − λ)² − 1 = λ² − 4λ + 3 = (λ − 1)(λ − 3) = 0, so λ = 1, 3.

  • λ = 1 : (A − I)v = 0 : x + y = 0, so v = (1, −1).
  • λ = 3 : (A − 3I)v = 0 : −x + y = 0, so v = (1, 1).

Check : A(1, 1)ᵀ = (3, 3)ᵀ = 3(1, 1)ᵀ ✔ and A(1, −1)ᵀ = (1, −1)ᵀ ✔. The eigenvectors are perpendicular because A is symmetric.

How to write it: Same steps as above, one block for each eigenvalue.
Exam tip: Write the eigenvector for each λ separately.
Q23

State the properties of eigenvalues. State the Cayley–Hamilton theorem and verify it for [[1, 2], [3, 4]]. 3 marks ★★★☆☆ Important

Answer

  • The sum of the eigenvalues = trace of A.
  • The product of the eigenvalues = |A|.
  • A is singular exactly when 0 is an eigenvalue.
  • Eigenvalues of Aᵀ are the same as those of A; of A⁻¹ they are 1/λ; of Aᵏ they are λᵏ.

Cayley–Hamilton : every square matrix satisfies its own characteristic equation.

For A = 1234 : λ² − 5λ − 2 = 0 (trace 5, det −2). A² = 7101522. A² − 5A − 2I = 0000 = O ✔.

How to write it: List the properties → statement of the theorem → substitute A in its characteristic polynomial.
Exam tip: Remember the characteristic polynomial of 2 × 2 : λ² − (trace)λ + det.
Q24

Mention some applications of matrices and linear algebra in computing and data science. 3 marks ★★☆☆☆ Good to know

Answer

  • Computer graphics : rotation, scaling and translation of images are matrix multiplications.
  • Machine learning : data is stored as matrices; linear regression solves a system of linear equations; neural-network layers are matrix products.
  • Search engines : Google PageRank is an eigenvector of the web link matrix.
  • Data reduction : PCA uses the eigenvalues and eigenvectors of the covariance matrix.
  • Networks and graphs : adjacency matrices represent graphs.
  • Cryptography : Hill cipher uses the matrix inverse.
How to write it: Write 4 points, each with the matrix idea and the application.
Exam tip: Link every point to computing. The examiner wants to see the use.
