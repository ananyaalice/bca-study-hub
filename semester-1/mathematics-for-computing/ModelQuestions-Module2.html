Q1

What is a set? Explain the roster form and the set-builder form with examples. 3 marks ★★★☆☆ Important

Answer

A set is a well-defined collection of distinct objects. The objects are called elements (members). Sets are written with capital letters and elements are written inside { }. “x ∈ A” means x belongs to A; “x ∉ A” means it does not.

FormMeaningExample
Roster (tabular) formList all the elements, separated by commasA = {1, 2, 3, 4, 5}
Set-builder formGive the common property of the elementsA = {x : x is a natural number, x ≤ 5}

Both describe the same set. Order and repetition do not matter : {1, 2, 3} = {3, 2, 1, 1}.

Well-defined : “the collection of tall students” is not a set, because “tall” is not clearly defined.

How to write it: Definition → ∈ and ∉ → table of the two forms with one example each → one line about well-defined.
Exam tip: Use “:” or “|” in set-builder form, read as “such that”.
Q2

Write in roster form : (i) {x : x is a prime number less than 15} (ii) {x ∈ ℤ : x² = 9} (iii) {x : x is a month with 30 days}. Write in set-builder form : (iv) {2, 4, 6, 8, 10} (v) {1, 4, 9, 16, 25}. 3 marks ★★★☆☆ Important

Answer

(i) Primes less than 15 : {2, 3, 5, 7, 11, 13}

(ii) x² = 9 gives x = 3 or x = −3 : {−3, 3}

(iii) April, June, September, November : {April, June, September, November}

(iv) {x : x = 2n, n ∈ ℕ, n ≤ 5} (even numbers up to 10)

(v) {x : x = n², n ∈ ℕ, n ≤ 5}

How to write it: Write each answer as a set on one line. For set-builder form, give the pattern and its range.
Exam tip: Check the domain (ℕ, ℤ) before listing, e.g. x² = 9 has two solutions in ℤ but one in ℕ.
Q3

Explain the types of sets with examples : empty, singleton, finite, infinite, universal, equal and equivalent sets. 5 marks ★★★★☆ Very important

Answer

TypeMeaningExample
Empty (null) set ∅ or { }No elements{x : x is an integer, 1 < x < 2} = ∅
Singleton setExactly one element{7}
Finite setNumber of elements can be counted{a, e, i, o, u}
Infinite setElements never endℕ = {1, 2, 3, …}

Note : ∅ is a set with no elements, but {∅} is a set with one element (the empty set). Equal sets are always equivalent, but equivalent sets need not be equal.

How to write it: Seven-row table (type, meaning, example) + one note about ∅ and {∅}.
Exam tip: Do not write ∅ as {0}. {0} has one element.
Q4

When are two sets equal? Are A = {1, 2, 3} and B = {x : x ∈ ℕ, x² ≤ 10} equal? 3 marks ★★★☆☆ Important

Answer

Two sets are equal if they have exactly the same elements : A = B means A ⊆ B and B ⊆ A.

B = {x ∈ ℕ : x² ≤ 10} : 1² = 1, 2² = 4, 3² = 9 are ≤ 10, but 4² = 16 is not. So B = {1, 2, 3} = A.

Yes, A and B are equal.

How to write it: Definition (A ⊆ B and B ⊆ A) → list B in roster form → compare → conclusion.
Exam tip: Always convert set-builder sets to roster form before comparing.
Q5

Define subset, proper subset and power set. Write the power set of A = {a, b, c} and find the number of its subsets. 5 marks ★★★★★ Must study

Answer

Subset : A ⊆ B if every element of A is in B. Proper subset : A ⊂ B if A ⊆ B and A ≠ B. Power set P(A) : the set of all subsets of A.

For A = {a, b, c} :

P(A) = { ∅, {a}, {b}, {c}, {a, b}, {a, c}, {b, c}, {a, b, c} }

Size of subset0123
Number1331

If a set has n elements, then it has 2ⁿ subsets (each element is either in or out). Here 2³ = 8. Number of proper subsets = 2ⁿ − 1 = 7.

Also ∅ ⊆ A and A ⊆ A for every set A.

How to write it: Three definitions → list P(A) in a line → count by size → the formula 2ⁿ.
Exam tip: Do not forget ∅ and the set A itself in the power set.
Q6

Draw Venn diagrams for A ∪ B, A ∩ B, A − B, Aᶜ and A Δ B (symmetric difference). 5 marks ★★★★★ Must study

Answer

In a Venn diagram, the rectangle is the universal set U and circles are sets. The shaded part is the answer.

How to write it: Draw a rectangle (U) and two overlapping circles for each; shade the required part and write its name below.
Exam tip: Always draw the rectangle for U and label the circles A and B.
Q7

Given A = {1, 2, 3}, B = {2, 3, 4}, find A ∪ B, A ∩ B, A − B, B − A and A Δ B. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

  • A ∪ B (all elements, each once) = {1, 2, 3, 4}
  • A ∩ B (common elements) = {2, 3}
  • A − B (in A but not in B) = {1}
  • B − A = {4}
  • A Δ B = (A − B) ∪ (B − A) = {1, 4}

Check : |A ∪ B| = |A| + |B| − |A ∩ B| = 3 + 3 − 2 = 4 ✔.

How to write it: Write the definition in brackets and the answer in bold for each operation.
Exam tip: This was asked in November 2025 (I (c)). Write the answer as a set with { }.
Q8

State the laws of set algebra and verify De Morgan's laws for U = {1, 2, 3, 4, 5, 6}, A = {1, 2, 3}, B = {3, 4, 5}. 5 marks ★★★★☆ Very important

Answer

LawStatement
CommutativeA ∪ B = B ∪ A ; A ∩ B = B ∩ A
Associative(A ∪ B) ∪ C = A ∪ (B ∪ C) ; (A ∩ B) ∩ C = A ∩ (B ∩ C)
DistributiveA ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) ; A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
IdentityA ∪ ∅ = A ; A ∩ U = A
ComplementA ∪ Aᶜ = U ; A ∩ Aᶜ = ∅ ; (Aᶜ)ᶜ = A
De Morgan(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ ; (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ

Verification

  • Aᶜ = {4, 5, 6}, Bᶜ = {1, 2, 6}
  • A ∪ B = {1, 2, 3, 4, 5} ⇒ (A ∪ B)ᶜ = {6}; Aᶜ ∩ Bᶜ = {6} ✔
  • A ∩ B = {3} ⇒ (A ∩ B)ᶜ = {1, 2, 4, 5, 6}; Aᶜ ∪ Bᶜ = {1, 2, 4, 5, 6} ✔

Both laws hold for these sets.

How to write it: Law table → the complements → compute both sides of each law and show they match.
Exam tip: Compute the complement first. Complement is always taken with respect to U.
Q9

What is the complement of a set? Find Aᶜ, Bᶜ and (A ∪ B)ᶜ if U = {1, …, 10}, A = {2, 4, 6, 8, 10}, B = {1, 2, 3, 4, 5}. 3 marks ★★★★☆ Very important

Answer

The complement of A is the set of elements of U that are not in A : Aᶜ = U − A.

  • Aᶜ = {1, 3, 5, 7, 9}
  • Bᶜ = {6, 7, 8, 9, 10}
  • A ∪ B = {1, 2, 3, 4, 5, 6, 8, 10}, so (A ∪ B)ᶜ = {7, 9}
How to write it: Definition → write Aᶜ, Bᶜ → compute A ∪ B → take its complement.
Exam tip: Elements of the complement are always from U, never from outside it.
Q10

What is the cardinality of a set? State the formulas for |A ∪ B| and |A ∪ B ∪ C|. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

The cardinality |A| of a finite set is the number of its elements. Example : |{a, e, i, o, u}| = 5, |∅| = 0.

|A ∪ B| = |A| + |B| − |A ∩ B|

|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |B ∩ C| − |A ∩ C| + |A ∩ B ∩ C|

Reason : the elements common to A and B are counted twice when we add |A| and |B|, so we subtract |A ∩ B| once.

Example : A = {1, 2, 3}, B = {2, 3, 4} : |A ∪ B| = 3 + 3 − 2 = 4.

How to write it: Define |A| → write the two formulas → reason in one line → one numerical example.
Exam tip: This is the inclusion–exclusion principle (asked in November 2025, I (f)).
Q11

In a class of 80 students, 50 like Maths, 40 like Computer Science and 15 like neither. How many like both? How many like only Maths? 5 marks ★★★★★ Must study

Answer

Let M = students who like Maths, C = Computer Science. |U| = 80, |M| = 50, |C| = 40, neither = 15.

  1. Students who like at least one subject = 80 − 15 = 65, so |M ∪ C| = 65.
  2. |M ∪ C| = |M| + |C| − |M ∩ C|, so 65 = 50 + 40 − |M ∩ C|, giving |M ∩ C| = 90 − 65 = 25.
  3. Only Maths = |M| − |M ∩ C| = 50 − 25 = 25. Only CS = 40 − 25 = 15.
RegionOnly MathsBothOnly CSNeitherTotal
Students2525151580

Check : 25 + 25 + 15 + 15 = 80 ✔.

Answer : 25 like both; 25 like only Maths.

How to write it: Define sets → |M ∪ C| = total − neither → apply the formula → find only-Maths → check that the regions add up to the total.
Exam tip: Always subtract “neither” first. Draw the Venn diagram if time permits.
Q12

In a survey of 100 people, 60 read newspaper A, 50 read B, 40 read C, 30 read A and B, 20 read B and C, 25 read A and C, and 10 read all three. Find how many read at least one paper and how many read none. 5 marks ★★★★☆ Very important

Answer

  1. |A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |B ∩ C| − |A ∩ C| + |A ∩ B ∩ C|
  2. = 60 + 50 + 40 − 30 − 20 − 25 + 10 = 150 − 75 + 10 = 85.
  3. Number who read none = 100 − 85 = 15.

Only A = 60 − 30 − 25 + 10 = 15, only B = 50 − 30 − 20 + 10 = 10, only C = 40 − 20 − 25 + 10 = 5.

How to write it: Write the 3-set formula → substitute → subtract from the total for “none”.
Exam tip: Use the 3-circle Venn diagram and start filling from the centre (all three).
Q13

Define the Cartesian product. Find A × B and B × A for A = {1, 2, 3}, B = {2, 4, 6}. Is A × B = B × A? 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

The Cartesian product A × B = {(a, b) : a ∈ A, b ∈ B} is the set of all ordered pairs whose first element is from A and second from B. |A × B| = |A| · |B|.

A × B = {(1,2), (1,4), (1,6), (2,2), (2,4), (2,6), (3,2), (3,4), (3,6)}

B × A = {(2,1), (2,2), (2,3), (4,1), (4,2), (4,3), (6,1), (6,2), (6,3)}

Each has 3 × 3 = 9 elements. But A × B ≠ B × A, since ordered pairs (1, 2) ≠ (2, 1). (A × B = B × A only if A = B or one of them is empty.)

How to write it: Definition and |A × B| = |A||B| → list both products → say they are not equal (ordered pairs).
Exam tip: This was asked in November 2025 (V (a)). List the pairs in order : first element by first element.
Q14

Define a relation. How many relations are there on a set with n elements? List all relations on A = {1, 2, 3} having exactly 3 ordered pairs. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A relation R from A to B is a subset of A × B. A relation on A is a subset of A × A. Domain = first elements, range = second elements.

If |A| = n, then A × A has n² pairs, and each pair is either in R or not. So the number of relations on A is 2n². For n = 3 : 2⁹ = 512.

Relations with exactly 3 pairs : choose 3 pairs out of the 9 pairs of A × A : ⁹C₃ = (9 × 8 × 7)/(3 × 2 × 1) = 84. Examples : {(1,1), (1,2), (1,3)}, {(1,1), (2,2), (3,3)}, {(1,2), (2,3), (3,1)}, … The full list of 84 relations is given in the Previous Questions 2025 page (IV (a)).

How to write it: Definition → formula 2^(n²) → ⁹C₃ = 84 → two or three examples of such relations.
Exam tip: Use the combination formula. You do not have to list all 84 unless asked; list the first few and write “…”.

Q16

Explain reflexive, symmetric, antisymmetric and transitive relations with examples. Is R = {(1,1), (2,2), (3,1)} reflexive on {1, 2, 3}? 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

PropertyMeaningExample on {1, 2, 3}Non-example
Reflexive(a, a) ∈ R for all a{(1,1), (2,2), (3,3), (1,2)}{(1,1), (2,2)}
Symmetric(a, b) ∈ R ⇒ (b, a) ∈ R{(1,2), (2,1), (3,3)}{(1,2)}
Antisymmetric(a, b) and (b, a) ∈ R ⇒ a = b{(1,1), (1,2), (2,3)}{(1,2), (2,1)}
Transitive(a, b), (b, c) ∈ R ⇒ (a, c) ∈ R{(1,2), (2,3), (1,3)}{(1,2), (2,3)}

R = {(1,1), (2,2), (3,1)} : (3,3) is not in R, so R is not reflexive.

Everyday examples : “≤” on numbers is reflexive, antisymmetric and transitive. “is a friend of” is symmetric.

How to write it: Table of four properties with an example and a non-example → test the given relation → one everyday example.
Exam tip: To test reflexive : check every element (a, a). One missing pair is enough to say “not reflexive”.
Q17

What is an equivalence relation? Show that congruence modulo 3 on ℤ is an equivalence relation and find its equivalence classes. 5 marks ★★★★☆ Very important

Answer

A relation that is reflexive, symmetric and transitive is an equivalence relation. Define a ~ b if 3 divides a − b.

  1. Reflexive : a − a = 0 is divisible by 3, so a ~ a.
  2. Symmetric : if 3 divides a − b, then 3 divides b − a = −(a − b).
  3. Transitive : if 3 | (a − b) and 3 | (b − c), then 3 | (a − b) + (b − c) = a − c.

So ~ is an equivalence relation. It splits ℤ into 3 equivalence classes :

  • [0] = {…, −6, −3, 0, 3, 6, …}
  • [1] = {…, −5, −2, 1, 4, 7, …}
  • [2] = {…, −4, −1, 2, 5, 8, …}
How to write it: Definition → check R, S, T in numbered steps → write the classes.
Exam tip: The classes are disjoint and together cover the whole set (a partition).
Q18

Define a function. Explain domain, codomain and range with an example. 5 marks ★★★★☆ Very important

Answer

A function f : A → B assigns to each element of A exactly one element of B. A is the domain, B is the codomain, and the set of actual outputs {f(x) : x ∈ A} is the range (range ⊆ codomain).

Example : A = {1, 2, 3}, B = {1, 4, 9, 16}, f(x) = x². Then f(1) = 1, f(2) = 4, f(3) = 9. Domain = {1, 2, 3}, codomain = {1, 4, 9, 16}, range = {1, 4, 9} (16 is not an output).

Not a function : a relation where one input has two outputs, e.g. {(1, 2), (1, 3)}, or an input with no output.

How to write it: Definition (each input exactly one output) → domain, codomain, range → one example → one non-example.
Exam tip: Range and codomain are not the same. Range is only the outputs that really occur.

Q20

Define composition of functions. If f(x) = 2x + 1 and g(x) = x², find (g∘f)(x), (f∘g)(x) and (g∘f)(3). 3 marks ★★★☆☆ Important

Answer

The composition (g∘f)(x) = g(f(x)) means : first apply f, then apply g.

  • (g∘f)(x) = g(2x + 1) = (2x + 1)² = 4x² + 4x + 1
  • (f∘g)(x) = f(x²) = 2x² + 1
  • (g∘f)(3) = (2·3 + 1)² = 7² = 49

So g∘f ≠ f∘g in general.

How to write it: Definition → substitute carefully → compute the number → state g∘f ≠ f∘g.
Exam tip: (g∘f) means f first, then g. Read it from right to left.
