I (a)

Define contrapositive of a statement with an example. [2 marks]

The contrapositive of a conditional statement “If p, then q” (p → q) is the statement “If not q, then not p” (¬q → ¬p). It is formed by negating both the hypothesis and the conclusion and then interchanging them.

Example

  • Statement : If it rains, then the ground is wet. (p : It rains, q : The ground is wet)
  • Contrapositive : If the ground is not wet, then it did not rain.

A statement and its contrapositive are logically equivalent : they always have the same truth value.

The last two columns are identical, so p → q ≡ ¬q → ¬p.

A relation R on a set A is reflexive if (a, a) ∈ R for every a ∈ A.

The set is not printed in the question, so we take A = {1, 2, 3} (the numbers used in R).

  1. (1,1) ∈ R ✔
  2. (2,2) ∈ R ✔
  3. (3,3) ∉ R ✘ (R has (3,1), not (3,3))

Answer : No, R is not reflexive, because the pair (3,3) is missing.

I (e)

State group axioms. [2 marks]

A non-empty set G with a binary operation * is a group if it satisfies four axioms :

  1. Closure : a * b ∈ G for all a, b ∈ G.
  2. Associativity : (a * b) * c = a * (b * c) for all a, b, c ∈ G.
  3. Identity : there is an element e ∈ G such that a * e = e * a = a for all a ∈ G.
  4. Inverse : for every a ∈ G there is a⁻¹ ∈ G such that a * a⁻¹ = a⁻¹ * a = e.

If, in addition, a * b = b * a for all a, b, then G is an abelian (commutative) group. Example : (ℤ, +) with identity 0 and inverse −a.

I (f)

State the inclusion–exclusion principle. [2 marks]

To count the elements in a union, add the sizes of the sets, subtract the sizes of the pairwise overlaps, and add back the triple overlap.

  • Two sets : |A ∪ B| = |A| + |B| − |A ∩ B|
  • Three sets : |A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|

Example : In a class, 60 like Maths, 50 like CS and 30 like both. Students who like at least one subject = 60 + 50 − 30 = 80.

I (j)

Define linear transformation. [2 marks]

A map T : V → W between vector spaces is a linear transformation if, for all u, v in V and every scalar c :

  • T(u + v) = T(u) + T(v) (additivity)
  • T(cu) = cT(u) (homogeneity)

Example : T(x, y) = (2x + y, x − 3y) is linear. Its matrix is 211-3. But T(x) = x + 1 is not linear, because T(0) = 1 ≠ 0.

II (c)

Using contradiction, prove that √2 is irrational. [3 marks]

Idea : assume the opposite, and show that this leads to something impossible.

  1. Assume the opposite. Suppose √2 is rational. Then √2 = a/b, where a and b are integers, b ≠ 0, and a/b is in lowest terms (a and b have no common factor).
  2. Square both sides. 2 = a²/b², so a² = 2b².
  3. So a² is even. If a² is even, then a is even (an odd number squared is odd). Write a = 2c.
  4. Substitute. (2c)² = 2b² gives 4c² = 2b², so b² = 2c². Hence b² is even and b is even.
  5. Contradiction. Both a and b are even, so they have the common factor 2. But we assumed a/b was in lowest terms. This is impossible.

Conclusion : our assumption was wrong. Hence √2 is irrational. ∎

Predicate

A predicate (propositional function) is a statement that contains one or more variables and becomes a proposition (true or false) when values are given to the variables or when the variables are quantified. It is written P(x). It is also called an open sentence, because its truth value is not known until x is given a value.

P(x) : x > 5P(3)False

P(x) : x + 2 = 7 is not a proposition, because it depends on x.

Quantifiers

A quantifier is a symbol that tells how many elements of the domain satisfy a predicate. It turns a predicate into a proposition.

QuantifierSymbolMeaningExample
Universal∀“for all”, “for every”Domain ℕ, P(x) : x + 0 = x. ∀x P(x) is true.

III (c)

Prove : (p ∨ q) ∧ (¬p) ⇒ q. [3 marks]

This is the rule Disjunctive Syllogism : if “p or q” is true and p is false, then q must be true.

Proof by truth table

pqp ∨ q¬p(p∨q)∧¬pq
TTTFFT
TFTFFF
FTTTTT
FFFTFF

The only row in which the premise (p ∨ q) ∧ ¬p is true is row 3 (p = F, q = T), and there q is also true. So whenever the premise is true, q is true. Hence (p ∨ q) ∧ (¬p) ⇒ q. ∎

Proof by laws (algebra)

  1. (p ∨ q) ∧ ¬p ≡ (p ∧ ¬p) ∨ (q ∧ ¬p) (distributive law)
  2. p ∧ ¬p is a contradiction (F), so this becomes F ∨ (q ∧ ¬p) ≡ q ∧ ¬p
  3. q ∧ ¬p implies q (simplification). ∎

V (b)

Define relation. Explain reflexive, symmetric, and transitive properties with examples. [5 marks]

A relation R from a set A to a set B is a subset of A × B. A relation on A is a subset of A × A. If (a, b) ∈ R we write a R b.

Let A = {1, 2, 3} for the examples.

PropertyMeaningExampleNon-example
Reflexive(a, a) ∈ R for every a ∈ AR = {(1,1), (2,2), (3,3), (1,2)}R = {(1,1), (2,2)} – (3,3) is missing
Symmetricif (a, b) ∈ R then (b, a) ∈ RR = {(1,2), (2,1), (3,3)}R = {(1,2)} – (2,1) is missing
Transitiveif (a, b) ∈ R and (b, c) ∈ R then (a, c) ∈ RR = {(1,2), (2,3), (1,3)}R = {(1,2), (2,3)} – (1,3) is missing

Everyday examples : “is equal to” on numbers is reflexive, symmetric and transitive. “is less than or equal to (≤)” is reflexive and transitive but not symmetric. “is a friend of” is symmetric but usually not transitive.

A relation that is reflexive, symmetric and transitive is called an equivalence relation.

VI (a)

Show G = {1, 3, 5, 7} with multiplication mod 8 is not a group. [5 marks]

Note on the question : when we check the four group axioms carefully, G = {1, 3, 5, 7} under multiplication mod 8 is a group (it is the well-known Klein four-group). So the statement “is not a group” cannot be proved. The question probably has a printing mistake (for example a different set or operation). The correct working is shown below. For example 3 × 5 = 15 = 7 (mod 8), 3 × 7 = 21 = 5 (mod 8), 5 × 7 = 35 = 3 (mod 8), and 3 × 3 = 9 = 1, 5 × 5 = 25 = 1, 7 × 7 = 49 = 1.

  1. Closure : every entry of the table is 1, 3, 5 or 7, so a × b ∈ G. ✔
  2. Associativity : multiplication of integers is associative, and taking mod 8 keeps this. ✔
  3. Identity : 1 × a = a × 1 = a for every a, so the identity is 1. ✔
  4. Inverse : 1 × 1 = 3 × 3 = 5 × 5 = 7 × 7 = 1, so every element is its own inverse. ✔

Conclusion : all four axioms hold, so G is a group (and abelian, since the table is symmetric).

How a set fails to be a group (for comparison)

  • {1, 3, 5, 7} under addition mod 8 : 3 + 5 = 8 ≡ 0 ∉ G, so closure fails. Not a group.
  • {1, 2, 3, …, 7} under multiplication mod 8 : 2 × 4 = 8 ≡ 0 ∉ the set, so closure fails; also 2 has no inverse. Not a group.
VI (b)

Prove H = 2ℤ is a subgroup of ℤ under addition. [5 marks]

H = 2ℤ = {…, −4, −2, 0, 2, 4, …} is the set of all even integers. A non-empty subset H of a group G is a subgroup if H is closed, contains the identity, and contains inverses (associativity is inherited from ℤ).

  1. H is non-empty and contains the identity : 0 = 2 × 0 ∈ H. ✔
  2. Closure : let a = 2m and b = 2n be in H. Then a + b = 2m + 2n = 2(m + n), which is even, so a + b ∈ H. ✔
  3. Inverses : for a = 2m ∈ H, the inverse is −a = 2(−m), which is even, so −a ∈ H. ✔

Hence 2ℤ ≤ ℤ. ∎

Same proof with the one-step subgroup test

H is a subgroup if a − b ∈ H for all a, b ∈ H. Take a = 2m, b = 2n : a − b = 2m − 2n = 2(m − n) ∈ H. ✔

VII (a)

Explain homomorphism and isomorphism of groups. [4 marks]

Homomorphism

Let (G, ∗) and (H, ∘) be groups. A function f : G → H is a homomorphism if f(a ∗ b) = f(a) ∘ f(b) for all a, b ∈ G. (Operate first and then map, or map first and then operate – the answer is the same.)

  • Kernel : Ker(f) = {x ∈ G : f(x) = identity of H}.
  • Image : Im(f) = {f(x) : x ∈ G}.
  • A homomorphism sends identity to identity.

Example : f : (ℤ, +) → (ℤ₅, +₅), f(x) = x mod 5. f(7 + 8) = f(15) = 0 and f(7) +₅ f(8) = 2 +₅ 3 = 0. Kernel = 5ℤ.

Isomorphism

A homomorphism f : G → H that is also one-one and onto is an isomorphism. Then G and H are isomorphic, written G ≅ H.

Isomorphism = Homomorphism + One-one + Onto.

Examples : (ℝ, +) ≅ (ℝ⁺, ×) by f(x) = eˣ, because ex+y = eˣ · eʸ, one-one and onto (x = ln y). Also (ℤ, +) ≅ (2ℤ, +) by f(n) = 2n.

VII (b)

Show f : ℤ → ℤ, f(x) = 3x + 1 is homomorphism; find the kernel. [6 marks]

Note on the question : for f(x) = 3x + 1 the homomorphism condition does not hold, so it cannot be shown to be a homomorphism (see Part 1). The question most likely means f(x) = 3x. Part 2 gives the full answer for f(x) = 3x, including the kernel. Write the check for the question as printed and explain the result.

Part 1 : the function as printed, f(x) = 3x + 1

For ℤ with addition we need f(x + y) = f(x) + f(y).

  • f(x + y) = 3(x + y) + 1 = 3x + 3y + 1
  • f(x) + f(y) = (3x + 1) + (3y + 1) = 3x + 3y + 2
  • These are not equal. Example : f(1 + 2) = f(3) = 10, but f(1) + f(2) = 4 + 7 = 11.
  • Also f(0) = 1 ≠ 0, so the identity does not go to the identity.

So f(x) = 3x + 1 is not a homomorphism. Its “kernel” would need 3x + 1 = 0, giving x = −1/3, which is not an integer, so no element is sent to 0 (the kernel of a real homomorphism always contains 0).

Part 2 : the likely intended function, f(x) = 3x

  1. Take any x, y ∈ ℤ.
  2. f(x + y) = 3(x + y) = 3x + 3y = f(x) + f(y). ✔ So f is a homomorphism.
  3. Kernel : solve f(x) = 0 (the identity of the target group (ℤ, +) is 0). 3x = 0 gives x = 0. So Ker(f) = {0}.
  4. Image : Im(f) = 3ℤ = {…, −6, −3, 0, 3, 6, …}.

Since Ker(f) = {0}, f is one-one. It is not onto ℤ (for example 1 is never an output).

VIII (a)

State pigeonhole principle with an application. [3 marks]

Pigeonhole principle : If n + 1 or more objects are placed into n boxes, then at least one box contains at least 2 objects.

Generalised form : if N objects are placed into k boxes, then some box has at least ⌈N/k⌉ objects.

Application

Among any 13 people, at least two were born in the same month. There are 12 months (boxes) and 13 people (objects), so by the pigeonhole principle some month contains at least two people.

Generalised : in a class of 100 students, at least ⌈100/12⌉ = ⌈8.33⌉ = 9 students were born in the same month.

VIII (b)

Solve the recurrence : aₙ = 3aₙ₋₁ + 2, a₀ = 1. [4 marks]

This is a first-order linear recurrence. We find the general solution as (solution of the homogeneous part) + (a particular solution).

  1. Homogeneous part : aₙ = 3aₙ₋₁ has the solution aₙ = A · 3ⁿ (A is a constant).
  2. Particular solution : try a constant aₙ = c. Then c = 3c + 2, so −2c = 2 and c = −1.
  3. General solution : aₙ = A · 3ⁿ − 1.
  4. Use the initial condition a₀ = 1 : A · 3⁰ − 1 = 1, so A = 2.

Answer : aₙ = 2 · 3ⁿ − 1.

VIII (c)

How many 5-letter words from “COMPUTE” without repetition? [3 marks]

The word COMPUTE has 7 different letters : C, O, M, P, U, T, E. We choose 5 of them and arrange them in order, with no letter repeated. Order matters, so we use a permutation ⁿPᵣ = n! / (n − r)!.

  1. Place 1 : 7 choices
  2. Place 2 : 6 choices
  3. Place 3 : 5 choices
  4. Place 4 : 4 choices
  5. Place 5 : 3 choices

Number of words = ⁷P₅ = 7 × 6 × 5 × 4 × 3 = 2520.

(“Words” here means any arrangement of letters, not only meaningful English words.)

IX (a)

Explain Euler and Hamiltonian paths. [4 marks]

Euler path and Euler circuit

An Euler path is a walk in a graph that uses every edge exactly once. Vertices may be repeated, but no edge is repeated. An Euler circuit is an Euler path that starts and ends at the same vertex.

  • A connected graph has an Euler circuit if and only if every vertex has even degree.
  • A connected graph has an Euler path (not a circuit) when exactly two vertices have odd degree; the path starts at one and ends at the other.

Hamilton path and Hamilton circuit

A Hamilton path is a simple path that passes through every vertex exactly once. A Hamilton circuit is a simple circuit that passes through every vertex exactly once and returns to the starting vertex. We do not have to use every edge.

Draw a graph with degree sequence (3, 3, 2, 2, 2, 2). [3 marks]

The degree sequence has 6 vertices. By the handshaking lemma, the sum of the degrees is twice the number of edges : 3 + 3 + 2 + 2 + 2 + 2 = 14, so the graph has 14 / 2 = 7 edges. (The sum is even, so such a graph can exist.)

Find the rank of the matrix [[1, 2, 3], [2, 4, 6], [1, 1, 1]]. [5 marks]

The matrix is A = 123246111. We use row operations to reach echelon form. The rank is the number of non-zero rows.

  1. R₂ → R₂ − 2R₁ : (2, 4, 6) − 2(1, 2, 3) = (0, 0, 0).
  2. R₃ → R₃ − R₁ : (1, 1, 1) − (1, 2, 3) = (0, −1, −2).
  3. Swap R₂ and R₃ to bring the zero row to the bottom.

Echelon form : 1230-1-2000

There are 2 non-zero rows, so rank(A) = 2.

Check : row 2 is twice row 1, so the three rows are dependent; rows 1 and 3 are independent. Also det A = 0.

Write the augmented matrix [A | B] and use forward elimination to reach echelon form, then back substitution.

[A | B] = 111623720341027

  2. R₃ → R₃ − R₂ : 111601580021 (echelon form reached)

Back substitution

XI (a)

Find the eigen values and the eigenvectors of [[3, −1], [1, 1]]. [5 marks]

Let A = 3-111. Eigenvalues λ satisfy the characteristic equation det(A − λI) = 0.

Step 1 : eigenvalues

det(A − λI) = (3 − λ)(1 − λ) − (−1)(1) = λ² − 4λ + 3 + 1 = λ² − 4λ + 4 = (λ − 2)² = 0.

So λ = 2 (a repeated eigenvalue, it occurs twice).

Step 2 : eigenvector for λ = 2

Solve (A − 2I)v = 0. A − 2I = 1-11-1, which gives x − y = 0, so x = y.

Taking y = 1, the eigenvector is v = (1, 1) (or any non-zero multiple of it).

Answer : eigenvalue λ = 2 (twice); eigenvectors are all non-zero multiples of (1, 1).

Check : A(1, 1)ᵀ = (3 − 1, 1 + 1)ᵀ = (2, 2)ᵀ = 2(1, 1)ᵀ ✔. Sum of eigenvalues 2 + 2 = 4 = trace; product 4 = det A = 3 + 1 ✔.

XI (b)

Determine whether the following sets are subspaces of ℝ³ : (i) Z = {(x, y, z) : z = xy} (ii) Q = {(x, y, z) : z = x + y}. [5 marks]

A non-empty subset W of ℝ³ is a subspace if it is closed under addition and scalar multiplication (and so contains the zero vector).

(i) Z = {(x, y, z) : z = xy} – NOT a subspace

  • (0, 0, 0) ∈ Z (0 = 0 × 0), so the zero vector is present – this alone is not enough.
  • Scalar multiplication fails : u = (1, 1, 1) ∈ Z because 1 = 1 × 1. Take c = 2 : 2u = (2, 2, 2). Is 2 = 2 × 2 = 4? No. So 2u ∉ Z.
  • Addition also fails : (1, 1, 1) ∈ Z and (1, 2, 2) ∈ Z, but their sum (2, 3, 3) has 3 ≠ 2 × 3 = 6, so it is not in Z.

Z is not closed, so Z is not a subspace of ℝ³.

(ii) Q = {(x, y, z) : z = x + y} – a subspace

  1. Zero vector : (0, 0, 0) ∈ Q because 0 = 0 + 0. ✔
  2. Closed under addition : let u = (x₁, y₁, x₁ + y₁) and v = (x₂, y₂, x₂ + y₂) be in Q. Then u + v = (x₁ + x₂, y₁ + y₂, (x₁ + y₁) + (x₂ + y₂)) = (X, Y, X + Y) with X = x₁ + x₂ and Y = y₁ + y₂. So u + v ∈ Q. ✔
  3. Closed under scalar multiplication : for a scalar c, cu = (cx₁, cy₁, c(x₁ + y₁)) = (cx₁, cy₁, cx₁ + cy₁) ∈ Q. ✔

Hence Q is a subspace of ℝ³. It is the plane z = x + y through the origin, with basis {(1, 0, 1), (0, 1, 1)} and dimension 2.
