Q1

What is a proposition? Give examples of statements that are propositions and statements that are not. 3 marks ★★★☆☆ Important

Answer

A proposition (statement) is a declarative sentence that is either true or false, but not both. We denote propositions by small letters p, q, r, … The truth value of a proposition is T (true) or F (false).

SentenceProposition?Reason
The sum of 2 and 3 is 5.Yes (True)It has a definite truth value
Delhi is the capital of Kerala.Yes (False)It is false, but it is still a statement
What is your name?NoA question
Close the door.NoA command
x + 2 = 7NoThe value of x is not given, so it can be true or false (it is an open sentence)
This sentence is false.NoIt cannot be given a truth value

Propositions that cannot be broken into smaller statements are simple (atomic) propositions. Those formed with connectives such as “and”, “or”, “not” are compound propositions.

How to write it: Definition (declarative + true or false, not both) → symbol p, q → a table of 2 propositions and 2 non-propositions.
Exam tip: Do not forget that a false sentence is still a proposition. “x + 2 = 7” is not.

Q4

Explain the conditional (implication) p → q. Write its converse, inverse and contrapositive with an example. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

The conditional p → q is read “if p, then q”. Here p is the hypothesis and q is the conclusion. It is false only when p is true and q is false.

FormSymbolExample (p : It rains, q : The road is wet)
Conditionalp → qIf it rains, then the road is wet.
Converseq → pIf the road is wet, then it rains.
Inverse¬p → ¬qIf it does not rain, then the road is not wet.
Contrapositive¬q → ¬pIf the road is not wet, then it does not rain.
pqp → qq → p¬p → ¬q¬q → ¬p
TTTTTT
TFFTTF
FTTFFT
FFTTTT

Result : a conditional and its contrapositive are equivalent (same columns). The converse and the inverse are equivalent to each other, but not to the conditional.

How to write it: Define p → q (hypothesis, conclusion) → table of the 4 forms with an example → combined truth table → write the result in two lines.
Exam tip: The converse is NOT equivalent to the original statement. This is the most common mistake.
Q5

Define contrapositive of a statement with an example. 2 marks ★★★★★ Must study Asked in Nov 2025

Answer

The contrapositive of “If p, then q” (p → q) is “If not q, then not p” (¬q → ¬p). We negate both parts and interchange them.

Example : Statement : If a number is divisible by 6, then it is divisible by 3. Contrapositive : If a number is not divisible by 3, then it is not divisible by 6.

pqp → q¬q → ¬p
TTTT
TFFF
FTTT
FFTT

Both columns are the same, so a statement and its contrapositive are logically equivalent.

How to write it: Statement → contrapositive form (¬q → ¬p) → one example → the equivalence line.
Exam tip: 2-mark answer : formula + example + “logically equivalent”. Write it in 4 lines.
Q6

Write the contrapositive, converse and inverse of “If a number is divisible by 4, then it is even”. 3 marks ★★★★☆ Very important

Answer

Let p : the number is divisible by 4, q : the number is even.

FormStatement
Given p → qIf a number is divisible by 4, then it is even. (True)
Contrapositive ¬q → ¬pIf a number is not even, then it is not divisible by 4. (True)
Converse q → pIf a number is even, then it is divisible by 4. (False : 6 is even but not divisible by 4)
Inverse ¬p → ¬qIf a number is not divisible by 4, then it is not even. (False : 6)

The contrapositive has the same truth value as the given statement. The converse and the inverse can differ from it.

How to write it: Name p and q → write the four statements in a table → state the truth value of each, with a counter-example (6) for the false ones.
Exam tip: Always name p and q first. Then the negations are easy.
Q7

What is logical equivalence? Show that p → q ≡ ¬p ∨ q. 3 marks ★★★★☆ Very important

Answer

Two compound propositions are logically equivalent (written A ≡ B) if they have the same truth value for every combination of truth values of the variables. Equivalently, A ↔ B is a tautology.

pqp → q¬p¬p ∨ q
TTTFT
TFFFF
FTTTT
FFTTT

The columns of p → q and ¬p ∨ q are identical, so p → q ≡ ¬p ∨ q.

How to write it: Definition (same truth value in every row) → truth table with the intermediate column ¬p → identical columns → conclusion.
Exam tip: Always include the helper column (¬p). It earns the method marks.
Q8

State and prove De Morgan's laws. 5 marks ★★★★☆ Very important

Answer

De Morgan's laws tell us how negation works with AND and OR :

  • ¬(p ∧ q) ≡ ¬p ∨ ¬q
  • ¬(p ∨ q) ≡ ¬p ∧ ¬q

In each table the two marked columns are equal, so both laws are proved.

Example : “It is not true that Ravi is tall and fast” means “Ravi is not tall or Ravi is not fast”.

List the standard laws of logic (equivalences). 3 marks ★★★☆☆ Important

Answer

Q10

Prove using laws of logic (without a truth table) that ¬(p ∨ (¬p ∧ q)) ≡ ¬p ∧ ¬q. 5 marks ★★★☆☆ Important

Answer

We start from the left side and use the laws step by step.

StepExpressionLaw used
1¬(p ∨ (¬p ∧ q))
2¬p ∧ ¬(¬p ∧ q)De Morgan
3¬p ∧ (¬(¬p) ∨ ¬q)De Morgan
4¬p ∧ (p ∨ ¬q)Double negation
5(¬p ∧ p) ∨ (¬p ∧ ¬q)Distributive
6F ∨ (¬p ∧ ¬q)Negation law (¬p ∧ p ≡ F)
7¬p ∧ ¬qIdentity law

Hence the left side ≡ ¬p ∧ ¬q. ∎

How to write it: Three columns: step, expression, law used. Stop at the right-hand side.
Exam tip: Write the law next to every step. Do not skip the double negation.
Q11

Define tautology, contradiction and contingency with examples. Verify whether (p ∨ q) → (p → q) is a tautology. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A compound proposition is a tautology if it is always true, a contradiction if it is always false, and a contingency if it is sometimes true and sometimes false.

TypeExampleTruth values
Tautologyp ∨ ¬pT, T
Contradictionp ∧ ¬pF, F
Contingencyp → qT, F, T, T

Verify (p ∨ q) → (p → q)

pqp ∨ qp → q(p∨q) → (p→q)
TTTTT
TFTFF
FTTTT
FFFTT

The last column has an F in the row p = T, q = F. So it is not a tautology (it is a contingency).

A statement that is a tautology : (p ∧ q) → (p ∨ q). Its last column is all T.
How to write it: Three definitions + one example each → truth table for the given statement → conclusion (tautology or not) in one line.
Exam tip: A tautology needs ALL rows true. One F row is enough to reject it.

Q13

Explain predicates with examples. What is an open sentence? 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

A predicate P(x) is a sentence with one or more variables that becomes a proposition when a value is given to each variable. A sentence with a variable whose truth is not yet known is an open sentence. The set of allowed values of x is the domain.

PredicateValueResult
P(x) : x > 5P(8)True
P(x) : x > 5P(3)False
Q(x, y) : x + y = 10Q(4, 6)True

“x + 2 = 7” is a predicate, not a proposition. “5 + 2 = 7” is a proposition.

How to write it: Definition → domain → table with 2–3 values → one line to separate predicate and proposition.
Exam tip: Remember : a predicate becomes a proposition either by giving values or by using quantifiers.
Q14

What are quantifiers? Explain the universal and existential quantifiers with examples and their negations. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A quantifier says how many elements of the domain satisfy a predicate.

QuantifierSymbolMeaningExample (domain ℤ)
Universal∀x P(x)for all x, P(x)∀x (x² ≥ 0) : True
Existential∃x P(x)there is at least one x with P(x)∃x (x² = 25) : True (x = 5, −5)

Negation

StatementNegation
∀x P(x)∃x ¬P(x)
∃x P(x)∀x ¬P(x)

Example : ¬∀x (x > 0) ≡ ∃x (x ≤ 0). A single counter-example (x = −1) makes a ∀-statement false.

How to write it: Definition → table of ∀ and ∃ with meaning and example → negation table → one negation example.
Exam tip: To negate, change ∀ ↔ ∃ and negate the predicate.
Q15

Write the negation of : (i) ∀x ∃y (x + y = 0) (ii) ∃x ∀y (x ≤ y) (iii) “All students passed the test”. 3 marks ★★★☆☆ Important

Answer

  • (i) ¬∀x ∃y (x + y = 0) ≡ ∃x ∀y (x + y ≠ 0)
  • (ii) ¬∃x ∀y (x ≤ y) ≡ ∀x ∃y (x > y)
  • (iii) Negation of “All students passed” is “Some student did not pass” (not “No student passed”).

Rule : move the ¬ inward, change each ∀ to ∃ and each ∃ to ∀, then negate the predicate.

How to write it: Move the negation step by step from left to right, flipping each quantifier.
Exam tip: “Not all” means “at least one not”. It does not mean “none”.
Q16

What is a rule of inference? List the important rules with their forms. 5 marks ★★★★☆ Very important Asked in Nov 2025

Answer

A rule of inference is a valid argument pattern that lets us get a conclusion from premises that are assumed true. An argument is valid if the conclusion is true whenever all the premises are true.

RulePremisesConclusion
Modus ponensp → q, pq
Modus tollensp → q, ¬q¬p
Hypothetical syllogismp → q, q → rp → r
Disjunctive syllogismp ∨ q, ¬pq
Additionpp ∨ q
Simplificationp ∧ qp
Conjunctionp, qp ∧ q
Resolutionp ∨ q, ¬p ∨ rq ∨ r

Example (modus ponens) : If it rains, I carry an umbrella. It rains. Therefore I carry an umbrella.

How to write it: Definition of validity → table (rule, premises, conclusion) → one example.
Exam tip: Learn the table by heart. Most proof questions use only 4 rules : MP, MT, HS, DS.

Q18

Prove : (p ∨ q) ∧ ¬p ⇒ q (disjunctive syllogism). 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

pqp ∨ q¬p(p∨q)∧¬pq
TTTFFT
TFTFFF
FTTTTT
FFFTFF

The only row where the premise is true is row 3 (p = F, q = T), and q is true there. Hence (p ∨ q) ∧ ¬p ⇒ q. ∎

Q20

Prove by a direct proof : the sum of two even integers is even, and the product of two odd integers is odd. 5 marks ★★★★☆ Very important

Answer

Direct proof : assume the hypothesis p is true and show, using definitions and known facts, that the conclusion q is true.

(i) Sum of two even integers

  1. Let a and b be even. Then a = 2m and b = 2n for integers m, n.
  2. a + b = 2m + 2n = 2(m + n).
  3. m + n is an integer, so a + b is even. ∎

(ii) Product of two odd integers

  1. Let a and b be odd. Then a = 2m + 1 and b = 2n + 1.
  2. ab = (2m + 1)(2n + 1) = 4mn + 2m + 2n + 1 = 2(2mn + m + n) + 1.
  3. This has the form 2k + 1, so ab is odd. ∎
How to write it: Say “Let a, b be …” → write using the definition (2m, 2m + 1) → simplify → conclusion with ∎.
Exam tip: Start every proof with the definition (even = 2m, odd = 2m + 1).
Q21

Prove by contraposition : if n² is even, then n is even. 5 marks ★★★★☆ Very important

Answer

Indirect proof by contraposition : to prove p → q, prove the equivalent statement ¬q → ¬p.

Here p : n² is even, q : n is even. We prove : if n is odd, then n² is odd.

  1. Let n be odd, n = 2k + 1.
  2. n² = (2k + 1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1.
  3. So n² is odd.

The contrapositive is proved, so the original statement is true : if n² is even then n is even. ∎

How to write it: State the plan (prove ¬q → ¬p) → write the contrapositive → proof → conclusion.
Exam tip: Use this method when the conclusion is easier to attack through its negation.
Q22

Using proof by contradiction, prove that √2 is irrational. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Proof by contradiction : assume the statement is false and reach an impossible result.

  1. Assume √2 is rational. Then √2 = a/b, where a, b are integers with no common factor, b ≠ 0.
  2. Squaring : 2 = a²/b², so a² = 2b².
  3. So a² is even, hence a is even. Let a = 2c.
  4. Then 4c² = 2b², so b² = 2c². So b² is even, hence b is even.
  5. Both a and b are even, so 2 is a common factor. This contradicts “no common factor”.

Our assumption is wrong. Hence √2 is irrational. ∎

How to write it: Assume the opposite → a/b in lowest terms → a² = 2b² → both even → contradiction → conclusion.
Exam tip: This proof was asked in November 2025 (II (c)). Write all 5 steps.
Q23

Prove by contradiction that there are infinitely many prime numbers. 5 marks ★★★☆☆ Important

Answer

  1. Assume there are only finitely many primes : p₁, p₂, …, pₙ.
  2. Form N = p₁ · p₂ · … · pₙ + 1.
  3. N is greater than 1, so it has a prime factor p. This p must be one of p₁, …, pₙ.
  4. Then p divides the product p₁ · … · pₙ and also divides N, so p divides N − (p₁ · … · pₙ) = 1. This is impossible, since no prime divides 1.

This is a contradiction. Hence there are infinitely many primes. ∎

Check : for the primes 2, 3, 5 : N = 31, which is prime (not in the list), so the list was incomplete.

How to write it: Assume finite list → build N = product + 1 → show a prime p divides 1 → contradiction.
Exam tip: The key step: p divides both N and the product, so p divides 1.
Q24

What is a counter-example? Disprove : “If n is a positive integer, then n² + n + 41 is prime”. 3 marks ★★★☆☆ Important

Answer

A counter-example is one case that makes a ∀-statement false. One counter-example is enough to disprove it.

Take n = 41 : 41² + 41 + 41 = 41(41 + 1 + 1) = 41 × 43 = 1763. This is divisible by 41 and 43, so it is not prime. Hence the statement is false. (It is true for n = 1, …, 39, which shows that checking examples does not prove a statement.)

How to write it: Define counter-example → choose the value → show the calculation → “hence the statement is false”.
Exam tip: Examples never prove a general statement, but one counter-example disproves it.

Q26

Short answers : (a) Define a compound proposition. (b) Find the truth value of (p → q) ∧ ¬q when p = T, q = F. (c) State the principle of contradiction. 2 marks ★★☆☆☆ Good to know Asked in Nov 2025

Answer

(a) A compound proposition is formed by joining simple propositions with connectives (¬, ∧, ∨, →, ↔).

(b) p → q = (T → F) = F, ¬q = T, so (p → q) ∧ ¬q = F ∧ T = False.

(c) A statement and its negation cannot both be true : ¬(p ∧ ¬p) is a tautology.

How to write it: One or two lines for each part.
Exam tip: For 2-mark questions write a definition and one example in 3–4 lines.
