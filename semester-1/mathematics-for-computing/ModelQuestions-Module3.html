Q1

What is a binary operation? Explain closure with examples. 3 marks ★★★☆☆ Important

Answer

A binary operation ∗ on a non-empty set S is a rule that combines any two elements a, b of S and gives one element a ∗ b. The set S is closed under ∗ if a ∗ b ∈ S for all a, b ∈ S.

Set and operationClosed?Reason
(ℤ, +)Yessum of two integers is an integer
(ℕ, −)No2 − 5 = −3 ∉ ℕ
({0, 1}, ×)Yes0·0, 0·1, 1·1 are in the set
(odd integers, +)No3 + 5 = 8 is even
(ℤ, ÷)No1 ÷ 2 is not an integer
How to write it: Definition → closure → table of 4–5 examples, with a reason for each.
Exam tip: To show “not closed”, one example is enough.
Q2

What is an algebraic structure? Explain the properties : commutative, associative, identity and inverse. 5 marks ★★★★☆ Very important

Answer

An algebraic structure (S, ∗) is a non-empty set S with one or more binary operations.

PropertyMeaningExample
Commutativea ∗ b = b ∗ a+ and × on ℤ; but − is not (3 − 2 ≠ 2 − 3)
Associative(a ∗ b) ∗ c = a ∗ (b ∗ c)+ and × on ℤ; but − is not
Identity ea ∗ e = e ∗ a = a0 for +, 1 for ×
Inverse of aa ∗ a⁻¹ = a⁻¹ ∗ a = e−a for +, 1/a for × (a ≠ 0)

Structures are named by the properties they satisfy : semigroup (closure + associative), monoid (+ identity), group (+ inverses).

How to write it: Definition of structure → table of four properties with meaning and example → the hierarchy line.
Exam tip: Remember the order : closure, associative, identity, inverse.
Q3

Define a semigroup with examples. Is (ℤ, −) a semigroup? 3 marks ★★★☆☆ Important

Answer

A semigroup (S, ∗) is a non-empty set with a binary operation that is closed and associative.

  • (ℕ, +), (ℤ, ×) and (ℝ, +) are semigroups.
  • (ℤ, −) is not a semigroup : (5 − 3) − 1 = 1 but 5 − (3 − 1) = 3, so − is not associative.
How to write it: Definition (closure + associative) → two examples → one non-example with a numerical check.
Exam tip: Test associativity with numbers when you want to disprove it.
Q4

Define a monoid with examples. Show that (ℕ, +) is a semigroup but not a monoid, where ℕ = {1, 2, 3, …}. 3 marks ★★★☆☆ Important

Answer

A monoid is a semigroup with an identity element e such that a ∗ e = e ∗ a = a for all a.

  • (ℕ ∪ {0}, +) is a monoid with identity 0. (ℤ, ×) is a monoid with identity 1.
  • (ℕ, +) with ℕ = {1, 2, 3, …} is closed and associative, so it is a semigroup. But there is no identity : we would need e with a + e = a, giving e = 0 ∉ ℕ. So it is not a monoid.
How to write it: Definition (semigroup + identity) → examples → show the identity is missing for ℕ.
Exam tip: Always state the identity element when you say “monoid”.
Q5

State the group axioms. 2 marks ★★★★★ Must study Asked in Nov 2025

Answer

A non-empty set G with a binary operation ∗ is a group if :

  1. Closure : a ∗ b ∈ G for all a, b ∈ G.
  2. Associativity : (a ∗ b) ∗ c = a ∗ (b ∗ c).
  3. Identity : there is e ∈ G with a ∗ e = e ∗ a = a.
  4. Inverse : for each a there is a⁻¹ ∈ G with a ∗ a⁻¹ = a⁻¹ ∗ a = e.

If also a ∗ b = b ∗ a, the group is abelian. Example : (ℤ, +).

How to write it: Four numbered axioms, then the definition of abelian with one example.
Exam tip: Write all four axioms with their formulas. This was asked in November 2025 (I (e)).
Q6

Show that G = {1, 3, 5, 7} is a group under multiplication modulo 8. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Operation table (× mod 8) :

×₈1357
11357
33175
55713
77531
  1. Closure : all entries of the table are in {1, 3, 5, 7}. ✔
  2. Associativity : multiplication of integers is associative, and so is mod 8. ✔
  3. Identity : the row and column of 1 repeat the elements, so e = 1. ✔
  4. Inverse : 1·1 = 3·3 = 5·5 = 7·7 = 1 (mod 8), so each element is its own inverse. ✔

All axioms hold, so G is a group. The table is symmetric, so G is abelian. (It is called the Klein four-group.)

How to write it: Make the table → check the four axioms one by one, referring to the table → conclusion.
Exam tip: This group appeared in November 2025 (VI (a)). Do the check honestly : every axiom holds.
Q7

Show that (ℤ₄, +₄) is a group. Write its operation table and the inverse of each element. 5 marks ★★★★☆ Very important

Answer

ℤ₄ = {0, 1, 2, 3} with addition modulo 4.

+₄0123
00123
11230
22301
33012
  1. Closure : every entry is in {0, 1, 2, 3}. ✔
  2. Associativity : addition mod 4 is associative. ✔
  3. Identity : 0. ✔
  4. Inverses : 0⁻¹ = 0, 1⁻¹ = 3, 2⁻¹ = 2, 3⁻¹ = 1. ✔

So (ℤ₄, +₄) is an abelian group of order 4. In general (ℤₙ, +ₙ) is a group for every n.

Exam tip: In ℤₙ the inverse of a is n − a (for a ≠ 0).
Q8

Prove that in a group the identity is unique, the inverse of an element is unique, and (ab)⁻¹ = b⁻¹a⁻¹. 5 marks ★★★★☆ Very important

Answer

  1. Identity unique : let e and e′ be identities. Then e = e·e′ (e′ is an identity) = e′ (e is an identity). So e = e′.
  2. Inverse unique : let b and c be inverses of a. Then b = be = b(ac) = (ba)c = ec = c.
  3. (ab)⁻¹ = b⁻¹a⁻¹ : (ab)(b⁻¹a⁻¹) = a(bb⁻¹)a⁻¹ = aea⁻¹ = aa⁻¹ = e, and similarly (b⁻¹a⁻¹)(ab) = e. So b⁻¹a⁻¹ is the inverse of ab.

Also the cancellation law holds : ab = ac ⇒ b = c (multiply by a⁻¹ on the left). ∎

How to write it: Three short proofs, each starting from the definition. Finish with ∎.
Exam tip: The trick for uniqueness : assume two, and show they are equal.
Q9

Prove that a group G in which a² = e for every a ∈ G is abelian. 3 marks ★★★☆☆ Important

Answer

  1. a² = e means a⁻¹ = a for every element of G.
  2. Take any a, b ∈ G. Then ab ∈ G, so (ab)⁻¹ = ab.
  3. But (ab)⁻¹ = b⁻¹a⁻¹ = ba (because every element is its own inverse).
  4. So ab = ba for all a, b. Hence G is abelian. ∎

Example : the Klein four-group {1, 3, 5, 7} under × mod 8.

How to write it: Use a⁻¹ = a → (ab)⁻¹ = ab and (ab)⁻¹ = ba → conclude ab = ba.
Exam tip: The fact (ab)⁻¹ = b⁻¹a⁻¹ is the key step.
Q10

Define a subgroup. State the subgroup test and prove that 2ℤ is a subgroup of (ℤ, +). 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A non-empty subset H of a group G is a subgroup (H ≤ G) if H is itself a group under the operation of G.

One-step test : H ≠ ∅ and a ∗ b⁻¹ ∈ H for all a, b ∈ H (for addition : a − b ∈ H).

Proof for H = 2ℤ (even integers) :

  1. 0 = 2·0 ∈ H, so H is non-empty and has the identity.
  2. Let a = 2m and b = 2n. Then a − b = 2(m − n), which is even, so a − b ∈ H.

By the subgroup test, 2ℤ ≤ ℤ. Similarly nℤ ≤ ℤ for every integer n. ∎

How to write it: Definition → test → proof in two numbered steps.
Exam tip: This was asked in November 2025 (VI (b)). Mention closure and inverses, or the one-step test.
Q11

Find all subgroups of (ℤ₆, +₆). Is the union of two subgroups always a subgroup? 3 marks ★★★☆☆ Important

Answer

ℤ₆ = {0, 1, 2, 3, 4, 5}. Subgroups :

  • {0} (trivial subgroup)
  • {0, 3} (generated by 3)
  • {0, 2, 4} (generated by 2)
  • ℤ₆ itself (generated by 1 or 5)

The orders 1, 2, 3, 6 divide 6, as Lagrange's theorem says.

Union : not always. H = {0, 2, 4} and K = {0, 3} are subgroups, but H ∪ K = {0, 2, 3, 4} is not closed : 2 + 3 = 5 ∉ H ∪ K.

How to write it: List subgroups by generator → counter-example for the union.
Exam tip: The subgroup of a cyclic group is generated by one element.
Q12

Define a cyclic group, a generator and the order of an element. Show that ℤ₆ is cyclic and find all its generators. 5 marks ★★★★☆ Very important

Answer

A group G is cyclic if there is an element g such that every element of G is a power (or multiple) of g. Then g is a generator and G = ⟨g⟩. The order of an element a is the smallest positive n with aⁿ = e (n·a = 0 in additive notation).

In ℤ₆ : multiples of 1 are 1, 2, 3, 4, 5, 0, so ⟨1⟩ = ℤ₆. Hence ℤ₆ is cyclic.

a012345
order163236

The generators are the elements of order 6 : 1 and 5. (In general a is a generator of ℤₙ if gcd(a, n) = 1.)

How to write it: Definitions → show ⟨1⟩ = ℤ₆ → table of orders → list generators.
Exam tip: Generators of ℤₙ : numbers coprime to n.
Q13

Prove that every cyclic group is abelian. Find the order of each element of the group {1, 3, 5, 7} under × mod 8. Is it cyclic? 5 marks ★★★☆☆ Important

Answer

Proof : let G = ⟨g⟩. Take a = gᵐ and b = gⁿ. Then ab = gᵐgⁿ = gᵐ⁺ⁿ = gⁿ⁺ᵐ = gⁿgᵐ = ba. So G is abelian. ∎

Orders in {1, 3, 5, 7} (× mod 8) : 1 has order 1; 3² = 9 = 1, so order 2; 5² = 25 = 1, order 2; 7² = 49 = 1, order 2. No element has order 4, so no element generates the group. It is not cyclic, even though it is abelian.

How to write it: Proof with gᵐ, gⁿ → list orders → conclude not cyclic.
Exam tip: Abelian does not mean cyclic.
Q14

What is a permutation? Write the cycle notation and find the product of the permutations α = (1 2) and β = (2 3) in S₃. 3 marks ★★★★☆ Very important

Answer

A permutation of a set is a one-one onto function from the set to itself. The permutations of {1, 2, 3} form the group S₃ of order 3! = 6. A cycle (1 2 3) means 1→2, 2→3, 3→1.

Product α∘β (first β, then α) :

  • 1 → β → 1 → α → 2, so 1 → 2
  • 2 → β → 3 → α → 3, so 2 → 3
  • 3 → β → 2 → α → 1, so 3 → 1

So α∘β = (1 2 3). And β∘α = (1 3 2), which is different : the product is not commutative.

How to write it: Define a permutation and a cycle → trace each element through → write the product in cycle form.
Exam tip: Decide the order (right to left) at the start and say it in your answer.
Q15

Write all elements of S₃ and its composition table. Show that S₃ is a non-abelian group. 5 marks ★★★★☆ Very important

Answer

S₃ = {e, (1 2), (1 3), (2 3), (1 2 3), (1 3 2)}. Composition table (p∘q = first q, then p) :

∘e(2 3)(1 2)(1 2 3)(1 3 2)(1 3)
ee(2 3)(1 2)(1 2 3)(1 3 2)(1 3)
(2 3)(2 3)e(1 3 2)(1 3)(1 2)(1 2 3)
(1 2)(1 2)(1 2 3)e(2 3)(1 3)(1 3 2)
(1 2 3)(1 2 3)(1 2)(1 3)(1 3 2)e(2 3)
(1 3 2)(1 3 2)(1 3)(2 3)e(1 2 3)(1 2)
(1 3)(1 3)(1 3 2)(1 2 3)(1 2)(2 3)e
  • Closure : every entry is one of the six permutations. ✔
  • Associative : composition of functions is associative. ✔
  • Identity : e. ✔
  • Inverse : (1 2)⁻¹ = (1 2), (1 3)⁻¹ = (1 3), (2 3)⁻¹ = (2 3), (1 2 3)⁻¹ = (1 3 2). ✔

It is not abelian : (1 2)∘(2 3) = (1 2 3) but (2 3)∘(1 2) = (1 3 2). So S₃ is the smallest non-abelian group, of order 6.

How to write it: List the six elements → table → axioms in one line each → one pair that does not commute.
Exam tip: Learn the six elements. The table is long, so write it neatly in rows.
Q16

What are even and odd permutations? Show that the even permutations of S₃ form a subgroup. 3 marks ★★☆☆☆ Good to know

Answer

Every permutation is a product of transpositions (2-cycles). It is even if the number of transpositions is even, and odd otherwise. A cycle of length k is even if k is odd.

In S₃ : e is even; (1 2), (1 3), (2 3) are odd; (1 2 3) = (1 3)(1 2) and (1 3 2) are even.

The set A₃ = {e, (1 2 3), (1 3 2)} is closed ((1 2 3)² = (1 3 2), (1 2 3)³ = e), contains e and inverses, so A₃ is a subgroup of S₃ of order 3 (the alternating group).

How to write it: Definitions → classify the six elements → list A₃ and check it is a subgroup.
Exam tip: The product of two odd permutations is even.
Q17

Define homomorphism, kernel and image of a group homomorphism with examples. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Let (G, ∗) and (H, ∘) be groups. A function f : G → H is a homomorphism if f(a ∗ b) = f(a) ∘ f(b) for all a, b ∈ G. The kernel is Ker f = {x ∈ G : f(x) = e_H}. The image is Im f = {f(x) : x ∈ G}.

Example 1 : f : (ℤ, +) → (ℤ₅, +₅), f(x) = x mod 5. f(7 + 8) = f(15) = 0 and f(7) +₅ f(8) = 2 +₅ 3 = 0 ✔. Ker f = 5ℤ, Im f = ℤ₅.

Example 2 : f : (ℝ, +) → (ℝ⁺, ×), f(x) = eˣ. f(x + y) = eˣ⁺ʸ = eˣ · eʸ ✔. Ker f = {0}.

Properties : f(e) = e′ and f(a⁻¹) = f(a)⁻¹. The kernel is a subgroup of G. f is one-one iff Ker f = {e}.

How to write it: Definition → kernel and image → two examples with the check f(a ∗ b) = f(a) ∘ f(b) → properties.
Exam tip: Always check the condition with actual numbers in the example. It was asked in November 2025 (VII (a)).
Q18

Show that f : ℤ → ℤ, f(x) = 3x is a homomorphism and find its kernel. Is f(x) = 3x + 1 a homomorphism? 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

  1. f(x + y) = 3(x + y) = 3x + 3y = f(x) + f(y). So f is a homomorphism.
  2. Kernel : f(x) = 0 ⇒ 3x = 0 ⇒ x = 0. So Ker f = {0}, and f is one-one.
  3. Image : Im f = 3ℤ = {…, −3, 0, 3, 6, …}, so f is not onto ℤ.

f(x) = 3x + 1

f(1 + 2) = f(3) = 10, but f(1) + f(2) = 4 + 7 = 11. They are different, and f(0) = 1 ≠ 0. So f(x) = 3x + 1 is not a homomorphism. (It is a linear function but not a group homomorphism because of the constant term.)

How to write it: Show f(x + y) = f(x) + f(y) → solve f(x) = 0 for the kernel → find the image → test the second function with numbers.
Exam tip: This question is related to VII (b) of November 2025. A homomorphism must send identity to identity.
Q19

Prove that the kernel of a homomorphism f : G → H is a subgroup of G. 3 marks ★★★☆☆ Important

Answer

  1. f(e) = e′ , so e ∈ Ker f. Hence Ker f ≠ ∅.
  2. Let a, b ∈ Ker f, i.e. f(a) = f(b) = e′. Then f(ab⁻¹) = f(a) f(b)⁻¹ = e′ e′⁻¹ = e′.
  3. So ab⁻¹ ∈ Ker f. By the subgroup test, Ker f ≤ G. ∎

Further, Ker f = {e} exactly when f is one-one.

How to write it: Use the one-step subgroup test → compute f(ab⁻¹) → conclude.
Exam tip: f(b⁻¹) = f(b)⁻¹ is a standard property to quote.
Q20

Define isomorphism of groups. Show that (ℝ, +) ≅ (ℝ⁺, ×). 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A homomorphism f : G → H that is one-one and onto is an isomorphism; then G ≅ H (G and H have the same structure).

Define f(x) = eˣ.

  1. Homomorphism : f(x + y) = eˣ⁺ʸ = eˣ · eʸ = f(x) · f(y). ✔
  2. One-one : eˣ = eʸ ⇒ x = y (take ln). ✔
  3. Onto : for any y > 0, x = ln y gives eˣ = y. ✔

Hence (ℝ, +) ≅ (ℝ⁺, ×). Another example : (ℤ, +) ≅ (2ℤ, +) by f(n) = 2n.

How to write it: Definition (homomorphism + one-one + onto) → define the map → check three conditions in numbered steps.
Exam tip: Isomorphism = Homomorphism + One-one + Onto. Write this line in the answer.
Q21

Show that the groups (ℤ₄, +₄) and ({1, 3, 5, 7}, ×₈) are not isomorphic. 3 marks ★★★☆☆ Important

Answer

Isomorphic groups have the same number of elements of each order.

  • In (ℤ₄, +₄) : the elements 1 and 3 have order 4.
  • In ({1, 3, 5, 7}, ×₈) : every non-identity element has order 2 (3² = 5² = 7² = 1).

The orders do not match, so the groups are not isomorphic, though both have 4 elements. (ℤ₄ is cyclic; the other is the Klein four-group, which is not cyclic.)

How to write it: State the invariant (order of elements) → compare the two groups → conclude.
Exam tip: To disprove an isomorphism, compare a property that isomorphism preserves (order, cyclic, abelian).
Q22

How to write it: One line per part.
