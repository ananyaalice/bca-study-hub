Chapter 1 : Matrices – Types and Operations

1.1 Definition

A matrix is a rectangular array of numbers arranged in m rows and n columns. Its order is m × n, and aᵢⱼ denotes the entry in row i, column j. Two matrices are equal only if they have the same order and all corresponding entries are equal.

1.3 Operations on matrices

  • Addition and subtraction : only for matrices of the same order, done entry by entry. Addition is commutative and associative.
  • Scalar multiplication : kA multiplies every entry of A by k.
  • Matrix multiplication : AB is defined only when the number of columns of A = number of rows of B. If A is m × n and B is n × p, then AB is m × p, and (AB)ᵢⱼ = Σₖ aᵢₖ bₖⱼ (row i of A dotted with column j of B).
  • Transpose : Aᵀ swaps rows and columns, so (Aᵀ)ᵢⱼ = Aⱼᵢ.
  • Trace : tr(A) is the sum of the diagonal entries of a square matrix.
A is m × n→B is n × p→AB is m × p

Properties to remember

  • (AB)C = A(BC) and A(B + C) = AB + AC, and AI = IA = A.
  • Multiplication is not commutative : in general AB ≠ BA.
  • AB = O does not imply A = O or B = O. Also AB = AC does not imply B = C.
  • (Aᵀ)ᵀ = A, (A + B)ᵀ = Aᵀ + Bᵀ, (kA)ᵀ = kAᵀ, (AB)ᵀ = BᵀAᵀ.
  • tr(A + B) = tr A + tr B, tr(kA) = k tr A, tr(AB) = tr(BA).
  • Every square matrix is the sum of a symmetric and a skew-symmetric matrix : A = ½(A + Aᵀ) + ½(A − Aᵀ).

Example 1 : multiplication is not commutative

Let A = 1234 and B = 0110.

  • AB : row 1 is (1·0 + 2·1, 1·1 + 2·0) = (2, 1); row 2 is (3·0 + 4·1, 3·1 + 4·0) = (4, 3). So AB = 2143
  • BA : row 1 is (0·1 + 1·3, 0·2 + 1·4) = (3, 4); row 2 is (1·1 + 0·3, 1·2 + 0·4) = (1, 2). So BA = 3412, which is different from AB.

Example 2 : product of a 2×3 and a 3×2 matrix

Let C = 102-131 (order 2×3) and D = 312110 (order 3×2). Then CD has order 2×2.

  • Row 1 : (1·3 + 0·2 + 2·1, 1·1 + 0·1 + 2·0) = (5, 1)
  • Row 2 : (−1·3 + 3·2 + 1·1, −1·1 + 3·1 + 1·0) = (4, 2)
  • So CD = 5142

Chapter 2 : Determinants

The determinant is a single number det(A) or |A|, defined only for square matrices. It tells us whether a matrix is invertible and how the transformation scales area or volume.

2.1 Computing determinants

  • 2 × 2 : | a b ; c d | = ad − bc.
  • 3 × 3 (cofactor expansion along row 1) : det A = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃, where the minor Mᵢⱼ is the determinant left after deleting row i and column j, and the cofactor is Cᵢⱼ = (−1)ⁱ⁺ʲ Mᵢⱼ.
  • The sign pattern for cofactors is +−+−+−+−+. You may expand along any row or column, so choose the one with the most zeros.
  • Triangular or diagonal matrices : the determinant is the product of the diagonal entries.

Example 3 : a 3 × 3 determinant

Find det A for A = 213041125.

  • Expanding along row 1 : det A = 2(4·5 − 1·2) − 1(0·5 − 1·1) + 3(0·2 − 4·1)
  • = 2(18) − 1(−1) + 3(−4) = 36 + 1 − 12 = 25
  • Since det A ≠ 0, the matrix is non-singular (invertible).

Chapter 3 : Inverse of a Matrix

A square matrix A has an inverse A⁻¹ if AA⁻¹ = A⁻¹A = I. The inverse exists exactly when det A ≠ 0, and it is unique when it exists.

3.1 Methods

  • Method 1 : adjoint formula. A⁻¹ = adj(A) / det(A), where adj(A) is the transpose of the cofactor matrix.
  • Method 2 : Gauss–Jordan. Write [A | I] and apply row operations until the left side becomes I. The right side is then A⁻¹. This is the more efficient method for larger matrices.

★ 2 × 2 shortcut ★

If A = abcd and det A = ad − bc ≠ 0, then

A⁻¹ = (1 / (ad − bc)) · d−b−ca

(swap a and d, change the signs of b and c, divide by the determinant)

3.2 Properties

  • (A⁻¹)⁻¹ = A, and (Aᵀ)⁻¹ = (A⁻¹)ᵀ.
  • (AB)⁻¹ = B⁻¹A⁻¹ (the order reverses).
  • (kA)⁻¹ = (1/k) A⁻¹ for k ≠ 0.
  • The system AX = B with A invertible has the unique solution X = A⁻¹B.

Example 4 : inverse using the adjoint

Find the inverse of A = 123014560.

  • det A = 1(0 − 24) − 2(0 − 20) + 3(0 − 5) = −24 + 40 − 15 = 1
  • Cofactors : C₁₁ = −24, C₁₂ = 20, C₁₃ = −5, C₂₁ = 18, C₂₂ = −15, C₂₃ = 4, C₃₁ = 5, C₃₂ = −4, C₃₃ = 1.
  • Cofactor matrix : -2420-518-1545-41
  • adj A = transpose of the cofactor matrix : -2418520-15-4-541
  • Since det A = 1, A⁻¹ = adj A.
  • Check : row 1 of A times column 1 of A⁻¹ gives 1(−24) + 2(20) + 3(−5) = 1, as required.

Chapter 4 : Rank and Echelon Form

4.1 Elementary row operations

  • Swap two rows (Rᵢ ↔ Rⱼ).
  • Scale a row by a non-zero constant (Rᵢ → kRᵢ).
  • Replace a row by itself plus a multiple of another row (Rᵢ → Rᵢ + kRⱼ).

These operations do not change the solution set of a system, the row space, or the rank of a matrix.

4.2 Echelon forms

  • Row echelon form (REF) : all zero rows are at the bottom; the first non-zero entry (the pivot) of each row lies strictly to the right of the pivot in the row above.
  • Reduced row echelon form (RREF) : REF where, in addition, every pivot equals 1 and is the only non-zero entry in its column. The RREF of a matrix is unique.

4.3 Rank

The rank of a matrix is the number of non-zero rows in its echelon form. Equivalently, it is the maximum number of linearly independent rows (or columns), and also the order of the largest square submatrix with non-zero determinant.

Rank facts

  • rank(A) ≤ min(m, n) for an m × n matrix, and rank(A) = rank(Aᵀ).
  • An n × n matrix is invertible if and only if its rank is n (full rank).
  • rank(AB) ≤ min(rank A, rank B).
  • Elementary row operations do not change the rank.

Example 6 : finding the rank

Find the rank of A = 12-1324103603.

  • R₂ → R₂ − 2R₁ gives (0, 0, 3, −6).
  • R₃ → R₃ − 3R₁ gives (0, 0, 3, −6).
  • Then R₃ → R₃ − R₂ gives (0, 0, 0, 0).
  • The echelon form is 12-13003-60000, which has 2 non-zero rows. So rank(A) = 2.

Chapter 5 : Solving Linear Equations

A system of m equations in n unknowns can be written as AX = B, where A is the coefficient matrix, X the column of unknowns and B the column of constants. The augmented matrix is [A | B].

5.1 Gaussian elimination

Reduce the augmented matrix to row echelon form using row operations (forward elimination), then solve from the last equation upwards (back substitution). Gauss–Jordan elimination continues to RREF so the solution can be read off directly. In practice, choosing the largest available pivot (partial pivoting) improves numerical stability.

Write [A | B]→Forward elimination to REF→Compare ranks→Back substitution

Example 7 : unique solution

Solve x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2.

Augmented matrix [A | B] : 11162-11312-12

  • R₂ → R₂ − 2R₁ and R₃ → R₃ − R₁ : 11160-3-1-901-2-4
  • Swap R₂ ↔ R₃ : 111601-2-40-3-1-9
  • R₃ → R₃ + 3R₂ (echelon form reached) : 111601-2-400-7-21
  • Back substitution : −7z = −21 gives z = 3. Then y − 2(3) = −4 gives y = 2. Then x + 2 + 3 = 6 gives x = 1.
  • Solution : (x, y, z) = (1, 2, 3). Here rank(A) = rank([A | B]) = 3, matching the unique-solution case.

Example 8 : infinitely many solutions

Solve x + y + z = 6, x + 2y + 3z = 14, 2x + 3y + 4z = 20.

  • The third equation is the sum of the first two, so it gives no new information.
  • After R₂ → R₂ − R₁ we get y + 2z = 8, and rank(A) = rank([A | B]) = 2 < 3, so there is one free variable.
  • Let z = t. Then y = 8 − 2t and x = 6 − y − z = −2 + t.
  • Solution : (x, y, z) = (−2 + t, 8 − 2t, t) for any real t. For t = 0 this gives (−2, 8, 0), which satisfies all three equations.

Example 9 : no solution

x + y = 2 and x + y = 3. Here rank(A) = 1 but rank([A | B]) = 2, so the system is inconsistent.

Chapter 6 : Vector Spaces, Basis and Dimension

6.1 Vector space

A vector space over ℝ is a set V with addition and scalar multiplication such that, for all u, v, w in V and scalars a, b :

  • V is closed under addition and under scalar multiplication.
  • u + v = v + u, and (u + v) + w = u + (v + w).
  • There is a zero vector 0 with v + 0 = v, and every v has an additive inverse −v.
  • a(u + v) = au + av, (a + b)v = av + bv, a(bv) = (ab)v, and 1·v = v.

Standard examples : ℝⁿ; the set Mₘ×ₙ of all m × n matrices; the set Pₙ of all polynomials of degree ≤ n; the set of all continuous functions on an interval.

6.2 Subspaces

A non-empty subset W of V is a subspace if it is closed under addition and scalar multiplication (equivalently : 0 is in W, u + v is in W, and cu is in W).

Every subspace contains the zero vector, which gives a quick way to rule things out : the set {(x, y) : x + y = 1} is not a subspace because (0, 0) is not in it.

6.3 Span, independence, basis, dimension

  • Span : span{v₁, …, vₖ} is the set of all linear combinations c₁v₁ + … + cₖvₖ.
  • Linearly independent : c₁v₁ + … + cₖvₖ = 0 forces every cᵢ = 0. Otherwise the vectors are dependent.
  • Basis : a set of vectors that is linearly independent and spans the space.
  • Dimension : the number of vectors in any basis. All bases of a space have the same size.

Example 10 : testing a basis

Do v₁ = (1, 2, 3), v₂ = (0, 1, 4), v₃ = (5, 6, 0) form a basis of ℝ³?

  • det 123014560 = 1(0 − 24) − 2(0 − 20) + 3(0 − 5) = −24 + 40 − 15 = 1 ≠ 0.
  • So the vectors are independent, and since there are three of them in ℝ³, they form a basis.

Here the vectors are the rows of the matrix (the same matrix as in Example 4).

Example 11 : basis and dimension of a subspace

Let W = {(x, y, z) : x + y + z = 0}. Any element has the form (−y − z, y, z) = y(−1, 1, 0) + z(−1, 0, 1).

  • So a basis is {(−1, 1, 0), (−1, 0, 1)} and dim W = 2 (one equation removes one degree of freedom from ℝ³).

Example 12 : null space and rank–nullity

For A = 123246, solving AX = O reduces to the single equation x + 2y + 3z = 0, with y and z free.

  • Basis of the null space : (−2, 1, 0) and (−3, 0, 1), so nullity = 2.
  • The rank is 1 (row 2 is twice row 1).
  • Check : rank + nullity = 1 + 2 = 3 = number of columns ✔

Chapter 7 : Linear Transformations

7.1 Definition

A map T : V → W between vector spaces is a linear transformation if, for all u, v in V and every scalar c :

  • T(u + v) = T(u) + T(v) (additivity)
  • T(cu) = cT(u) (homogeneity)

Consequences : T(0) = 0, and T(c₁v₁ + … + cₖvₖ) = c₁T(v₁) + … + cₖT(vₖ). So a linear map is completely determined by what it does to a basis. The map T(x) = x + 1 is not linear because T(0) = 1 ≠ 0.

7.2 Matrix of a linear transformation

Every linear map T : ℝⁿ → ℝᵐ is multiplication by an m × n matrix A, so T(x) = Ax. The columns of A are the images of the standard basis vectors : A = [T(e₁) | T(e₂) | … | T(eₙ)].

Example 13 : finding the matrix

T : ℝ² → ℝ² is given by T(x, y) = (2x + y, x − 3y). Then T(e₁) = T(1, 0) = (2, 1) and T(e₂) = T(0, 1) = (1, −3).

So the matrix is A = 211-3.

Check : T(1, 2) = (2 + 2, 1 − 6) = (4, −5), and A·(1, 2)ᵀ = (2·1 + 1·2, 1·1 − 3·2) = (4, −5) ✔

7.3 Kernel and image

  • Kernel (null space) : ker T = {v : T(v) = 0}, a subspace of the domain. Its dimension is the nullity.
  • Image (range) : Im T = {T(v)}, a subspace of the codomain. Its dimension is the rank.
  • Rank–nullity theorem : dim(domain) = dim(ker T) + dim(Im T).
  • T is one-one (injective) exactly when ker T = {0}; T is onto (surjective) when Im T equals the whole codomain. A bijective linear map is an isomorphism.

Example 14 : kernel and image

T : ℝ³ → ℝ² is T(x, y, z) = (x − y, y + z), with matrix 1-10011.

  • Kernel : x − y = 0 and y + z = 0 give x = y and z = −y, so ker T = span{(1, 1, −1)} and nullity = 1.
  • The two rows are independent, so rank = 2 and Im T = ℝ².
  • Check : 3 = 1 + 2 ✔
  • Since the kernel is non-zero, T is not one-one, though it is onto.

Chapter 8 : Eigenvalues and Eigenvectors

8.1 Definitions

For a square matrix A, a non-zero vector v is an eigenvector with eigenvalue λ if Av = λv.

Geometrically, A only stretches or flips v along its own line (and shrinks it to zero if λ = 0).

Rewriting gives (A − λI)v = 0, which has a non-zero solution only when det(A − λI) = 0. This is the characteristic equation, a polynomial of degree n in λ.

8.2 Method

Step 1 : solve det(A − λI) = 0 for λ→Step 2 : for each λ solve (A − λI)v = 0

Example 15 : a 2 × 2 matrix

Find the eigenvalues and eigenvectors of A = 4123.

  • det(A − λI) = (4 − λ)(3 − λ) − 2 = λ² − 7λ + 10 = (λ − 5)(λ − 2). So λ = 5 and λ = 2.
  • For λ = 5 : (A − 5I) = -112-2, giving x = y. Eigenvector v = (1, 1).
  • For λ = 2 : (A − 2I) = 2121, giving 2x + y = 0. Eigenvector v = (1, −2).
  • Checks : sum 5 + 2 = 7 = trace; product 5 × 2 = 10 = det A = 12 − 2; and A(1, −2)ᵀ = (2, −4)ᵀ = 2(1, −2)ᵀ.
  • A² − 7A + 10I = 1871411 − 2871421 + 100010 = O (the matrix satisfies its own characteristic equation).

Example 16 : a symmetric 3 × 3 matrix

Let A = 200034049. Expanding along row 1 : det(A − λI) = (2 − λ)[(3 − λ)(9 − λ) − 16] = (2 − λ)(λ² − 12λ + 11) = (2 − λ)(λ − 1)(λ − 11).

EigenvalueEigenvectorWorking
λ = 2(1, 0, 0)(A − 2I) gives y + 4z = 0 and 4y + 7z = 0, so y = z = 0 and x is free
λ = 1(0, −2, 1)(A − I) gives x = 0 and y + 2z = 0
λ = 11(0, 1, 2)(A − 11I) gives x = 0 and −8y + 4z = 0, so z = 2y

Checks : trace 14 = 2 + 1 + 11 and det A = 22 = 2 × 1 × 11. Because A is symmetric, the eigenvectors are orthogonal, for example (0, −2, 1)·(0, 1, 2) = −2 + 2 = 0.

★ Key Observations ★

  • Sum of eigenvalues = trace; product of eigenvalues = determinant – a quick check.
  • Eigenvalues come from det(A − λI) = 0; eigenvectors from (A − λI)v = 0.
  • Eigenvectors of a symmetric matrix (for different eigenvalues) are orthogonal.

Chapter 9 : Applications

9.1 Computer graphics

  • Points and vectors are stored as coordinate columns, and each transformation (rotation, scaling, reflection, shear) is a matrix multiplication, so an object can be moved by transforming all its vertices at once.
  • Composition : applying T₁ first and then T₂ uses the single matrix A₂A₁ (the first transformation is on the right). Order matters because matrix multiplication is not commutative.
  • Homogeneous coordinates : translation is not linear in ℝ², so a point (x, y) is written as (x, y, 1). A translation by (tₓ, t_y) becomes the 3 × 3 matrix 10tₓ01t_y001, and translation, rotation and scaling can then all be combined by multiplying matrices.
  • 3D graphics : rotation about the z-axis by θ is cos θ−sin θ0sin θcos θ0001. Graphics pipelines (model, view and projection transforms) are chains of 4 × 4 matrices applied to every vertex.

9.2 Data science

  • Data as matrices : a dataset with n samples and d features is an n × d matrix X, and nearly every algorithm reduces to matrix operations on it.
  • Linear regression : the least-squares coefficients satisfy the normal equations (XᵀX)β = Xᵀy, so β = (XᵀX)⁻¹Xᵀy when XᵀX is invertible.
  • Principal Component Analysis (PCA) : the eigenvectors of the covariance matrix give the directions of greatest variance, and each eigenvalue is the variance along its direction. Keeping the top few eigenvectors reduces dimension while preserving most of the information.
  • Singular Value Decomposition (SVD) : any matrix factors as A = UΣVᵀ. Keeping only the largest singular values gives a low-rank approximation, used for image compression, noise reduction and recommender systems.
  • PageRank and Markov chains : the steady-state distribution is an eigenvector of the transition matrix with eigenvalue 1.
  • Neural networks : each layer computes y = Wx + b, which is a matrix–vector product followed by a non-linearity.

★ Exam Points ★

  • AB defined only if columns of A = rows of B. AB ≠ BA in general. (AB)ᵀ = BᵀAᵀ. (AB)⁻¹ = B⁻¹A⁻¹.
  • 2 × 2 determinant ad − bc; 3 × 3 by cofactors with signs + − + / − + − / + − +. det(kA) = kⁿ det A. det(AB) = det A · det B.
  • A⁻¹ exists ⇔ det A ≠ 0. 2 × 2 inverse : swap a, d; change signs of b, c; divide by det. Gauss–Jordan : [A | I] → [I | A⁻¹].
  • Rank = number of non-zero rows in echelon form. Invertible ⇔ rank = n.
  • AX = B : unique if rank A = rank [A|B] = n; infinite if rank A = rank [A|B] < n; none if the ranks differ.
  • Basis = independent + spanning; dimension = number of vectors in a basis. A subspace must contain 0.
  • Linear map : T(u + v) = T(u) + T(v), T(cu) = cT(u), T(0) = 0. Matrix columns = T(eⱼ). Rank–nullity : dim domain = nullity + rank.
  • Eigenvalues : det(A − λI) = 0; sum = trace; product = det. If A has eigenvalue λ, then A² has λ².
