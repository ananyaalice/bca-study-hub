Chapter 1 : Defining and Calling Functions

1.1 What is a function?

  • Function = a named block of code that does one task. It runs only when called
  • Uses: reuse code, break a big program into small parts (modular), easy to read and debug
  • Defined with the keyword def
def function_name(parameters):
    """docstring - optional description"""
    # body (indented)
    return value          # optional

1.2 Calling a function

Chapter 2 : Function Arguments

2.1 Positional arguments

  • Matched by position (order). First value → first parameter
def sub(a, b):
    return a - b
sub(10, 3)      # 7
sub(3, 10)      # -7  (order matters)

2.2 Keyword arguments

  • Passed as name=value. Order does not matter
  • In a call, positional arguments must come before keyword arguments
sub(b=3, a=10)  # 7

2.3 Default arguments

  • Parameter has a default value, used if the caller gives no value
  • Default parameters must come after non-default ones
def greet(name, msg="Hello"):
    print(msg, name)
greet("Ravi")          # Hello Ravi
greet("Ravi", "Hi")    # Hi Ravi

2.4 Variable-length arguments

  • Used when the number of arguments is not known
  • *args → extra positional arguments, collected as a tuple
  • **kwargs → extra keyword arguments, collected as a dictionary
  • Order in definition: normal, default, *args, **kwargs
def total(*nums):
    print(nums)
    return sum(nums)
total(1, 2, 3)
(1, 2, 3)  → returns 6
def info(**data):
    print(data)
info(name="Ravi", age=20)
{'name': 'Ravi', 'age': 20}

Chapter 3 : The return Statement

  • return sends a value back to the caller and ends the function at once
  • Code written after return is not executed
  • No return statement → function gives None
  • Can return many values → returned as a tuple
def add(a, b):
    return a + b
result = add(5, 3)       # 8

def calc(a, b):
    return a + b, a - b
s, d = calc(10, 4)       # s = 14, d = 6
print()return
Only shows a value on screenGives the value back to the caller to store or use

Chapter 4 : Recursion and Lambda

4.1 Recursion

  • Recursion = a function that calls itself
  • Two parts: base case (stops the calls) and recursive case (calls itself with a smaller problem)
  • No base case → RecursionError (maximum recursion depth exceeded; default limit 1000)
def fact(n):
    if n == 0 or n == 1:      # base case
        return 1
    return n * fact(n - 1)    # recursive case
print(fact(5))                # 120
fact(3)→3 × fact(2)→2 × fact(1)→fact(1) = 1⇒ back:2×1 = 2→3×2 = 6

Fibonacci series (n terms)

  • Each term = sum of the previous two. Series: 0, 1, 1, 2, 3, 5, 8 …
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

for i in range(7):
    print(fib(i), end=" ")    # 0 1 1 2 3 5 8
RecursionLoop (iteration)
Function calls itself. Short codeRepeats using for / while
Uses more memory (call stack), usually slowerUses less memory, usually faster

4.2 Lambda expressions

  • Lambda = small anonymous function (no name) written in one line
  • Syntax: lambda arguments: expression
  • Can take many arguments but has only one expression. Result is returned automatically (no return)
  • Used for short, one-time functions
square = lambda x: x * x
print(square(5))                      # 25
add = lambda a, b: a + b
print(add(2, 3))                      # 5
print(list(map(lambda x: x * 2, [1, 2, 3])))   # [2, 4, 6]
def functionlambda
Has a name. Many statements. Uses returnAnonymous. Single expression. No return

Chapter 5 : Scope and Lifetime of Variables

  • Scope = the part of the program where a variable can be used
  • Lifetime = how long the variable exists in memory
Local variableGlobal variable
CreatedInside a functionOutside all functions
ScopeOnly inside that functionWhole program
LifetimeCreated when function is called, destroyed when it endsUntil the program ends
  • Using a local variable outside its function → NameError
  • Assigning inside a function creates a new local variable, even if a global has the same name
  • global keyword → lets a function change the global variable
  • Python searches names in order LEGB:
L – Local→E – Enclosing
(outer function)→G – Global→B – Built-in
x = 10
def f():
    x = 5          # local x
    print(x)       # 5
f()
print(x)           # 10  (global unchanged)

def g():
    global x
    x = 20         # changes global x
g()
print(x)           # 20

Programs (Lab-type)

# prime number check using a function
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    return True
print(is_prime(7))      # True
print(is_prime(10))     # False

★ Key Observations

  • Parameter is in the definition. Argument is in the call
  • No return → function gives None
  • Positional arguments come before keyword arguments in a call
  • Default parameters come after normal parameters
  • *args → tuple. **kwargs → dictionary
  • Recursion must have a base case
  • Lambda has one expression only
  • Local variable cannot be used outside its function
  • Built-in functions need no import. math, random, time need import

Real-Life Applications

  • Functions: write once, use many times – calculators, billing, menu programs
  • Recursion: factorial, Fibonacci, searching folders
  • math: scientific and engineering calculations
  • random: dice and card games, random passwords, sample selection
  • time: delays, timers, measuring program speed

★ Exam Points ★

  • Function is defined with def and runs only when called
  • Four argument types: positional, keyword, default, variable-length
  • *args = tuple of extra positional values. **kwargs = dictionary of extra keyword values
  • return sends a value back and ends the function. Many values → tuple. No return → None
  • Recursion = function calls itself. Needs base case. Else RecursionError
  • Lambda: lambda arguments: expression – anonymous, one expression
  • Local: inside function, destroyed when function ends. Global: outside, lives till program ends
  • global keyword changes a global variable inside a function
  • Built-in: made by Python (print, len, max). User-defined: made with def
  • Import: import m, from m import x, import m as n
  • math: sqrt, pow, ceil, floor, factorial, gcd, pi. random: random, randint, choice. time: time, sleep, ctime
  • randint(a, b) includes both ends. randrange(a, b) excludes b
