Chapter 1 : Working with Files

1.1 Why files?

  • Variables lose data when the program ends. A file stores data permanently on disk
  • Two kinds: text files (readable characters, default) and binary files (images, audio – use mode b)
  • Steps: open → read / write → close

1.2 open() function

file_object = open("data.txt", "r")    # open(filename, mode)
ModeNameMeaning
"r"Read (default)Only reading. File must exist, else FileNotFoundError
"w"WriteCreates file if absent. Erases old content if present
"a"AppendCreates file if absent. Adds new data at the end, old content stays
"r+"Read and writeFile must exist
"x"CreateMakes a new file. Error if it already exists
  • Add b for binary: "rb", "wb"

1.3 Closing a file

  • f.close() saves data and frees resources
  • with statement closes the file automatically, even if an error occurs ✔ (best way)
with open("data.txt", "r") as f:
    content = f.read()
# file is closed here automatically

  • Each line from a file ends with \n. Use strip() or print(line, end="")

Chapter 3 : Writing to Text Files

  • write(string) writes text. It does not add a new line – put \n yourself
  • writelines(list) writes many strings (no \n added)
  • Only strings can be written. Convert numbers: f.write(str(10))
  • "w" replaces old content. "a" keeps it and adds at the end
# write mode
with open("out.txt", "w") as f:
    f.write("Hello\n")
    f.write("Python\n")
# append mode
with open("out.txt", "a") as f:
    f.write("Files\n")
# out.txt: Hello / Python / Files

Chapter 4 : CSV Files

  • CSV = Comma Separated Values. Each line is a record; fields are separated by commas
  • Used for tables – opens in Excel. Handled with the csv module: import csv
  • csv.writer(f) → writerow(list) one row, writerows(list of lists) many rows
  • csv.reader(f) → each row comes as a list of strings
  • Use newline="" when writing (avoids blank lines on Windows)
import csv
with open("students.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["Name", "Marks"])
    w.writerow(["Ravi", 80])
    w.writerow(["Anu", 90])

with open("students.csv", "r") as f:
    r = csv.reader(f)
    for row in r:
        print(row)
['Name', 'Marks']
['Ravi', '80']        # numbers come back as strings
['Anu', '90']
  • csv.DictReader(f) reads the first row as headings; each row is a dictionary: row["Name"] → 'Ravi'

5.3 try – except – else – finally

BlockWork
tryCode that may cause an error
exceptRuns if error occurs – handles it
elseRuns only if no error occurred
finallyRuns always – error or not (cleanup, e.g. close file)
try block→Error?Yes →except|No →else→finally
(always)→rest of program
try:
    a = int(input("Enter number: "))
    print(10 / a)
except ZeroDivisionError:
    print("Cannot divide by zero")
except ValueError:
    print("Enter a valid number")
else:
    print("No error")
finally:
    print("Done")
InputOutput
52.0 → No error → Done
0Cannot divide by zero → Done
abcEnter a valid number → Done
  • Many except blocks allowed. Put specific exceptions first
  • One except for many types: except (ValueError, TypeError):
  • Get the message: except ZeroDivisionError as e: then print(e) → division by zero
  • except: alone catches every error – not good practice
  • try needs at least one except or a finally. Order: try, except, else, finally

Handling a file error

try:
    with open("data.txt", "r") as f:
        print(f.read())
except FileNotFoundError:
    print("File not found")

Chapter 6 : Raising Exceptions

  • raise makes an exception by the programmer. Syntax: raise ExceptionType("message")
  • Used to stop wrong data, e.g. a negative age
age = -5
if age < 0:
    raise ValueError("Age cannot be negative")
ValueError: Age cannot be negative

try:                                   # raise + try-except together
    raise ValueError("Bad input")
except ValueError as e:
    print("Caught:", e)                # Caught: Bad input

Exception family (some)

Exception→ArithmeticError
→ ZeroDivisionError|LookupError
→ IndexError, KeyError|OSError
→ FileNotFoundError|ValueError, TypeError, NameError
  • Catching a parent exception also catches its children (except LookupError catches IndexError and KeyError)

Program (Lab-type)

# count lines and words in a file safely
try:
    with open("sample.txt", "r") as f:
        lines = f.readlines()
    words = 0
    for line in lines:
        words += len(line.split())
    print("Lines:", len(lines), "Words:", words)
except FileNotFoundError:
    print("File not found")
# sample.txt (Hello / Python / Files) → Lines: 3 Words: 3

★ Key Observations

  • "w" erases old content. "a" adds at the end. "r" needs an existing file
  • Always close a file. with does it automatically
  • read() → string. readline() → one line. readlines() → list
  • write() takes only strings and adds no new line
  • CSV values read back are strings
  • finally always runs. else runs only when there is no error
  • Syntax error = before running. Exception = while running
  • raise creates an exception. except catches it

Real-Life Applications

  • Files: saving student records, log files, reports, settings
  • CSV: reading and writing spreadsheet data (Excel), data science datasets
  • try-except: stops crashes from wrong user input, missing files, divide by zero
  • finally: closing files or connections in every case
  • raise: checking rules – age, marks, password length

★ Exam Points ★

  • Syntax: open(filename, mode). Default mode: "r"
  • Modes: r read, w write (overwrites), a append. r+ read and write
  • "r" on a missing file → FileNotFoundError
  • with closes the file automatically. Or use f.close()
  • Methods: read() whole file, readline() one line, readlines() list of lines, write() text
  • CSV module: csv.reader, csv.writer, writerow, writerows
  • Exception = run-time error. Common: ZeroDivisionError, ValueError, TypeError, NameError, IndexError, KeyError, FileNotFoundError
  • try risky code | except handles error | else no error | finally always runs
  • Raise manually: raise ValueError("message")
