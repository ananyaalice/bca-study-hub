I (c)

Predict the output of: a, b = '10', 5   print(a*b)   print(a+b)

Step by step

  1. a, b = '10', 5 gives a = '10' (a string) and b = 5 (an integer).
  2. print(a*b): the * operator between a string and an integer repeats the string. So '10' is repeated 5 times and the output is 1010101010.
  3. print(a+b): the + operator cannot join a string and an integer. Python raises a TypeError, so nothing is printed for this line.

Program and real output

Example program
a, b = '10', 5
print(a*b)
print(a+b)
Output
1010101010
TypeError: can only concatenate str (not "int") to str

Answer: The first line prints 1010101010. The second line gives a TypeError because a string and an integer cannot be added.

How to correct the error

Corrected program
a, b = '10', 5
print(int(a) + b)      # convert the string to int, then add
print(a + str(b))      # convert the int to string, then join
Output
15
105
I (d)

Write a Python program to check if a given number is odd or even.

A number is even if it is exactly divisible by 2. It is odd if the remainder after dividing by 2 is 1. We use the modulus operator % to find the remainder.

Steps

  1. Read the number and convert it to an integer using int(input()).
  2. Find the remainder using n % 2.
  3. If the remainder is 0, print even. Otherwise print odd.

Program

Example program
n = int(input("Enter a number: "))
if n % 2 == 0:
    print(n, "is an even number")
else:
    print(n, "is an odd number")
Output (when the user types 7)
Enter a number: 7
7 is an odd number
Output (when the user types 10)
Enter a number: 10
10 is an even number
I (e)

Explain default arguments in short.

A default argument is a function parameter that already has a value given in the function definition. If the caller does not give a value, the default value is used. If the caller gives a value, it replaces the default.

  • It is written as parameter = value in the function definition.
  • Default parameters must come after the normal parameters.
  • It makes some arguments optional and reduces the code.

Example

Example program
def greet(name, message="Welcome"):     # message has a default value
    print(message, name)

greet("Anu")                      # default value is used
greet("Anu", "Good morning")      # default value is replaced
Output
Welcome Anu
Good morning Anu
I (f)

What is the purpose of the random module in Python?

The random module is a built-in module. Its purpose is to generate random numbers and to make random choices. It is used in games (rolling a dice), lucky draws, OTP generation, shuffling cards and selecting random samples of data. We must write import random before using it.

Common functions

FunctionUse
random.random()Gives a random float between 0.0 and 1.0
random.randint(a, b)Gives a random integer from a to b (both included)
random.choice(sequence)Picks one random item from a list, string or tuple
random.shuffle(list)Mixes the items of a list in random order
random.seed(n)Fixes the starting point, so the same random values repeat

Example

Example program
import random

random.seed(5)                     # makes the output the same every time
print(random.randint(1, 6))        # rolling a dice
print(random.choice(["red", "green", "blue"]))
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)
print(round(random.random(), 2))
Output
5
green
[5, 4, 2, 1, 3]
0.65

Without random.seed(), the values will be different every time the program is run.

I (g)

Which is the immutable data type in Python? Explain.

Tuple is an immutable data type in Python. Immutable means that the value cannot be changed after it is created. We cannot add, remove or change items of a tuple. Other immutable types are int, float, str, bool and frozenset.

Example 1: changing a tuple gives an error

Example program
t = (10, 20, 30)
print(t[0])
t[0] = 99          # trying to change an item
Output
10
TypeError: 'tuple' object does not support item assignment

Example 2: a string is also immutable

Example program
s = "python"
s[0] = "J"         # error
Output
TypeError: 'str' object does not support item assignment

Compare with a list (mutable)

Example program
marks = [10, 20, 30]     # list is mutable
marks[0] = 99            # change is allowed
print(marks)
Output
[99, 20, 30]

Advantage: Immutable data is safe, because it cannot be changed by mistake. A tuple can also be used as a dictionary key.

I (h)

How are key-value pairs stored in Python?

Key-value pairs are stored in a dictionary (dict). A dictionary is written inside curly braces { }. Each key is joined to its value with a colon and the pairs are separated by commas.

  • Keys must be unique and immutable (for example string, number or tuple).
  • Values can be of any type and can repeat.
  • A value is read using its key, not by an index number.
  • Python stores a dictionary using a hash table, so searching a key is very fast.
  • From Python 3.7, a dictionary remembers the order in which items were added.

Example

Example program
student = {"name": "Anu", "age": 20, "city": "Kochi"}
print(student["name"])           # read a value using its key
student["age"] = 21              # change a value
student["course"] = "BCA"        # add a new key-value pair
print(student)
for key, value in student.items():
    print(key, "->", value)
Output
Anu
{'name': 'Anu', 'age': 21, 'city': 'Kochi', 'course': 'BCA'}
name -> Anu
age -> 21
city -> Kochi
course -> BCA

I (j)

How a CSV file can be read using the CSV module?

CSV means Comma Separated Values. It is a text file in which each line is a row and the values are separated by commas. Python has a built-in csv module to read such files.

Steps

  1. Write import csv.
  2. Open the file using open() (the with statement closes it automatically).
  3. Create a reader object using csv.reader(file).
  4. Use a for loop. Each row is read as a list of strings.

Example

File: students.csv
name,marks,city
Anu,85,Kochi
Ravi,72,Kollam
Meera,90,Kannur
Example program
import csv

with open("students.csv", "r", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
Output
['name', 'marks', 'city']
['Anu', '85', 'Kochi']
['Ravi', '72', 'Kollam']
['Meera', '90', 'Kannur']

Reading each row as a dictionary

csv.DictReader() uses the first line as the keys, so we can read a value using the column name.

File: students.csv
name,marks,city
Anu,85,Kochi
Ravi,72,Kollam
Meera,90,Kannur
Example program
import csv

with open("students.csv", "r", newline="") as file:
    for row in csv.DictReader(file):
        print(row["name"], "scored", row["marks"])
Output
Anu scored 85
Ravi scored 72
Meera scored 90

II (a)

What is a comment? How can multi-line commenting be done in Python?

A comment is a line of text written in the program to explain the code. The Python interpreter ignores comments, so they do not affect the output. Comments make the program easy to read and understand.

Single-line comment

A single-line comment starts with the hash symbol #. Everything after # on that line is ignored.

Multi-line comment

Python has no special symbol for multi-line comments. There are two ways to write them:

  1. Using # on every line: start each line of the comment with #.
  2. Using triple quotes: write the lines between """ ... """ or ''' ... '''. Python reads it as a string that is not used anywhere, so it works like a comment.

Example

Example program
# This is a single-line comment
print("Hello")        # a comment can also come after code

# Method 1: many lines, each starts with #
# This program prints a message.
# It shows how comments are written.

"""
Method 2: triple quotes.
This is a multi-line comment.
It can have many lines.
"""
print("Comments are ignored by Python")
Output
Hello
Comments are ignored by Python
II (b)

Which is the correct variable name _example or 1example? Justify.

_example is the correct variable name. 1example is wrong, because a variable name cannot start with a digit.

Justification: rules for naming a variable

  1. A variable name must start with a letter (a-z, A-Z) or an underscore ( _ ).
  2. After the first character, it can have letters, digits and underscores.
  3. It cannot contain spaces or special symbols such as @, #, $, %, -.
  4. Variable names are case-sensitive. age and Age are different variables.
  5. A Python keyword (like if, for, class) cannot be used as a name.

V (a)

Explain conditional statements in Python with examples.

Conditional statements are used to take decisions in a program. The program checks a condition. If the condition is True, one block of statements runs. If it is False, that block is skipped or another block runs. Conditions are written using comparison operators (==, !=, >, <) and logical operators (and, or, not).

Important: Python uses indentation (4 spaces) to mark the block of statements. A colon ( : ) must be written at the end of the if, elif and else lines.

1. if statement

The block runs only when the condition is True.

Syntax
if condition:
    statements
Example program
age = 20
if age >= 18:
    print("You can vote")
Output
You can vote

2. if-else statement

One block runs when the condition is True and the other block runs when it is False.

Syntax
if condition:
    statements
else:
    statements
Example program
marks = 35
if marks >= 40:
    print("Pass")
else:
    print("Fail")
Output
Fail

3. if-elif-else statement (ladder)

It is used when there are more than two choices. The conditions are checked from top to bottom. The first True block runs and the rest are skipped.

Syntax
if condition1:
    statements
elif condition2:
    statements
else:
    statements
Example program
marks = 82
if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 50:
    print("Grade C")
else:
    print("Fail")
Output
Grade B

4. Nested if statement

An if statement written inside another if statement is called a nested if.

Example program
age = 25
has_id = True

Discuss the need for modular programming in Python.

Modular programming means dividing a big program into small parts called modules. In Python, a module is a file (.py) that contains functions and variables. A module is used in another program with the import statement.

Need (advantages) of modular programming

  • Easy to understand: each module does one small job.
  • Reusability: a module can be used again in many programs, so the same code need not be written again.
  • Easy debugging and testing: an error is found in a small module more easily than in a big program.
  • Easy maintenance: a change in one module does not disturb the others.
  • Teamwork: different programmers can work on different modules at the same time.
  • Avoids name clashes: every module has its own namespace.

What is the scope and lifetime of a Python variable?

Scope means the part of the program where a variable can be used (seen). Lifetime means the time for which the variable stays in memory, that is, from the moment it is created until it is removed.

Types of scope (LEGB rule)

When Python sees a variable name, it searches for it in this order: Local, Enclosing, Global and Built-in. This is called the LEGB rule.

ScopeWhere the variable is createdWhere it can be usedLifetime
LocalInside a functionOnly inside that functionUntil the function finishes
EnclosingIn an outer function that has an inner functionIn the outer function and the inner functionUntil the outer function finishes
GlobalOutside all functionsAnywhere in the programUntil the program ends
Built-inAlready defined by Python (print, len)Anywhere in the programUntil the program ends

Example 1: local and global variables

Example program
x = 10                 # global variable

def show():
    y = 5              # local variable
    print("Inside function: x =", x, ", y =", y)

show()
print("Outside function: x =", x)
Output
Inside function: x = 10 , y = 5
Outside function: x = 10

The global variable x is seen inside and outside the function. The local variable y is created only when the function runs.

Example 2: a local variable cannot be used outside

Program with an error
def show():
    y = 5

show()
print(y)
Output
NameError: name 'y' is not defined

The variable y was removed when the function ended, so Python cannot find it. This shows the lifetime of a local variable.

Example 3: the global keyword

A function can only read a global variable. To change it inside the function, we must write the global keyword.

Example program
count = 0

def increase():
    global count       # tells Python to use the global variable
    count = count + 1

increase()
increase()
print(count)
Output
2

Example 4: the nonlocal keyword (enclosing scope)

Example program
def outer():
    n = 1
    def inner():
        nonlocal n     # use the variable of the outer function
        n = n + 10
    inner()
    print(n)

outer()
Output
11

  1. try block: write the code that may cause an error.

finally:
