Chapter 1 : Working with Files

Why files are needed, opening modes and closing.

Q1

Why do we need files? What are the two kinds of files? 3 marks

Answer

Variables lose their data when the program ends. A file stores data permanently on the disk. There are two kinds of files: text files (readable characters, the default) and binary files (images, audio; opened with mode b). A file is used in three steps: open, then read or write, then close.

Q2

List out the various modes of file opening in Python and their use cases. 5 marks

Answer

A file is opened using open(filename, mode). The default mode is "r".

ModeNameMeaningUse case
"r"Read (default)Only reading. The file must exist, else FileNotFoundErrorReading an existing file
"w"WriteCreates the file if absent. Erases old content if presentSaving fresh data
"a"AppendCreates the file if absent. Adds data at the end; old content staysLog files, adding new records
"r+"Read and writeThe file must existReading and changing a file
"x"CreateMakes a new file. Error if it already existsCreating a file safely

Add b for binary files: "rb", "wb".

Example program
f = open("data.txt", "w")      # create and write
f.write("Hello\n")
f.close()
f = open("data.txt", "r")      # read
print(f.read())
f.close()
f = open("new.txt", "x")       # create a new file
f.close()
try:
    open("new.txt", "x")       # file already exists
except FileExistsError:
    print("x mode gives an error if the file exists")
Output
Hello

x mode gives an error if the file exists
Exam tip: Write the five modes in a table. Underline that "w" erases old content and "r" needs an existing file.

Chapter 3 : Writing to Text Files

write(), writelines() and the modes w and a.

Q6

Explain the methods write() and writelines(). 3 marks

Answer

  • write(string) writes text. It does not add a new line, so we put \n ourselves.
  • writelines(list) writes many strings (no \n is added).
  • Only strings can be written. Convert numbers using str(), for example f.write(str(10)).
Example program
with open("out.txt", "w") as f:
    f.write("Hello\n")
    f.write(str(10) + "\n")
    f.writelines(["a\n", "b\n"])
with open("out.txt") as f:
    print(f.read())
Output
Hello
10
a
b
Q7

Write a Python program to write content to a file and then add more content. Differentiate between w and a modes. 5 marks

Answer

"w" replaces the old content. "a" keeps the old content and adds the new content at the end.

Example program
with open("out.txt", "w") as f:        # write mode
    f.write("Hello\n")
    f.write("Python\n")

with open("out.txt", "a") as f:        # append mode
    f.write("Files\n")

with open("out.txt", "r") as f:
    print(f.read())

with open("out.txt", "w") as f:        # "w" again erases the old content
    f.write("New\n")
with open("out.txt") as f:
    print(f.read())

Chapter 4 : CSV Files

Reading and writing comma separated files.

Q8

What is a CSV file? Write a program to write and read a CSV file. 5 marks

Answer

CSV stands for Comma Separated Values. Each line is a record and the fields are separated by commas. It is used for tables and opens in Excel. It is handled using the csv module (import csv).

  • csv.writer(f) gives a writer. writerow(list) writes one row. writerows(list of lists) writes many rows.
  • csv.reader(f) gives each row as a list of strings.
  • Use newline="" while writing, to avoid blank lines on Windows.
Example program
import csv
with open("students.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["Name", "Marks"])
    w.writerow(["Ravi", 80])
    w.writerow(["Anu", 90])

with open("students.csv", "r") as f:
    r = csv.reader(f)
    for row in r:
        print(row)
Output
['Name', 'Marks']
['Ravi', '80']
['Anu', '90']

Notice that the numbers come back as strings ('80', '90').

Exam tip: Write "numbers are read back as strings". It is a key observation of this module.
Q9

csv.DictReader(f) reads the first row as headings. Every other row comes as a dictionary, so we can use row["Name"].

Q13

Write the important rules of using multiple except blocks. 3 marks

Answer

  • Many except blocks are allowed. Put the specific exceptions first.
  • One except can handle many types: except (ValueError, TypeError):
  • To get the error message use except ZeroDivisionError as e: and print(e).
  • except: alone catches every error. It is not good practice.
  • try needs at least one except or a finally. The order is try, except, else, finally.
Example program
try:
    print(10 / 0)
except ZeroDivisionError as e:
    print("Error:", e)

for value in ["7", "x", None]:
    try:
        print(int(value))
    except (ValueError, TypeError):
        print("Bad value:", value)
Output
Error: division by zero
7
Bad value: x
Bad value: None

Chapter 6 : Raising Exceptions

The raise keyword, the exception family and a lab program.

Q15

Explain the raise keyword with an example. 3 marks

Answer

raise creates an exception by the programmer. The syntax is raise ExceptionType("message"). It is used to stop wrong data, for example a negative age. A raised exception can be caught with try-except.

Example program
try:
    raise ValueError("Bad input")
except ValueError as e:
    print("Caught:", e)

age = -5
if age < 0:
    raise ValueError("Age cannot be negative")
Output
Caught: Bad input
ValueError: Age cannot be negative
Q16

Draw the family (hierarchy) of the common exceptions. 3 marks

Answer

Exceptions are arranged in a family. Catching a parent exception also catches its children. For example, except LookupError catches both IndexError and KeyError.

Example program
try:
    [1, 2][5]

Q18

What is an exception? Discuss how exceptions are handled in Python. 10 marks

Answer

  1. Introduction: An exception is an error that occurs while the program is running. If it is not handled, the program stops. Exception handling catches it so the program can continue.
  2. Common exceptions: ZeroDivisionError, ValueError, TypeError, NameError, IndexError, KeyError, FileNotFoundError.
  3. Handling: try (risky code), except (handles the error), else (no error), finally (always runs).
  4. Many except blocks for different errors, and as e to get the message.
  5. Raising: raise ValueError("message") to create an exception ourselves.
  6. Conclusion: Exception handling makes a program safe and user-friendly.
Example program
def divide(a, b):
    try:
        if b < 0:
            raise ValueError("b cannot be negative")
        result = a / b
    except ZeroDivisionError:
        print("Cannot divide by zero")
    except ValueError as e:
        print("Error:", e)
    else:
        print("Result:", result)
    finally:
        print("Done")

divide(10, 2)
divide(10, 0)
divide(10, -1)
Output
Result: 5.0
Done
Cannot divide by zero
Done
Error: b cannot be negative
Done
