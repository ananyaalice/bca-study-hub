Q2

Why is bool called a subclass of int? How do comparisons give bool values? 3 marks ★★★☆☆ Important

Answer

In Python, True is equal to 1 and False is equal to 0. So a bool value can be used in calculations, and we say that bool is a subclass of int. Every comparison, such as 5 > 3, gives a bool value (True or False).

Example program
print(True + True)
print(True * 10)
print(5 > 3)
print(type(5 > 3))
print(int(True), int(False))
Output
2
10
True
<class 'bool'>
1 0
Q3

What are truthy and falsy values? Where are they used? 3 marks ★★★★☆ Very important

Answer

A value that is treated as False in a condition is called falsy. They are 0, 0.0, "", [], (), {} and None. All other values are truthy. They are used in if and while conditions, for example to check whether a list is empty.

Example program
items = []
if items:
    print("List has items")
else:
    print("List is empty")

name = "Anu"
if name:
    print("Name is not empty")
Output
List is empty
Name is not empty

Chapter 3 : Input and Output

input() and print().

Q6

input() reads a line typed by the user and always returns a str. For numbers we convert it with int() or float(). A common error is that "5" + "3" gives "53" and not 8.

Q7

Explain print() with sep, end and f-string formatting. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

sep is the gap between values (default: space). end is the ending text (default: new line \n). An f-string (preferred) puts variables inside curly braces, and :.2f gives two decimal places.

Example program
name = "Anu"
age = 20
print("A", "B", "C", sep="-")
print("No newline", end=" ")
print("same line")
print(f"{name} is {age} years old")
print(f"{3.14159:.2f}")
Output
A-B-C
No newline same line
Anu is 20 years old
3.14

Chapter 4 : Conditional Statements

Taking decisions: if, if-else, if-elif-else and nested if.

Q8

What is a conditional statement? Name its four forms. 3 marks ★★★★☆ Very important

Answer

A conditional statement chooses which block of code runs, depending on a condition that is True or False. A block is shown by indentation, and the condition line ends with a colon ( : ). The four forms are:

  1. if statement
  2. if-else statement
  3. if-elif-else statement
  4. Nested if statement
Q9

Explain the if statement with an example. 3 marks ★★★☆☆ Important

Answer

The if statement runs its block only if the condition is True. If the condition is False, the block is skipped.

Syntax
if condition:
    # body of if
Example program
temperature = 38
if temperature > 37:
    print("You have a fever.")
print("Program ends")
Output
You have a fever.
Program ends
Q10

Explain the if-else statement with a flowchart and an example. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

In the if-else statement, the if block runs when the condition is True and the else block runs when it is False. Exactly one block runs.

Example program
age = 16
if age >= 18:
    print("You are eligible to vote.")
else:
    print("You are not eligible to vote.")
Output
You are not eligible to vote.
How to write it: Write the syntax, one line on how it works, the flowchart and the program.
Q11

Explain the if-elif-else statement with an example. 5 marks ★★★★★ Must study

Answer

The if-elif-else statement is used to test many conditions in order. The first True block runs and the remaining blocks are skipped, even if they are also True. elif means "else if". The else block runs only if none of the conditions is True. If no condition is True and there is no else, no block runs.

Example program
marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "F"
print(f"Grade: {grade}")
Output
Grade: C
Exam tip: Write the conditions from the highest to the lowest. The first True condition decides the result.

  • A compound condition joins tests using and, or and not.

username = "admin"

age = 25

if age >= 18 and has_id:

Access granted
Entry allowed

Explain conditional statements in Python with examples. 10 marks ★★★★★ Must study Asked in Nov 2025

Answer

  1. Introduction: Conditional statements take decisions by testing a condition that is True or False. Indentation shows the block and a colon ends the condition line.

Q17

Explain the range(start, stop, step) function with examples. 3 marks ★★★★☆ Very important

Answer

  • start: the first value (optional, default 0).
  • stop: the end limit (required). The stop value is not included, so the last value is stop - 1.
  • step: the increase between values (optional, default 1).
Example program
print(list(range(5)))
print(list(range(2, 10, 2)))
print(list(range(10, 0, -3)))
for i in range(0, 4):
    print(i, end=" ")
Output
[0, 1, 2, 3, 4]
[2, 4, 6, 8]
[10, 7, 4, 1]
0 1 2 3
Exam tip: range(5) gives 0 to 4. It never includes 5.
Q18

Explain the while loop. What is an infinite loop? 5 marks ★★★★★ Must study

Answer

The while loop repeats as long as the condition is True. It is used when the number of iterations is not known in advance. We must update the variable inside the loop. If the condition never becomes False, the loop never ends. This is an infinite loop.

Syntax
while condition:
    # body
    # update
Example program
count = 1
while count <= 5:
    print(count, end=" ")
    count += 1          # update avoids an infinite loop
print()

# A menu-style loop using while True and break
while True:
    choice = input("Enter q to quit: ")
    if choice == "q":
        break
print("Bye")
Output (the user types a, then q)
1 2 3 4 5 
Enter q to quit: a
Enter q to quit: q
Bye
Q19

What are nested loops? Write programs for a number table and a star pattern. 5 marks ★★★★☆ Very important

Answer

A nested loop is a loop inside another loop. The inner loop finishes all its rounds for every one round of the outer loop. Nested loops are used for tables, grids, matrices and patterns. Any loop can be nested in the other (a for in a while, or a while in a for).

for i in range(1, 4):

    print()

Star pattern

Chapter 6 : Loop Control Statements

break, continue, pass and else with loops.

Q23

Explain break, continue and pass with examples. 5 marks ★★★★★ Must study

Answer

  • break ends the nearest loop completely. The remaining rounds are skipped.
  • continue skips the rest of the current round and goes to the next round. The loop does not end.
  • pass does nothing. It is a placeholder where a statement is needed but no action is ready yet.
Example program
for num in range(1, 10):
    if num == 5:
        break
    print(num, end=" ")
print("<- break")

for num in range(1, 6):
    if num == 3:
        continue
    print(num, end=" ")
print("<- continue")

for num in range(5):
    if num == 2:
        pass
    print(num, end=" ")
print("<- pass")

def not_ready():
    pass              # empty body, no error
Output
1 2 3 4 <- break
1 2 4 5 <- continue
0 1 2 3 4 <- pass
Exam tip: break ends the loop, continue skips one round, pass does nothing at all. Also: break ends only the nearest loop, not all nested loops.
Q24

Explain the else clause with loops. 3 marks ★★★☆☆ Important

Answer

A for or while loop can have an optional else. The else block runs when the loop ends normally (all rounds are done). It is skipped if the loop was ended by break.

Example program
for i in range(3):
    print(i, end=" ")
else:
    print("Loop finished normally")

for i in range(10):
    if i == 3:
        break
    print(i, end=" ")
else:
    print("skipped")
print()
Output
0 1 2 Loop finished normally
0 1 2
Q25

Write a program to check whether a number is prime using loop-else. 5 marks ★★★★☆ Very important

Answer

  1. If the number is less than 2, it is not prime.
  2. Check the divisors from 2 to n - 1.
  3. If any divisor divides n exactly, print "Not prime" and break.
  4. If the loop ends without break, the else block prints "Prime".
Example program
n = 29
if n < 2:
    print("Not prime")
else:
    for i in range(2, n):
        if n % i == 0:
            print("Not prime")
            break
    else:
        print("Prime")
Output (n = 29)
Prime
Output (n = 28)
Not prime

Q28

Explain the loop control statements in Python with suitable programs. 10 marks ★★★★☆ Very important

Answer

  1. Introduction: Loop control statements change the normal flow of a loop. They are break, continue, pass and the else clause.
  2. break: leaves the loop at once.
  3. continue: skips the current round.
  4. pass: a placeholder that does nothing.
  5. else: runs only if the loop ends without a break.
  6. Programs: prime check and list search (given below).
  7. Conclusion: write the summary table of the four statements.
Example program
numbers = [3, 7, 11, 15]
for n in numbers:
    if n % 2 == 0:
        print("Even number found:", n)
        break
else:
    print("No even number in the list")

for i in range(1, 8):
    if i % 2 == 0:
        continue
    print(i, end=" ")
print()
Output
No even number in the list
1 3 5 7
