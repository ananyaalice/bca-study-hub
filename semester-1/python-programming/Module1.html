Chapter 1 : Getting Started

1.1 What is Python?

  • Programming = designing, writing, testing and maintaining instructions for a computer
  • Python is a high-level, interpreted, general-purpose language, known for readability and simplicity
  • Created by Guido van Rossum (Netherlands) as a successor to the ABC language
  • Name from the British comedy series “Monty Python’s Flying Circus” – not the snake ✔
  • Free and open source. File extension → .py

1.2 History of Python

1.5 Installing Python

  1. Visit python.org/downloads → download latest stable version
  2. Run the installer (python-3.x.x.exe on Windows)
  3. Tick “Add Python to PATH” ✔ (very important)
  4. Click Install Now → wait → Close
  5. Verify: python --version (Linux/macOS may need python3 --version)
  • pip = package manager, installed with Python 3.4 and later. Installs libraries from PyPI
  • Check: pip --version. Install: pip install package_name

Chapter 2 : Syntax, Keywords and Variables

2.1 Basic syntax rules

  • Indentation (whitespace, usually 4 spaces) defines blocks – no braces { }
  • Wrong indentation → IndentationError
  • Statement ends at new line. Semicolon is optional and rarely used
  • Python is case-sensitive – Name and name are different
  • Comment: # for one line. Multi-line: triple quotes """ """ (often used as docstring)
if 5 > 3:
    print("5 is greater than 3")   # indented block
else:
    print("Condition is false")

2.2 Keywords

  • Keywords = reserved words with a fixed meaning. Cannot be used as variable or function names
  • Python 3 has 35 keywords. See them: import keyword then print(keyword.kwlist)
False None True and as assert async await break class continue def del elif else except finally for from global if import in is lambda nonlocal not or pass raise return try while with yield

2.3 Identifiers

  • Identifier = name of a variable, function, class, module or any object
  1. Must begin with a letter or underscore (_)
  2. Remaining characters: letters, digits, underscore
  3. Cannot begin with a digit
  4. Cannot be a keyword
  5. Case-sensitive: age, Age, AGE are different
  6. Use meaningful names (PEP 8)
Valid ✔Invalid ✘
total, student_name, _count, marks1, isValid, MAX_LIMIT 1value (digit first), class (keyword), total% (symbol), my-name (hyphen)

2.4 Variables

  • Variable = named location in memory that stores a value
  • Dynamically typed – no type declaration. Type is decided from the value, at run time
  • Same name can be given a new type later
  • Naming rules = identifier rules. PEP 8 style: snake_case (student_total)
x→10
name = "Alice"      # str
age = 21            # int
height = 5.6        # float
is_student = True   # bool

2.5 Multiple assignment

x, y, z = 10, 20, 30    # different values
a = b = c = 0           # same value to all
  • Works by tuple unpacking. Number of names on the left = number of values on the right

Chapter 4 : Input and Output

4.1 input()

  • Pauses the program, reads a line typed by the user. Syntax: input("message")
  • Always returns a string (str) ★
  • For numbers, convert: int(input()), float(input())
"5" + "3"            # "53"  (joined as text)
int("5") + int("3")  # 8

4.2 print()

  • Shows output on the console. Takes many values separated by commas
  • sep = text between values (default: one space)
  • end = text after output (default: new line \n)
  • print() returns None – never write result = print(...)
print("Python", "is", "fun")            # Python is fun
print("Python", "is", "fun", sep="-")    # Python-is-fun
print("Loading", end="...")             # no new line after it

4.3 Formatting output (3 ways)

  • 2 decimal places: f"{3.14159:.2f}" → 3.14

  • Compound form does the operation, then assigns: c += a means c = c + a
  • Same for -= *= /= %= **= //=

5.5 Identity and membership

  • is → True if both sides are the same object in memory. is not → opposite
  • in → True if value is found in a sequence (string, list, tuple). not in → opposite
  • Equal ≠ identical – == compares values, is compares objects
x = 12; y = 12
x is y            # True (small numbers share one object)
nums = [21, 13, 10, 17]
10 in nums        # True
5 in nums         # False
10 not in nums    # False

5.6 Operator precedence

Which operator works first. High → low:

( )→**→* / // %→+ −→<< >>→&→^→|→comparison, is, in→not→and→or
2 + 3 * 4      # 14  (* first)
(2 + 3) * 4    # 20  (brackets first)

★ Key Observations

  • Python uses indentation instead of braces
  • No type declaration – type comes from the value
  • input() gives str → convert before calculation
  • int() cuts the decimal part – it does not round
  • print() returns None
  • = assigns, == compares. is checks object, == checks value
  • / gives float (5/2 = 2.5). // gives floor (5//2 = 2)
  • 17 % 4 = 1 (remainder). 2 ** 3 = 8 (power)
  • Version check is python --version (or capital -V). Small -v is not for version
