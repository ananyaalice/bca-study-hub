Chapter 1 : Defining and Calling Functions

What a function is and how to call it.

Q1

What is a function? Write the syntax of defining a function. What are its uses? 3 marks ★★★★☆ Very important

Answer

A function is a named block of code that does one task. It runs only when it is called. It is defined using the keyword def.

Syntax
def function_name(parameters):
    """docstring - optional description"""
    # body (indented)
    return value          # optional

Uses: (1) We can reuse the code, (2) a big program can be broken into small parts (modular), (3) the program becomes easy to read and debug. A docstring is the optional text in triple quotes that describes the function.

Q2

How is a function called? Differentiate between a parameter and an argument. 5 marks ★★★★☆ Very important

Answer

A function is called by writing its name followed by brackets with the values. When it is called, the argument is sent to the parameter, the body executes and a value is returned to the caller.

Example program
def greet(name):             # name is a parameter
    print("Hello,", name)

greet("Ravi")                # "Ravi" is an argument
Output
Hello, Ravi
ParameterArgument
Variable in the definition (name)Actual value in the call ("Ravi")
  • A function must be defined before it is called.
  • Giving the wrong number of arguments gives a TypeError.
Wrong number of arguments
def add(a, b):
    return a + b

print(add(2, 3))
print(add(2))
Output
5
TypeError: add() missing 1 required positional argument: 'b'
Exam tip: Parameter = in the definition. Argument = in the call. Write this line in every answer.

Chapter 2 : Function Arguments

Positional, keyword, default and variable-length arguments.

Q3

Explain positional arguments with an example. 3 marks ★★★☆☆ Important

Answer

In positional arguments the values are matched by their position (order). The first value goes to the first parameter, the second value to the second parameter, and so on. So the order matters.

Example program
def sub(a, b):
    return a - b

print(sub(10, 3))
print(sub(3, 10))
Output
7
-7
Q4

Explain keyword arguments with an example. 3 marks ★★★☆☆ Important

Answer

In keyword arguments the values are passed as name=value. The order does not matter. In a call, positional arguments must come before keyword arguments.

Example program
def sub(a, b):
    return a - b

print(sub(b=3, a=10))
print(sub(10, b=3))
Output
7
7
Q5

What are default arguments? Give an example. 3 marks ★★★★★ Must study Asked in Nov 2025

Answer

A parameter can have a default value. It is used if the caller does not give a value. Default parameters must come after the non-default parameters.

Example program
def greet(name, msg="Hello"):
    print(msg, name)

greet("Ravi")
greet("Ravi", "Hi")
Output
Hello Ravi
Hi Ravi
Q6

Summarize how arbitrary (variable-length) arguments can be assigned in Python functions. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

When the number of arguments is not known, we use variable-length arguments.

TypeSymbolCollected as
Extra positional arguments*argsA tuple
Extra keyword arguments**kwargsA dictionary

The order in a definition is: normal, default, *args, **kwargs.

Example program
def total(*nums):
    print(nums)
    return sum(nums)

print(total(1, 2, 3))

def info(**data):
    print(data)

info(name="Ravi", age=20)

def mix(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)

mix(1, 5, 7, 8, x=9)
Output
(1, 2, 3)
6
{'name': 'Ravi', 'age': 20}
1 5 (7, 8) {'x': 9}
Exam tip: *args gives a tuple; **kwargs gives a dictionary. Write these two sentences exactly.
Q7

Explain the different types of function arguments in Python with examples. 10 marks ★★★★★ Must study

Answer

  1. Introduction: Arguments are the values passed to a function. Python has four types: positional, keyword, default and variable-length.
  2. Positional: matched by order.
  3. Keyword: passed as name=value, order does not matter.
  4. Default: the parameter has a default value used when no value is given.
  5. Variable-length: *args (tuple) and **kwargs (dictionary).
  6. Rules: positional before keyword in a call; default parameters after normal ones.
Example program
def student(name, course="BCA", *marks, **extra):
    print("Name:", name, "| Course:", course)
    print("Marks:", marks)
    print("Extra:", extra)

student("Anu")
student("Ravi", "BSc", 80, 90, city="Kochi")
student(course="MCA", name="Joel")
Output
Name: Anu | Course: BCA
Marks: ()
Extra: {}
Name: Ravi | Course: BSc
Marks: (80, 90)
Extra: {'city': 'Kochi'}
Name: Joel | Course: MCA
Marks: ()
Extra: {}

Chapter 3 : The return Statement

Sending a value back to the caller.

Q8

Explain the return statement. How is it different from print()? 5 marks ★★★★☆ Very important

Answer

  • return sends a value back to the caller and ends the function at once. Code after return is not executed.
  • If there is no return statement, the function gives None.
  • A function can return many values, which are returned as a tuple.
Example program
def add(a, b):
    return a + b

result = add(5, 3)
print(result)

def calc(a, b):
    return a + b, a - b

s, d = calc(10, 4)
print(s, d)

def show(x):
    print(x)             # no return

print(show(5))
Output
8
14 6
5
None
print()return
Only shows a value on the screenGives the value back to the caller to store or use
Exam tip: A function without return gives None. This is a favourite one-mark question.

Chapter 4 : Recursion and Lambda

Functions that call themselves and one-line functions.

Q9

What is recursion? Write a recursive program for the factorial of a number. 5 marks ★★★★★ Must study

Answer

Recursion is a function that calls itself. It has two parts: the base case, which stops the calls, and the recursive case, which calls the function with a smaller problem. If there is no base case, Python raises a RecursionError (maximum recursion depth exceeded; the default limit is 1000).

Example program
def fact(n):
    if n == 0 or n == 1:      # base case
        return 1
    return n * fact(n - 1)    # recursive case

print(fact(5))
print(fact(3))
Output
120
6
Exam tip: Always write the base case first and mark it with a comment.
Q10

Write a recursive program to display the Fibonacci series of n terms. 5 marks ★★★★☆ Very important

Answer

In the Fibonacci series, each term is the sum of the previous two terms: 0, 1, 1, 2, 3, 5, 8 ... The base case is n < 2, where the function returns n itself.

Example program
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

for i in range(7):
    print(fib(i), end=" ")
Output
0 1 1 2 3 5 8

Q12

Detail the concept of lambda functions in Python. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

A lambda is a small anonymous function (a function without a name) written in one line. It can take many arguments but has only one expression. The result is returned automatically (no return). It is used for short, one-time functions.

Syntax
lambda arguments : expression
Example program
square = lambda x: x * x
print(square(5))

add = lambda a, b: a + b
print(add(2, 3))

print(list(map(lambda x: x * 2, [1, 2, 3])))
Output
25
5
[2, 4, 6]

Chapter 5 : Scope and Lifetime of Variables

Where a variable can be used and how long it lives.

Q14

What is the scope and lifetime of a variable? Differentiate between local and global variables. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Scope is the part of the program where a variable can be used. Lifetime is how long the variable exists in memory.

PointLocal variableGlobal variable
CreatedInside a functionOutside all functions
ScopeOnly inside that functionThe whole program
LifetimeCreated when the function is called, destroyed when it endsUntil the program ends
Example program
x = 10                 # global

def f():
    x = 5              # a new local x
    print(x)

f()
print(x)               # global x is unchanged
Output
5
10
A local variable used outside its function
def show():
    y = 5

show()
print(y)
Output
NameError: name 'y' is not defined

Assigning a value inside a function creates a new local variable, even if a global variable with the same name exists.

Q15

Explain the global keyword and the LEGB rule. 5 marks ★★★★☆ Very important

Answer

The global keyword lets a function change a global variable. Python searches for a name in the order LEGB: Local, Enclosing (outer function), Global and Built-in.

Example program
x = 10

def g():
    global x
    x = 20          # changes the global x

g()
print(x)
Output
20

Chapter 7 : Modules and Standard Libraries

Reusing code with modules; math, random and time.

Q17

What is a module? Explain the different ways to import a module. 5 marks ★★★★☆ Very important

Answer

A module is a .py file that contains functions, variables and classes. It helps us to reuse and organise code.

Way to importUse
import mathmath.sqrt(16)
from math import sqrtsqrt(16) (no prefix)
import math as mm.sqrt(16) (short name)
from math import *All names. Not recommended
Example program
import math
from math import sqrt
import math as m
print(math.sqrt(16), sqrt(16), m.sqrt(16))
Output
4.0 4.0 4.0
Q18

Discuss the need for modular programming in Python. How can we create our own module? 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Modular programming divides a big program into small parts called modules. It makes the program easy to understand, allows reuse, makes debugging and testing easier, helps teams to work on different modules and avoids name clashes.

  1. Write the functions in a file, for example mymath.py.
  2. Keep the file in the same folder as the main program.
  3. Use import mymath in the main program and call mymath.add(2, 3).
File: mymath.py
def add(a, b):
    return a + b
main.py (uses the module mymath.py shown above)
import mymath
print(mymath.add(2, 3))
Output
5

Q22

Write a program to check whether a number is prime using a function. 5 marks ★★★★☆ Very important

Answer

Example program
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    return True

print(is_prime(7))
print(is_prime(10))
Output
True
False
Q23

Explain the scope and lifetime of a variable and compare built-in functions with user-defined functions (combined model question). 5 marks ★★★☆☆ Important

Answer

Part 1: scope and lifetime. Scope is where a variable can be used. Lifetime is how long it exists. A local variable lives only while its function runs. A global variable lives until the program ends. Python searches names in the order LEGB.

Part 2: functions. Built-in functions are given by Python (len(), max()) and need no definition. User-defined functions are written by the programmer using def.

Example program
total = 0                       # global

def add_marks(m):
    global total
    total = total + m           # changes the global variable

for mark in [40, 50, 60]:
    add_marks(mark)
print("Total:", total, "| Highest:", max(40, 50, 60))
Output
Total: 150 | Highest: 60
