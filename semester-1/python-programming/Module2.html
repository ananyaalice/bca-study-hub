Chapter 3 : Input and Output

3.1 input()

  • Reads a line typed by the user. Always returns str ★
  • Convert for numbers: int(input()), float(input())
  • Common error: "5" + "3" gives "53", not 8

3.2 print()

  • sep = gap between values (default: space). end = ending text (default: \n)
  • f-string (preferred): f"{name} is {age} years old". Format: f"{3.14159:.2f}" → 3.14
age = int(input("Enter your age: "))
print("Next year:", age + 1)             # Next year: 21  (if 20 entered)
print("A", "B", "C", sep="-")            # A-B-C
print("No newline", end=" ")             # stays on same line

Chapter 4 : Conditional Statements

  • A conditional statement chooses which block runs, based on a condition (True or False)
  • Block is shown by indentation. Condition line ends with a colon :
  • Four forms: if, if-else, if-elif-else, nested if

4.1 if statement

  • Runs the block only if condition is True. If False, block is skipped
if condition:
    # body of if
---
temperature = 38
if temperature > 37:
    print("You have a fever.")

4.2 if-else statement

  • True → if block runs. False → else block runs. Exactly one block runs
Condition?→ True →if block|False →else block→next statement
age = 16
if age >= 18:
    print("You are eligible to vote.")
else:
    print("You are not eligible to vote.")   # this runs

4.3 if-elif-else statement

  • Tests many conditions in order. Runs the first True block. Rest are skipped, even if True
  • elif = “else if” – checks another condition when the earlier ones are False
  • else runs only if none matched. If none match and there is no else → no block runs
marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "F"
print(f"Grade: {grade}")     # Grade: C

4.4 Nested and compound conditions

  • Nested if = an if statement inside another if
  • Compound condition = tests joined by and, or, not
username = "admin"
password = "1234"
if username == "admin":
    if password == "1234":
        print("Access granted")      # this runs
    else:
        print("Wrong password")
else:
    print("Unknown user")

if age >= 18 and has_id:           # compound
    print("Entry allowed")

Chapter 5 : Loops (Iteration)

  • Loop = repeats a block of code. Iteration = one repetition
  • Two loops in Python: for and while
  • Every loop has 4 parts:
1 Initialization
(i = 0)→2 Condition
(for / while line)→3 Body
(indented)→4 Update
(i += 1)↺

In a for loop the update is automatic. In a while loop we write it ourselves.

5.1 for loop

  • Goes through a sequence (list, tuple, string, dict, set) or a range. Used when iterations are known
  • Syntax: for val in sequence:

range(start, stop, step)

  • start – first value (optional, default 0)
  • stop – end limit (required). stop is NOT included (last value = stop − 1)
  • step – increase between values (optional, default 1)
  • range(0, 4) → 0, 1, 2, 3  |  list(range(5)) → [0, 1, 2, 3, 4]
for i in range(5):          # 0 1 2 3 4
    print(i)
for i in range(2, 10, 2):   # 2 4 6 8
    print(i)
for ch in "abc":            # a b c
    print(ch)
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):   # index with item
    print(index, fruit)

5.2 while loop

  • Repeats as long as condition is True. Used when iterations are not known in advance
  • Syntax: while condition:
  • ★ Must update the variable inside the loop. Otherwise → infinite loop
  • while True: with break – common in menu-driven programs
count = 1
while count <= 5:
    print(count)
    count += 1          # update – avoids infinite loop

while True:
    choice = input("Enter q to quit: ")
    if choice == 'q':
        break

5.3 Nested loops

  • A loop inside another loop. Inner loop finishes all its rounds for every one round of the outer loop
  • Used for tables, grids, matrices, pattern printing
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end="\t")
    print()

Chapter 6 : Loop Control Statements

They change the normal flow of a loop: break, continue, pass and else with loops.

break

Ends the nearest loop completely. Remaining rounds are skipped. 
for num in range(1, 10):
    if num == 5:
        break
    print(num)
1 2 3 4

continue

Skips the rest of the current round. Goes to the next round. Loop does not end. 
for num in range(1, 6):
    if num == 3:
        continue
    print(num)
1 2 4 5

pass

Does nothing. A placeholder where a statement is needed but no action yet. Does not skip anything. 
for num in range(5):
    if num == 2:
        pass
    print(num)            # 0 1 2 3 4
def not_ready():
    pass                  # empty function body, no error

6.4 else with loops

  • for and while can have an optional else
  • else runs when the loop ends normally (all rounds done)
  • else is skipped if the loop was ended by break ★
for i in range(3):
    print(i)
else:
    print("Loop finished normally")
0 1 2 + message (else RUNS)
for i in range(10):
    if i == 3:
        break
    print(i)
else:
    print("skipped")
0 1 2 (else SKIPPED)

Program: prime number check using loop-else

n = 29
if n < 2:
    print("Not prime")
else:
    for i in range(2, n):
        if n % i == 0:
            print("Not prime")
            break
    else:
        print("Prime")            # Prime

Search in a list

numbers = [2, 4, 6, 8]
target = 5
for n in numbers:
    if n == target:
        print("Found!")

else:

★ Key Observations

  • input() → str. Convert with int() / float() before maths
  • int() cuts decimals – no rounding. int("3.5") → ValueError
  • In if-elif-else only the first True block runs
  • range(5) gives 0 to 4. It does not include 5
  • while loop without an update step → infinite loop
  • break stops the loop. continue skips one round. pass does nothing
  • Loop else runs only if there was no break
  • break ends only the nearest loop, not all nested loops

Real-Life Applications

  • Conditions: grading, voting eligibility, login check (username and password)
  • for loop: going through lists and strings, multiplication tables
  • while loop: input validation, menu-driven programs, game loops, polling
  • Nested loops: grids, matrices, pattern printing
  • Loop-else: searching for an item (found / not found)

★ Exam Points ★

  • Basic types: int, float, complex, bool, str. int has no size limit. str is immutable
  • bool: True = 1, False = 0. False values: 0, 0.0, "", [], (), {}, None
  • Conversion: implicit (automatic, int → float) and explicit (int() float() str() bool())
  • input() → always str. print() → sep (default space), end (default \n)
  • Conditionals: if, if-else, if-elif-else, nested if. Indentation shows the block
  • if can be used without else. elif checks the next condition when earlier ones are False
  • No condition True and no else → no block runs
  • Loops: for (known iterations) and while (condition-based)
  • range(start, stop, step): start = 0, step = 1 by default. stop excluded
  • Nested loop: inner loop completes fully for each outer round
  • break ends loop | continue skips the current round | pass placeholder
  • Loop else runs when loop ends normally; skipped after break
