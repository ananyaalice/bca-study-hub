Q1

What is Python? Who created it? Why is it named Python? 2 marks ★★★★☆ Very important

Answer

Python is a high-level, interpreted, general-purpose programming language. It is known for its simple and readable syntax. It was created by Guido van Rossum in the Netherlands as a successor to the ABC language. The name comes from the British comedy series "Monty Python's Flying Circus", and not from the snake. Python is free and open source, and its files are saved with the extension .py.

A Python program (first.py)
print("Hello, World!")
Output
Hello, World!

Q4

Explain how a Python program is executed. 5 marks ★★★★☆ Very important

Answer

A Python program is executed in the following steps.

  1. The programmer writes the source code and saves it in a file with the .py extension.
  2. The interpreter reads the source code and converts it into bytecode.
  3. The bytecode is given to the Python Virtual Machine (PVM).
  4. The PVM runs the bytecode instruction by instruction and gives the output.

Because the bytecode runs on the PVM, the same program can run on any operating system that has Python installed. The interpreter stops at the first error and shows a message.

How to write it: Write the four steps in order: source code, interpreter, bytecode, PVM, output. Draw the chain diagram.
Exam tip: Do not forget the word bytecode and the full form of PVM.
Q5

Explain the steps to install Python. What is pip? 5 marks ★★★☆☆ Important

Answer

Python can be installed on Windows by following these steps.

  1. Visit python.org/downloads and download the latest stable version.
  2. Run the installer file (for example python-3.x.x.exe).
  3. Tick the box "Add Python to PATH". This is very important, because it lets us run Python from any folder.
  4. Click Install Now, wait for the setup to finish and click Close.
  5. Verify the installation by typing python --version in the terminal. On Linux or macOS use python3 --version.

What is pip?

pip is the package manager of Python. It is installed with Python 3.4 and later. It downloads and installs libraries from PyPI (the Python Package Index, the online store of libraries). Check it with pip --version and install a library with pip install package_name.

Commands (typed in the terminal)
python --version
pip --version
pip install numpy
How to write it: Write the steps as a numbered list. Underline "Add Python to PATH". Then add 2 lines on pip.
Exam tip: A very common one-mark point: the version is checked using python --version (capital -V also works). A small -v is not for the version.

Chapter 2 : Syntax, Keywords and Variables

Rules of writing Python code, reserved words, names and variables.

Q10

Explain the basic syntax rules of Python with an example. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

Syntax means the rules for writing a program correctly. The basic rules of Python are:

  1. Indentation (usually 4 spaces) defines a block of code. Python does not use braces { }.
  2. Wrong indentation gives an IndentationError.
  3. A statement ends at the end of the line. A semicolon is optional and rarely used.
  4. Python is case-sensitive. Name and name are different.
  5. A comment starts with #. A multi-line comment can be written in triple quotes """ """.
Example program
if 5 > 3:
    print("5 is greater than 3")   # indented block
else:
    print("Condition is false")
Output
5 is greater than 3
How to write it: Write each rule as one short numbered sentence. Then add the example program with the indentation clearly visible.
Exam tip: Use the words indentation, case-sensitive and # for comments. Draw the program neatly with 4 spaces.

An IndentationError occurs when the statements of a block are not indented correctly. Python uses indentation to show which statements belong to a block, so a missing or uneven indentation stops the program.

Answer

An identifier is the name given to a variable, function, class, module or any object. The rules are:

  1. It must begin with a letter or an underscore (_).
  2. The remaining characters can be letters, digits or underscores.
  3. It cannot begin with a digit.
  4. It cannot be a keyword.

  6. Use meaningful names, as suggested by PEP 8 (for example student_name).

Q14

What is a variable? Explain dynamic typing with an example. 5 marks ★★★★★ Must study

Answer

A variable is a named location in memory that stores a value. In Python we do not declare the type of a variable. The type is decided from the value at run time. This is called dynamic typing. The same name can be given a new value of another type later.

Example program
name = "Alice"      # str
age = 21            # int
height = 5.6        # float
is_student = True   # bool
print(type(age))

x = 10
x = "Hello"         # same name, new type
print(type(x))
Output
<class 'int'>
<class 'str'>

Variable names follow the identifier rules. The PEP 8 style for names is snake_case, for example student_total.

How to write it: Definition, then "no type declaration, type decided at run time (dynamic typing)", then example with type().
Q15

Explain multiple assignment in Python with examples. 3 marks ★★★☆☆ Important

Answer

Python allows us to assign values to many variables in one statement. There are two forms.

  • Different values: x, y, z = 10, 20, 30. It works by tuple unpacking, so the number of names on the left must be equal to the number of values on the right.
  • Same value: a = b = c = 0 gives the value 0 to all three variables.
Example program
x, y, z = 10, 20, 30
print(x, y, z)

a = b = c = 0
print(a, b, c)
Output
10 20 30
0 0 0
Exam tip: If the number of names and values is not equal, Python gives a ValueError.

Q17

Differentiate between int and float. Why does 0.1 + 0.2 not give exactly 0.3? 3 marks ★★★☆☆ Important

Answer

An int has no decimal point (10) and has no size limit. A float has a decimal point (10.5) and is stored in 64-bit double precision. A bool is a subclass of int, so True is 1 and False is 0.

Computers store floats in binary, and some decimal fractions cannot be stored exactly. So a very small rounding error appears.

Example program
print(0.1 + 0.2)
print(True + True)
print(2.5e3)
print(type(10), type(10.0))
Output
0.30000000000000004
2
2500.0
<class 'int'> <class 'float'>

Q23

Explain the print() function with the parameters sep and end. 5 marks ★★★★★ Must study Asked in Nov 2025

Answer

The print() function shows output on the screen. It can print many values separated by commas. Two useful parameters are:

  • sep: the text placed between the values. The default is one space.
  • end: the text placed after the output. The default is a new line (\n).
Example program

print("Python", "is", "fun", sep="-")
print("Loading", end="...")
print("Done")
Output
Python is fun
Python-is-fun
Loading...Done

print() returns None. So we should never write result = print(...).

How to write it: Say what print does, explain sep and end with their default values, and give the three-line example.

Q31

Differentiate between identity and membership operators. What is the difference between == and is? 3 marks ★★★★☆ Very important

Answer

  • Identity operators (is, is not) check whether two names refer to the same object in memory.
  • Membership operators (in, not in) check whether a value is found in a sequence such as a string, list or tuple.
  • == compares the values, but is compares the objects. Equal does not mean identical.
Example program
x = 12
y = 12
print(x is y)
nums = [21, 13, 10, 17]
print(10 in nums)
print(5 in nums)
print(10 not in nums)
a = [1, 2]
b = [1, 2]
print(a == b, a is b)
Output
True
True
False
False
True False
Q32

What is operator precedence? Write the order of precedence. 3 marks ★★★☆☆ Important

Answer

Operator precedence decides which operator works first when an expression has many operators. The order from high to low is:

( ) → ** → * / // % → + - → << >> → & → ^ → | → comparison, is, in → not → and → or

Example program
print(2 + 3 * 4)       # * first
print((2 + 3) * 4)     # brackets first
print(2 ** 3 ** 2)     # ** works from right to left
Output
14
20
512

Brackets can always be used to change the order.

Answer

(Model essay answer. Use the structure below. Details are in the earlier questions of this chapter.)

  1. Introduction: An operator is a symbol that performs an operation on operands. Python has seven families of operators.
  2. Arithmetic: + - * / // % **, for calculations.
