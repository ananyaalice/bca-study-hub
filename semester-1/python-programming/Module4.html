Chapter 1 : Lists

1.1 What is a list?

  • List = ordered collection of items, written in square brackets [ ]
  • Mutable (can be changed). Duplicates allowed. Items can be of different types
marks = [70, 85, 90]
mixed = [1, "Ravi", 2.5, True]
empty = []
a = list("abc")        # ['a', 'b', 'c']
b = list(range(5))     # [0, 1, 2, 3, 4]

1.2 Indexing

  • Positive index starts at 0. Negative index starts at -1 (last item)
  • Index out of range → IndexError
lst1020304050
index01234
negative-5-4-3-2-1
lst[0]    # 10
lst[-1]   # 50
lst[1] = 99   # list changes → [10, 99, 30, 40, 50]

1.3 Slicing

  • Syntax: lst[start:stop:step]. stop is not included. Defaults: start 0, step 1
lst = [10, 20, 30, 40, 50]
lst[1:4]    # [20, 30, 40]
lst[:3]     # [10, 20, 30]
lst[2:]     # [30, 40, 50]
lst[::2]    # [10, 30, 50]
lst[::-1]   # [50, 40, 30, 20, 10]  (reversed)

  • Useful functions: len() sum() max() min(). Operators: + join, * repeat, in check. del lst[i] deletes an item

Chapter 2 : Tuples

  • Tuple = ordered collection in round brackets ( ). Immutable – cannot be changed after creation
  • Duplicates allowed. Indexing and slicing work like a list
  • Changing an item → TypeError
  • Only two methods: count(x) and index(x)
t = (10, 20, 30)
t[0]          # 10
t[0] = 5      # TypeError (immutable)
single = (5,) # one item needs a comma. (5) is just an int
p = 1, 2, 3   # brackets optional → (1, 2, 3)

Unpacking

  • Assigning tuple items to separate variables. Number of variables = number of items, else ValueError
  • * collects the remaining items (as a list)
t = (1, 2, 3)
a, b, c = t           # a=1, b=2, c=3
x, *rest = (1, 2, 3, 4)   # x=1, rest=[2, 3, 4]
a, b = b, a           # swap using tuple
ListTuple
[ ] – mutable( ) – immutable
Many methodsOnly count and index
Slower, more memoryFaster, less memory. Safe for fixed data

Chapter 3 : Sets

  • Set = collection of unique items in curly brackets { }
  • Unordered – no index, no slicing. Can add / remove items (mutable)
  • Duplicates are removed automatically. Items must be immutable (numbers, strings, tuples)
  • Empty set → set(). Note {} makes an empty dictionary
s = {1, 2, 2, 3}        # {1, 2, 3}
t = set([5, 5, 6])      # {5, 6}
e = set()               # empty set
MethodWork
add(x)Adds one item
update(iterable)Adds many items
remove(x)Removes x. KeyError if not present
discard(x)Removes x. No error if not present
pop()Removes and returns an arbitrary item
clear()Removes all items

Set operations (A = {1,2,3,4}, B = {3,4,5,6})

OperationSymbol / methodResult
Union (all items)A | B, A.union(B){1, 2, 3, 4, 5, 6}
Intersection (common)A & B, A.intersection(B){3, 4}
Difference (in A, not in B)A - B, A.difference(B){1, 2}
Symmetric differenceA ^ B, A.symmetric_difference(B){1, 2, 5, 6}

Printed order of a set may differ – a set has no fixed order.

Chapter 4 : Dictionaries

  • Dictionary = collection of key : value pairs in { }
  • Keys are unique and immutable (str, int, tuple). Values can be any type and can repeat
  • Mutable. Items are found by key, not by index
  • From Python 3.7 a dict keeps insertion order (older books call it “unordered”)
student = {"name": "Ravi", "age": 20}
student["name"]            # 'Ravi'
student["marks"]           # KeyError (no such key)
student.get("marks")       # None (no error)
student.get("marks", 0)    # 0  (default value)
student["age"] = 21        # update
student["city"] = "Kochi"  # add new pair
MethodWork
keys()All keys
values()All values
items()All (key, value) pairs
get(k, default)Value of k, or default if missing
update(other)Adds / changes pairs from another dict
pop(k)Removes key k, returns its value
popitem()Removes the last inserted pair
clear()Removes all pairs
  • del student["age"] deletes a pair. "name" in student checks the keys

Nested dictionaries

  • A dictionary inside another dictionary. Use one key after another
students = {
    "s1": {"name": "Ravi", "age": 20},
    "s2": {"name": "Anu", "age": 19}
}
students["s1"]["name"]        # 'Ravi'
students["s2"]["age"] = 21    # change inner value
students["s3"] = {"name": "Joel", "age": 22}   # add new inner dict

Chapter 5 : Iterating over Data Structures

lst = [10, 20, 30]
for x in lst:                          # items
    print(x)
for i in range(len(lst)):              # index
    print(i, lst[i])
for i, x in enumerate(lst):            # index + item
    print(i, x)

d = {"a": 1, "b": 2}
for k in d:                  # keys
    print(k)
for v in d.values():         # values
    print(v)
for k, v in d.items():       # key and value
    print(k, v)
  • Tuple, set and string also work with for x in ... (set order is not fixed)
  • Loop over a dictionary directly → gives keys

Chapter 6 : Comprehensions

6.1 List comprehension

  • Short way to build a list in one line
  • Syntax: [expression for item in iterable if condition] (if part is optional)
# loop way
sq = []
for x in range(1, 6):
    sq.append(x ** 2)
# comprehension way
sq = [x ** 2 for x in range(1, 6)]
# [1, 4, 9, 16, 25]
[x for x in range(10) if x % 2 == 0]       # [0, 2, 4, 6, 8]
["even" if x % 2 == 0 else "odd" for x in range(3)]   # ['even', 'odd', 'even']

6.2 Dictionary comprehension

  • Syntax: {key: value for item in iterable if condition}
{x: x ** 2 for x in range(1, 5)}        # {1: 1, 2: 4, 3: 9, 4: 16}
{n: len(n) for n in ["Ravi", "Anu"]}    # {'Ravi': 4, 'Anu': 3}

Programs (Lab-type)

# sum and average of a list
marks = [70, 80, 90]
total = sum(marks)
avg = total / len(marks)
print(total, avg)     # 240 80.0
# linear search
nums = [4, 8, 15, 16]
target = 15
for i in range(len(nums)):
    if nums[i] == target:
        print("Found at index", i)
        break
else:
    print("Not found")  # Found at index 2
# bubble sort
arr = [64, 34, 25, 12, 22]
n = len(arr)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]   # swap
print(arr)            # [12, 22, 25, 34, 64]
# remove duplicates (order may change)
data = [1, 2, 2, 3, 3, 3]
print(list(set(data)))   # [1, 2, 3]
# count words using a dictionary
text = "to be or not to be"
count = {}
for w in text.split():
    count[w] = count.get(w, 0) + 1
print(count)
# {'to': 2, 'be': 2, 'or': 1, 'not': 1}

★ Key Observations

  • List [ ] mutable. Tuple ( ) immutable. Set { } unique. Dict {k: v} key-value
  • Slicing: stop index is not included
  • Single-item tuple needs a comma: (5,)
  • {} is an empty dict. Empty set is set()
  • remove() gives an error if item is missing. discard() does not
  • dict[key] → KeyError if missing. dict.get(key) → None
  • Dictionary keys must be immutable. A list cannot be a key
  • Unpacking needs the same number of variables as items

Real-Life Applications

  • List: marks of students, shopping cart, to-do list
  • Tuple: fixed data – coordinates (x, y), dates, days of the week
  • Set: removing duplicates, unique visitors, common friends (intersection)
  • Dictionary: student records, phone book, word count, JSON-like data
  • Comprehensions: quick filtering and conversion of data
