BCA Study Hub — Semester 1

Open index.html to start. It links to Semester 1. From there, open a subject and select a module or question page.

Navigation is kept simple and responsive. Every page has Home/breadcrumb links; module pages also include Previous and Next links.

To add existing study content, replace the placeholder inside the corresponding module HTML file while preserving the filename and the navigation links. For example, Python Programming Module 1 is:
semester-1/python-programming/module1.html

ModelQuestions.html is for practice/model questions. PreviousQuestions.html should contain only verified questions/papers from actual previous examinations.

All styles are embedded within each HTML file. There are no external CSS, JavaScript, font, or image dependencies.

The other seven semester pages are not yet created; their cards on the home page are intentionally inactive.
